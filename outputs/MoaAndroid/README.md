# 지금 내 기분이 그래 Android 0.3.0

**상태: 통합 빌드·QA 진행 중.** 이 문서는 현재 소스의 구현 범위를 설명합니다. 새 버전의 테스트 통과나 출시 승인을 의미하지 않습니다. 출시·Play 제출·서비스 배포는 이번 작업 범위에서 보류했습니다.

6~18개월 아기의 소리와 표정을 보호자가 살펴보고, 그 순간을 아이 시점의 문장으로 풀어 보는 Android 앱입니다. 결과는 **보호자가 확인하고 수정하는 표현 예시**입니다. 감정, 욕구, 울음 원인, 건강 상태, 발달 수준을 판정하지 않습니다.

## 실행

Android Studio에서 이 디렉터리를 열거나 Android SDK와 JDK 17 이상 환경에서 실행합니다. 통합 작업 환경은 JDK 21, Android SDK 36입니다.

```powershell
.\gradlew.bat :app:assembleDebug :app:assembleDebugAndroidTest :app:lintRelease
```

APK는 `app/build/outputs/apk/debug/app-debug.apk`에 생성됩니다. 최소 Android 8.0(API 26), compile/target SDK 36, versionCode 6입니다. 앱 이름은 `지금 내 기분이 그래`, 기술 식별자는 기존 설치의 연속성을 위해 `com.moa.babylanguage`를 유지합니다. 마이크·카메라는 권한과 해당 하드웨어가 필요합니다.

## 사용 흐름과 무료 범위

1. **오늘:** 소리 녹음, 저장된 영상 또는 실시간 카메라를 선택합니다. 월령은 선택 사항이며 문장 추천에는 적용하지 않습니다.
2. 소리는 최대 10초, 16 kHz PCM으로 기기 메모리에서 분석합니다. YAMNet 일반 소리 후보가 표시돼도 보호자가 소리 유형을 확인해야 합니다. 녹음이 어렵다면 수동으로 진행할 수 있습니다.
3. 저장 영상은 30초·50MB 이하 파일을 시스템 선택기로 읽습니다. 최대 5개 프레임과 첫 최대 10초의 오디오를 살펴봅니다. 오디오가 없거나 분석하기 어려워도 직접 확인할 수 있습니다. 실시간 카메라는 얼굴·입 열림 단서만 제시하며 전후면 전환을 지원합니다.
4. 보호자가 수유·수면·놀이 등 상황을 선택하면 표현 예시 3개를 비교하고 직접 수정해 저장합니다. 근거는 펼쳐서 확인할 수 있습니다.
5. **기록:** 기록 조회·개별 삭제, 최근 일주일 요약, 문장 PNG 카드 공유를 제공합니다. 카드에 보호자 메모는 포함하지 않습니다.
6. **아기말북:** 월별 기록과 세 가지 표지 미리보기는 무료입니다. 이용권이 확인되면 기기에서 월별 PDF를 만들 수 있습니다. 보호자 메모 포함은 기본적으로 꺼져 있습니다. 한 권은 최대 300개 기록·300쪽이며 한도를 넘으면 원본을 유지하고 생성을 중단합니다.
7. **돌봄:** 전체 기록의 JSON 백업·가져오기, CSV 내보내기, 전체 기록 삭제, 구매 복원, 개인정보처리방침을 제공합니다. CSV는 가져오기 형식이 아닙니다.

기본 표현 만들기·수정·기록·조회·삭제·JSON/CSV 백업·PNG 공유는 이용권과 관계없이 사용할 수 있습니다. 무료 기록을 가리거나 분석 정확도를 유료 등급으로 나누지 않습니다.

## 문장이 달라지는 방식

`PhraseEngine.kt`는 소리 5종 × 상황 6종의 조합마다 앞부분 4개와 뒷부분 4개를 조합한 **16개 표현**을 사용합니다. 새 세션에는 같은 조합에서 최근 제시한 9개 표현을 피하며 3개를 고릅니다. 동일 세션의 선택은 기기 내 캐시에서 유지하며 캐시는 최대 128개 세션입니다.

따라서 기존의 고정 3문장보다 다양하지만 **표현은 유한하며 시간이 지나면 다시 나올 수 있습니다.** LLM 자유 생성이나 아기의 의도를 알아내는 번역 엔진이 아닙니다. 의미가 같은 문장의 표현만 바뀔 수도 있으며 보호자가 고치거나 직접 적을 수 있습니다.

## 데이터와 복구

- 기록은 앱 전용 **SQLite**에 최대 10,000건 저장합니다. 저장 항목은 시각, 소리 유형, 상황, 메모, 선택·수정 문장, 입력 경로, 모델 단서와 월령 범위입니다. 과거 SharedPreferences 기록을 이전하고, 이전이 완료된 사본은 정리합니다. 손상된 이전 항목의 복구용 사본이 있으면 안내하며 전체 기록 삭제 시 함께 지웁니다.
- 원본 녹음·카메라 프레임·영상 파일을 앱에 보관하거나 서버로 보내지 않습니다. 앱 작업 버퍼는 사용 후 초기화하지만 Android·모델 SDK 내부 복사본의 즉시 완전 삭제까지 보장하지 않습니다. 선택한 영상은 기존 URI에서 읽으며 원래 저장 위치에 남습니다.
- 표현 후보의 반복 방지 상태, 설치별 무작위 결제 식별자, 짧은 유효기간의 서명된 이용권은 별도 SharedPreferences에 저장합니다. 구매 토큰 원문은 앱에서 별도 영구 저장하지 않습니다.
- `allowBackup=false`, `fullBackupContent=false`와 Android 12+ 백업·기기 이전 제외 규칙을 사용합니다. 모든 제조사 이전 도구까지 검증한 것은 아닙니다. 자동 동기화·외부 아기 기록 DB·앱 로그인은 없습니다.
- 무료 JSON 백업은 메모를 포함하며 사용자가 선택한 저장 위치에 씁니다. 가져오기는 UTF-8·스키마·크기·길이를 검사하고 미리보기 후 트랜잭션으로 합칩니다. 같은 기록은 중복을 피하며 같은 시각의 다른 기록은 기존 기록을 보존하고 같은 날짜 안에서 구분합니다. CSV는 표 열람용입니다.
- 공유용 PNG/PDF는 앱 캐시에 생성합니다. 24시간이 지난 파일은 정리 작업 대상이며 기록 삭제 시 앱이 관리하는 공유 캐시도 정리합니다. 다른 앱으로 공유했거나 직접 내보낸 파일은 해당 위치에서 사용자가 삭제해야 합니다.
- 앱 삭제·기기 분실 시 서버 복원은 불가능합니다. 보관한 JSON 백업으로 기록을 옮기고, 구매는 같은 Google Play 계정에서 별도로 복원합니다.

## 결제와 네트워크

Google Play Billing **9.1.0** 클라이언트와 별도 검증 API 소스를 구현했습니다. 상품 ID는 `jigeum_album`, 요금제는 `monthly`(월 자동 갱신)와 `three-month-prepaid`(3개월 선불)입니다. 화면 가격은 Google Play 상품 응답을 사용하며 고정 가격을 임의로 표시하지 않습니다.

APK의 `INTERNET` 권한은 결제 확인 경로에 필요합니다. 소리·영상·기록의 서버 분석은 없습니다. 앱의 검증 요청에는 패키지명·상품 ID·구매 토큰·무작위 설치 식별자만 담습니다. 검증 API는 Google Play 상태를 확인하고 설치에 묶인 최대 24시간의 서명된 이용권을 반환합니다. 자체 사용자 DB는 사용하지 않습니다. 서버 자격 증명과 개인 서명 키는 APK에 넣지 않습니다.

빌드 공개 설정은 `JIGEUM_PLAY_VERIFY_URL`(HTTPS)과 `JIGEUM_PLAY_ENTITLEMENT_PUBLIC_KEY`입니다. 기본값은 비어 있으므로 현재 설정 없는 빌드는 구매를 열거나 유료 권한을 임의로 부여하지 않습니다. 무료 기능은 유지됩니다. 실제 구매·복원·보류·취소·환불 검증은 Play 상품과 검증 서비스가 준비된 후 별도로 필요하며 모의 테스트로 대체했다고 주장하지 않습니다.

검증 서비스 소스는 `../PlayVerifier`에 있습니다. 이번 작업에서 배포하지 않습니다. 서비스 장애 시 확인된 이용권의 유효기간 안에서만 임시 사용하며 만료되면 다시 확인해야 합니다. 기록과 무료 기능은 남습니다. 앱 내 전체 아기 기록 삭제는 Google Play 구독 해지를 의미하지 않습니다.

## 모델과 근거 한계

- [YAMNet](https://github.com/tensorflow/models/tree/master/research/audioset/yamnet): 일반 AudioSet 소리 분류. 0.20 후보 표시·0.50 울음/웃음 칩 선선택은 내부 임시 기준이며 아기 의도 정확도나 검증된 확률이 아닙니다. 일반 말소리를 옹알이로 자동 확인하지 않습니다.
- [MediaPipe Face Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/face_landmarker): 얼굴·입 형태 관찰. 영아의 감정·욕구 판독이 아닙니다.
- `.tflite` 실행은 MediaPipe Tasks가 담당합니다. 별도 LiteRT SDK 직접 연동, librosa 앱 탑재, voc2vec 학습·탑재는 구현하지 않았습니다. 논문과 레퍼런스 검토를 실제 임상/영아 의도 정확도 검증으로 표현하지 않습니다.
- 모델 출처·해시·라이선스는 assets의 `YAMNET_NOTICE.txt`, `MODEL_NOTICE.txt`, `LICENSE-APACHE-2.0.txt`에 있습니다.
