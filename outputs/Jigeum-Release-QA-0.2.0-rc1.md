# 지금 내 기분이 그래 Android 출시 후보 0.2.0-rc1 QA

2026-09-30 · 앱 표시 이름 `지금 내 기분이 그래` · 설치 식별자 `com.moa.babylanguage`

## 판정 범위

API 35 x86_64 에뮬레이터에서 기능 코드가 같은 디버그 APK와 별도 QA 키로 서명한 **비축소 릴리스 APK**로 소리·카메라·저장·삭제와 영상 선택의 정상·오류 경로를 확인했다. 마지막 개인정보 안내 문구 수정 뒤 디버그 APK와 AAB를 다시 빌드하고 Lint를 통과했으며, 이 문구만 바뀐 최종 파일의 동적 재시험은 수행하지 않았다. 최종 AAB와 네이티브 라이브러리는 정적 검사했다. **ARM 실기기, 실제 영아 입력의 의미·정확도, Play Console 제출 심사는 이 시험으로 검증되지 않는다.**

## 시험 해석

첫 카메라 자동 시험에서 UIAutomator가 시작 직후 세 번 빈 구조를 반환했다. 앱 프로세스와 화면은 살아 있었고 같은 APK의 재시험은 통과했다. 녹음 백그라운드 자동 시험은 화면 덤프 대기 중 10초 자동 종료가 먼저 발생했다. 홈으로 나간 뒤 `onStop`을 기다리는 빠른 재시험에서 기대한 중단 안내가 나타났다. 두 시도는 앱 결함으로 단정하지 않았으며 실패 흔적과 재시험 결과를 모두 개발 증거에 보존했다.

영상 파일은 시스템 선택기의 URI에서 읽고 앱 기록에 URI·원본을 저장하지 않는다. 파일 길이·크기를 제한하고 디코더·랜드마커를 닫는다. 서버, 계정, 광고·분석 SDK, 인터넷 권한이 없으므로 서버 장애·동시접속 시험은 이번 버전에 적용되지 않는다. 기기 안에서는 카메라 반복과 영상 크기 제한으로 병목을 확인했다. 저사양 ARM의 지연·발열은 실제 기기에서 측정해야 한다.

**릴리스 전용 결함:** 처음 적용한 R8 축소 릴리스에서는 CameraScan과 영상 가져오기 모두 FaceLandmarker 초기화가 실패했다. 로그에서 MediaPipe protobuf 필드 `SystemInfo.platform_`가 제거된 것을 확인했고, 좁은 보존 규칙으로 첫 오류를 해결해도 후속 연결 오류가 발생했다. 이번 버전은 코드·리소스 축소를 끄고 비축소 릴리스에서 얼굴 모델 초기화와 카메라·저장 영상·10초 소리 흐름을 재시험해 통과했다. 추후 MediaPipe 업그레이드 또는 축소를 다시 켤 때 이 경로를 회귀 시험해야 한다.

**자동화 재시험:** 선택한 영상의 가로 화면 요약이 처음엔 보이지 않았다. 요약이 접힌 화면 아래에 있었고, 시험 스크립트가 세로 화면의 물리 해상도로 스와이프 좌표를 계산해 화면 밖을 누른 것이 원인이었다. 가로 표시 크기에 맞춘 스크롤로 요약을 확인했고, 다시 세로로 돌려도 선택 내용이 남았다.

## 제출 전 필수

1. 사용자 결정 이름 `지금 내 기분이 그래`의 스토어 중복·상표 사용 가능성을 확인하고 기술 식별자 `com.moa.babylanguage` 유지 결정을 첫 게시 전에 확정한다.
2. 운영자명·지원 이메일·시행일을 넣은 개인정보처리방침을 공개 HTTPS URL에 게시한다.
3. 소유자 업로드 키로 AAB를 서명하고 Play App Signing 및 Play Console 선언을 완료한다.
4. ARM64 실기기 두 종류 이상에서 마이크, 카메라, 기존 영상, 회전, 백그라운드, 16KB 페이지, 장시간 사용을 확인한다.
5. 실제 보호자 대상 시험으로 문장이 아기의 의도를 정확히 알아냈다는 오해를 일으키지 않는지 확인한다.

정적·동적 실행 로그와 화면은 개발 증거 ZIP에 보관한다. Play 제출 가능 여부는 서명·계정·정책·실기기 검증을 마친 뒤 다시 판단해야 한다.
