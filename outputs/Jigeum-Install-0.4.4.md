# 지금 내 기분이 그래 0.4.4 설치 안내

Android 8/API26 이상. APK는 개발 서명이며 무료 기능 확인용이다. 기존 개발 서명 설치는 APK를 열어 업데이트하면 기록이 유지된다. 서명이 다르면 기존 앱을 삭제하지 말고 먼저 무료 JSON 백업을 보관한다.

1. `Jigeum-Android-debug-0.4.4.apk`를 Android 기기로 옮겨 연다.
2. 설치에 쓰는 앱의 ‘알 수 없는 앱 설치’를 허용하고 설치한다. 설치 후 이 권한은 다시 끌 수 있다.
3. 녹음 또는 직접 입력 → 보호자 상황 확인 → 문장 수정·저장 → PNG 공유·JSON 백업을 확인한다. 앱 로그인과 외부 기록 DB는 없다.

카메라·저장 영상·PDF는 전체 이용권 기능이다. 현재 결제 검증 URL/공개키가 비어 있어 실제 구매는 비활성화돼 있다. AAB는 미서명으로 Play에 제출할 수 없다. 운영 설정·업로드 서명·실제 Play 거래·ARM 실기기 확인과 공개 제출은 이후 진행한다.
