# 아가톡 아이콘

2026-10-01. 사용자가 요청한 **아기 얼굴 + 말풍선**을 built-in imagegen의 새 이미지 생성으로 제작했다. 최종 디자인 브리프는 단순한 둥근 아기 얼굴·작은 앞머리·살구빛 피부·세이지 말풍선·크림 배경이다. 기존 캐릭터를 실사화하지 않는다.

- `agattok-icon-source.png`: 생성 원본.
- `agattok-play-icon-512.png`: Play용512px 초안. Console에 업로드하지 않음.
- Android drawable-nodpi 복사본과 adaptive foreground14dp inset 적용. 단색 아이콘은 별도 baby+bubble vector.
- 패키지/서명은 유지하고 앱서랍 이름은 **아가톡**.

이 문서의 디자인 브리프는 생성 프롬프트의 축약이며 실행 프롬프트 전문을 복원했다고 주장하지 않는다. 실제 마스킹 확인 결과는 [0.5 QA](../../docs/qa/0.5.0/README.md)를 따른다. 기존 확정 트레일러 가족 캐릭터와 별개 자산이다.
