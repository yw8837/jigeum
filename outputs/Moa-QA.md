# 모아 Android MVP 0.1.2 작동 점검

2026-09-30 · API 35 x86_64 에뮬레이터 기준. 재현 경로, 실패·수정·회귀, 명령 종료 코드와 증거는 [전체 UltraQA 보고서](./Moa-UltraQA-2026-09-30.md)에 있다.

| 항목 | 결과 |
|---|---|
| 빌드·Lint·APK 16KB 정렬 | 통과. Gradle 종료 코드 0, Lint 오류 0·경고 14, `zipalign -P 16` 통과 |
| 소리 수동 입력→문장→저장·삭제 | 통과 |
| 마이크 권한 거부→설정 안내→복구 | 통과 |
| 10초 녹음 후 분석 화면 | 통과. 실제 영아 소리 분류 정확도는 미검증 |
| 카메라 얼굴 관찰→문장 | 통과. MediaPipe 1.0.0 x86_64 모델 구동 확인 |
| 녹음 중 앱 이탈 | 녹음 중단과 미저장 안내 확인 |
| 손상·중복 기록과 Unicode 메모 | 정상 기록 보존·중복 건너뛰기·문구 표시 확인 |
| 작은 화면·큰 글자 | 720×1280/200%에서 핵심 버튼·월령 선택 접근 확인 |
| 기기 내 반복·대량 기록 | 카메라 20회 같은 프로세스 통과, 기록 2,000건 목록 진입 확인 |
| 네트워크 단절 | 비행기 모드에서 핵심 번역·저장·삭제 통과 |
| 홍보 영상 | H.264/AAC 720×1280 26.5초, 전체 디코드 오류 없음 |

이번 수정은 손상 기록에 의한 전체 기록 소실, ID 충돌, 권한 복구 안내 누락, 큰 글자에서 카메라 조작 가림, 매니페스트 Lint 오류, 앱 아이콘 누락, MediaPipe의 16KB 정렬 경고를 다뤘다. 현재 앱은 **기기 내 처리**라 서버 장애·동시 접속 부하 경로가 없다. 향후 서버 도입 시 시험 조건은 전체 보고서에 적었다.

**출시 전 필수:** ARM64 실기기에서 모델 성능·발열·회전·16KB 페이지 호환성을 재검증한다. 기존 영상 파일 가져오기와 음성·영상 동시 분석은 구현되지 않았다. 결과 문장은 아기의 의도를 판정한 값이 아니라 보호자 맥락을 반영한 가능한 표현 예시다.
