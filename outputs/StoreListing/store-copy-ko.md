## 자세한 설명 — 최종 QA·Play 연결 확인 후 게시할 초안

아기가 옹알이할 때, 지금 이 순간을 어떤 말로 남기면 좋을까요?

‘지금 내 기분이 그래’는 6~18개월 아기를 돌보는 보호자가 소리와 상황을 살펴보고 아이 시점의 표현을 기록하는 앱입니다. 최대 10초의 소리를 녹음하거나 직접 들은 소리를 고른 뒤 수유·수면·놀이 등 그때의 상황을 알려 주세요. 표현 예시 3개를 비교하고, 우리 아이에게 어울리게 고쳐 저장할 수 있어요.

### 무료로 계속 쓰는 기본 기능

- 최대 10초 녹음과 직접 입력: 일일 횟수 차감 없이 사용
- 같은 품질의 표현 후보 3개, 문장 수정·저장
- 기존 기록 조회·삭제와 최근 일주일 기본 요약
- 기본 PNG 문장 카드 공유
- JSON 기록 백업·가져오기, CSV 내보내기
- 월별 앨범과 세 가지 표지 미리보기

기존 기록에 유료 보관 기간을 두지 않습니다. 앱 삭제나 휴대전화 분실에 대비해 JSON 백업을 직접 보관할 수 있어요. 사용 횟수에 따른 과금은 없으며 기기 저장 공간과 기록 수 등 기술상 한도는 적용됩니다.

### 하나의 전체 이용권

- 실시간 카메라로 얼굴과 입의 보이는 움직임 살펴보기
- 보호자가 고른 30초·50MB 이하 저장 영상 분석
- 월별 아기말북 PDF 만들기와 세 가지 표지 적용

저장 영상은 최대 5개 장면과 첫 최대 10초 소리의 일반적인 후보를 기기에서 살펴봅니다. 모델 후보는 보호자가 확인해야 합니다. 카메라·영상·PDF를 위한 이용권을 따로 구매할 필요는 없습니다. 월간 자동 갱신 또는 자동 갱신 없는 3개월 이용권 중 선택하며, 실제 가격과 청구 조건은 앱의 Google Play 상품·결제 화면에서 확인합니다.

이용권이 끝나도 이미 생성된 문장 초안은 무료로 편집·저장할 수 있습니다. 저장 완료 기록의 조회·공유·삭제·백업과 다른 무료 기능, 보관한 PDF도 계속 이용할 수 있습니다. 새 카메라 관찰·영상 분석·PDF 생성에는 유효한 이용권이 필요합니다.

### 보호자가 확인하는 표현이에요

소리 모델은 일반 소리 후보를, 얼굴 모델은 화면에 보이는 형태의 단서를 제공합니다. 아기의 실제 뜻·감정·배고픔·졸림의 원인이나 건강·발달 상태를 판정하지 않습니다. 표현은 유한한 예시를 반복을 줄여 제시하는 방식이며, 무한 생성이나 실제 의도 번역을 보장하지 않습니다. 보호자가 알맞게 고쳐 기록해 주세요.

앱 회원가입은 없습니다. 아기 기록은 이 기기에 저장하며 원본 녹음·영상·기록을 운영자 분석 서버에 올리지 않습니다. 결제 확인에는 Google Play와 구매 토큰·설치 식별자를 이용한 검증 통신이 필요합니다. 같은 Play 계정으로 구매를 복원할 수 있으며 기록은 별도로 보관한 JSON 백업에서 가져옵니다. 다른 앱이나 클라우드에 직접 공유한 파일에는 해당 서비스의 처리가 적용됩니다.
