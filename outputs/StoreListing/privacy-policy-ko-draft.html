지금 내 기분이 그래 개인정보처리방침

0.4.0 소스의 데이터 흐름을 반영한 미게시 초안: 무료 기본 기능과 카메라·저장 영상·PDF 전체 이용권의 권한 분리, 기록 백업·공유·결제 검증 흐름을 코드에 반영했습니다. 로컬 통합 빌드·QA를 완료했으며 실제 Play·ARM 검증은 별도이며 결과는 0.4.0 QA 보고서에 기록합니다. 출시·제출·검증 API 배포는 보류 중입니다. 공개 URL, 시행일, 필요한 운영자 공개 정보와 실제 서버 제공자·로그 보존 정책을 확정한 뒤 게시해야 합니다. 소스 구현이 테스트 통과나 서비스 개시를 의미하지 않습니다.

1. 서비스와 저장 정보

‘지금 내 기분이 그래’는 6~18개월 아기의 성인 보호자가 소리와 장면을 살펴보고 표현 문장을 만들고 기록하는 Android 앱입니다. 앱 회원가입이나 로그인은 없습니다. 보호자가 선택한 월령 범위, 소리 유형, 직전 상황, 메모, 문장, 기록 시각, 입력 경로, 모델 단서 이름은 앱 전용 SQLite 저장소에 남습니다. 아기 기록을 보관하는 외부 DB나 자동 동기화는 사용하지 않습니다.

표현이 바로 반복되는 일을 줄이기 위한 소리·상황별 후보 이력과 세션 캐시는 기기 내 SharedPreferences에 저장합니다. 조합마다 16개 표현에서 최근 9개를 피하는 방식이므로 표현은 시간이 지나면 다시 나올 수 있습니다. 아기의 의도를 확정하거나 의료·발달 상태를 진단하지 않습니다.

2. 마이크·카메라·선택한 영상

마이크는 보호자가 녹음을 시작할 때 최대 10초 동안 사용합니다. 소리는 기기 메모리에서 임시로 분석하며 원본 녹음 파일을 만들거나 보관하지 않습니다. 카메라는 보호자가 시작한 화면에서 사용하고 전후면을 전환할 수 있습니다. 실시간 카메라 프레임이나 얼굴 정보 파일은 저장하지 않습니다.

영상 가져오기는 보호자가 시스템 파일 선택기에서 고른 30초·50MB 이하 파일을 읽습니다. 최대 5개 장면을 살펴보고 오디오가 있으면 첫 최대 10초의 소리를 기기 메모리에서 추출·분석합니다. 원본 영상이나 추출 오디오 파일을 앱 저장소에 복사해 보관하거나 운영자 서버에 전송하지 않습니다. 형식·기기 상태에 따라 분석하지 못할 수 있으며 결과는 보호자가 확인합니다. 선택한 영상은 원래 저장 위치에 남고, 사진·클라우드 제공자의 접근·동기화에는 해당 제공자의 정책이 적용됩니다.

앱이 관리하는 작업용 소리 버퍼는 사용 후 초기화하지만 Android와 모델 SDK 내부 메모리의 즉시 완전 삭제까지 보장하지는 않습니다.

3. 보호자가 선택하는 백업과 공유

JSON 백업과 CSV 내보내기는 기록과 메모를 포함합니다. 보호자가 시스템 저장 화면에서 선택한 위치에 파일을 쓰며, JSON 백업은 앱에서 다시 가져올 수 있습니다. 선택한 위치가 다른 앱이나 클라우드라면 해당 서비스가 파일을 처리할 수 있습니다. 앱을 삭제하거나 휴대전화를 잃으면 서버 복원은 불가능하므로 필요한 백업은 보호자가 보관해야 합니다.

문장 PNG 카드와 월별 PDF는 기기에서 만듭니다. PNG에 보호자 메모는 담지 않습니다. PDF의 메모 포함은 보호자가 선택하며 기본적으로 꺼져 있습니다. 앱은 시스템 공유 화면에서 보호자가 고른 앱에 파일 읽기 권한을 제공합니다. 자동 가족 공유나 자동 업로드는 하지 않습니다. 수신 앱에서의 이용·보관에는 해당 제공자의 정책이 적용됩니다.

4. Google Play 결제와 검증 통신

0.4.0의 녹음·직접 입력과 기본 표현·기록·삭제·백업·PNG 공유는 무료이며 전체 이용권은 카메라 관찰·저장 영상 분석·월별 PDF 생성에 사용합니다. 상품 조회·구매·복원은 Google Play Billing을 사용하고 결제 수단은 Google Play가 처리합니다. 앱 자체 로그인 없이 같은 Google Play 계정으로 구매를 복원할 수 있습니다. 구매 복원은 아기 기록을 복원하는 기능이 아닙니다.

결제 확인이 설정된 빌드는 HTTPS로 패키지명, 상품 ID, Google Play 구매 토큰, 앱 설치별 무작위 식별자를 운영자 검증 API에 보냅니다. 검증 API는 Google Play에서 상품·상태·기간을 확인하고 설치에 묶인 서명된 이용권을 반환합니다. 아기 소리·영상·기록·메모는 이 요청에 포함하지 않습니다. 이용권은 최대 24시간 또는 구독 만료 중 먼저 도래하는 시각까지 유효합니다.

앱은 설치 식별자와 서명된 이용권, 캐시 버전·수신 시각·수신 시 단조시간·부팅 횟수를 기기 안에 저장하며 구매 토큰 원문을 별도 영구 저장하지 않습니다. 단조시간은 기기의 실제 경과시간을 확인하는 데 사용합니다. 시계를 되돌려도 오프라인 허용 기간이 늘어나지 않도록 검사하며 재부팅 후에는 온라인에서 이용권을 다시 확인해야 합니다. 검증 서비스 소스는 사용자 DB나 요청 본문·토큰 로그를 만들지 않고, 요청 처리와 과다 요청 제한을 위해 구매 조회·소켓 IP 등의 일시적인 메모리 상태를 사용합니다. 실제 배포 제공자, 접속 로그와 보존 정책은 배포 전 이 초안에 반영해야 합니다. Google Play의 계정·결제 처리는 Google의 정책을 따릅니다.

현재 기본 빌드의 검증 URL과 공개 키는 비어 있고 검증 API는 배포하지 않았습니다. 설정이 없으면 구매를 진행하거나 유료 권한을 임의로 부여하지 않으며 무료 기능은 계속 사용할 수 있습니다. 앱에는 결제 확인을 위한 INTERNET 권한이 있고 광고·행동 분석·앱 계정 SDK는 없습니다.

0.4.0 무료 기능과 이용권 만료

카메라 관찰·저장 영상 분석·월별 PDF와 세 가지 표지는 하나의 전체 이용권으로 제공합니다. 10초 녹음/직접 입력, 같은 품질의 문장 3후보·수정·저장, 기존 기록, PNG 기본 공유, JSON 백업·복원과 CSV 내보내기, 주간 기본 요약과 앨범 미리보기는 무료로 유지합니다. 이 권한 분리를 소스에 반영했으며 실제 구매 연결 검증은 별도로 남아 있습니다.

권한 만료 시 진행 중인 카메라·영상 분석은 중지하고 늦은 응답을 폐기합니다. 이미 생성된 문장 초안은 무료로 편집·저장할 수 있고, 저장 완료 기록은 무료로 조회·공유·삭제하고 백업할 수 있습니다. 권한이 유효할 때 실제 생성을 시작한 PDF는 완료할 수 있고, 만들어 보관한 파일은 이용권 만료로 삭제하거나 읽기를 잠그지 않습니다. 명시적 환불·권한 철회 또는 검증 거절을 확인하면 새로운 유료 작업을 막습니다. 오프라인 중 새 환불은 즉시 알 수 없으며 이미 확인한 서명의 유효기간인 최대 24시간 안에서만 임시 이용할 수 있습니다. 재부팅이나 캐시 검증 정보 손상 시에는 온라인 재확인이 필요합니다. 자세한 범위는 이용약관 초안을 참고하며 최종 QA와 공개 방침을 일치시킵니다.

5. 보관·삭제와 이전

기록은 보호자가 삭제하거나 앱 데이터를 지우거나 앱을 제거할 때까지 기기에 남습니다. 기록 화면에서 개별 삭제, 돌봄 화면에서 전체 기록과 월령 선택 삭제가 가능합니다. 전체 삭제 시 표현 반복 방지 이력도 초기화합니다. 이전 버전 기록은 SQLite로 옮긴 후 성공적으로 이전한 옛 사본을 정리하며, 손상된 항목의 복구용 사본이 있으면 안내하고 전체 기록 삭제 시 함께 지웁니다.

공유용 파일은 앱 전용 캐시에 저장하며 24시간이 지난 자체 생성 파일은 정리 대상입니다. 기록 삭제 시 앱이 관리하는 공유 캐시도 정리합니다. 보호자가 외부에 내보내거나 다른 앱에 보낸 파일은 앱 내 삭제로 지워지지 않으므로 해당 위치에서 직접 삭제해야 합니다.

Android 자동 백업·기기 이전에서 앱 데이터가 제외되도록 설정했습니다. 모든 제조사의 별도 이전 도구까지 검증한 것은 아닙니다. 앱 기록 삭제나 앱 제거는 Google Play 구독 해지를 의미하지 않습니다. 구독 해지·환불·Google 계정 관련 권리는 Google Play의 해당 관리 경로를 이용합니다.

6. 보호자와 아기 정보

앱의 사용 대상은 성인 보호자이며 아기 이름·정확한 생년월일·연락처를 요구하지 않습니다. 자유 메모에는 보호자가 입력한 개인정보가 포함될 수 있습니다. 백업·메모 포함 PDF를 공유하기 전 수신자와 포함 내용을 확인할 수 있습니다. 결과 문장은 보호자가 수정하는 표현 예시이며 영아의 실제 의도나 건강을 판정한 결과가 아닙니다.
