## 0.4.4 권한 분리와 데이터 처리 영향

0.4.4 소스는 카메라 관찰·저장 영상 분석·월별 PDF를 하나의 전체 이용권으로 묶고, 10초 녹음/직접 입력·같은 품질의 문장 3후보·수정·저장·기존 기록·PNG 공유·JSON 백업/복원·CSV 내보내기·주간 기본 요약·앨범 미리보기를 무료로 유지한다. 이 경계 변경 자체가 아기 영상·문장의 외부 수집을 추가하는 것은 아니다.

권한 처리 코드는 만료 시 진행 중 카메라/영상 중지와 늦은 응답 폐기, 이미 생성된 문장 초안의 무료 편집·저장, 유효한 권한으로 시작한 PDF 생성 완료를 구분한다. 저장 완료 기록은 무료 조회·공유·삭제·백업을 유지한다. 보관한 PDF는 권한 만료로 지우거나 잠그지 않는다. 명시적 검증 거절/환불·권한 철회 확인은 신규 유료 진입을 즉시 막고, 네트워크 장애는 유효한 서명 캐시의 최대 24시간 안에서만 임시 사용을 허용한다. 수신 시 단조시간과 부팅 횟수를 함께 검사하므로 재부팅 후에는 온라인 재확인이 필요하다. 오프라인 중 새 환불을 즉시 감지할 수는 없다. 이 동작의 통합 검증 결과는 QA 보고서로 확인하며 실제 Play 거래 검증은 별도로 남아 있다.

## 현재 빌드 설정과 활성화 구분

소스에는 `INTERNET` 권한과 Play Billing이 있다. 앱의 자체 네트워크 목적은 결제 확인이며 기록·미디어 분석 서버는 없다. `JIGEUM_PLAY_VERIFY_URL`·`JIGEUM_PLAY_ENTITLEMENT_PUBLIC_KEY` 기본값은 비어 있어 설정 없는 빌드는 구매를 열거나 유료 권한을 부여하지 않는다. 무료 기능은 유지한다. 배포용 결제 설정을 활성화하면 위 전송 흐름을 기준으로 최종 선언을 작성해야 한다.

- **전송 보호:** 앱의 검증 URL은 HTTPS만 허용하고 리다이렉트에 구매 토큰을 따라 보내지 않는다. Manifest는 cleartext 전송을 비활성화한다. 검증 API의 실제 HTTPS 경계는 배포 후 확인해야 한다.
- **삭제:** 앱 기록의 개별/전체 삭제, 전체 삭제 시 월령·표현 이력 및 마이그레이션 복구 사본 정리. 아직 공유 화면에 전달하지 않은 공유 파일도 정리한다. 이미 전달한 파일은 수신 앱의 늦은 읽기를 위해 별도 캐시에 남으며, 전달 후 24시간이 지나면 다음 앱 시작·공유·기록 삭제 때 정리 대상이다. 최대 20개·64MiB 상한에서는 기존 파일을 지우지 않고 새 공유를 거절한다. Android 캐시 회수 시 더 일찍 사라질 수 있고 앱 미실행 시 다음 정리까지 남는다. 앱 데이터 삭제·앱 제거로 캐시를 지운다. 외부에 저장·공유한 파일은 사용자가 그 위치에서 삭제한다.
- **백업:** OS 자동 백업·기기 이전 제외 규칙을 사용한다. 모든 제조사 도구의 동작 검증은 별개다. 무료 JSON 백업은 사용자가 직접 관리한다.
- **계정:** 앱 회원가입/로그인은 없다. Google Play 계정은 결제·복원에 사용된다. 앱 계정 삭제와 Google 계정/구매 기록 삭제를 혼동하지 않는다.
- **기타 SDK:** 광고·행동 분석·앱 로그인 SDK는 없다. MediaPipe/YAMNet은 기기 내 추론에 사용한다.
- **SDK 자체 진단:** MediaPipe Tasks에는 앱/작업 이름·처리 지연·처리 횟수 등의 성능 진단 경로가 있으며 확인한 payload에 원음/영상/랜드마크/아기 기록은 없다. Billing도 자체 진단을 같은 CCT DataTransport로 전달한다. 현재 APK는 ACCESS_NETWORK_STATE를 제거해 CCT decorate 단계의 네트워크 상태 조회가 실패하고 저장/HTTP 전송 전 중단한다. SDK transport DB는 초기화되지만 시험 종료 후 events/transport_contexts는 비어 있었다. 빈 DB만으로 모든 네트워크 미전송을 보장하지 않는다. 공식 opt-out 구현은 아니며 SDK/권한 변경 시 다시 검증해야 한다.
- **대상 사용자:** 성인 보호자. 실제 스토어 소재·UI·마케팅과 Play 대상 연령 설문을 일치시킨다.

## 출시 전에 남은 확인

최종 패키지의 권한/SDK와 네트워크를 검증하고 실제 Google Play 구매·복원·환불·보류 상태를 시험한다. 공개 방침 URL·운영자 정보·배포 제공자/접근 로그/보존 정책을 확정한 뒤 Play의 데이터 유형·수집·공유·일시 처리 정의에 맞춰 답한다. 이 항목들은 현재 작업에서 제출하거나 배포하지 않는다.

**표현 한계:** 일반 소리·얼굴 형태 단서와 보호자 상황을 바탕으로 유한한 문장 예시를 제공한다. ‘울음 원인 정확 번역’, ‘배고픔/졸림 진단’, ‘발달 이상 판별’, ‘모든 엔진 결합으로 검증된 정확도’라고 설명하지 않는다.
