# 지금 내 기분이 그래 0.2.1 설치 안내

이 파일은 **Android 휴대전화에 설치해 시험하는 디버그 APK** 안내입니다. Play 스토어 공개 버전은 아닙니다. Android 8.0 이상이 필요하고, 마이크·카메라 기능에는 해당 하드웨어와 권한이 필요합니다. 로그인, 가입, API 키, 인터넷 연결은 필요하지 않습니다. 모델이 내장돼 APK가 약 **70 MiB**입니다.

## 설치

1. 휴대전화에서 [Jigeum-Android-debug-0.2.1.apk](Jigeum-Android-debug-0.2.1.apk)를 다운로드하거나 파일로 옮긴 뒤 엽니다.
2. Android가 설치를 막으면 **이 파일을 연 앱**(예: 파일 앱 또는 브라우저)에 한해 `이 출처의 앱 설치 허용`을 켭니다. 설치를 마친 뒤 원하면 해당 허용을 다시 끌 수 있습니다.
3. 설치를 눌러 완료한 뒤 앱 목록에서 **지금 내 기분이 그래**를 엽니다.

**기존 버전과 서명이 달라 설치가 거부되면:** Android는 같은 설치 식별자의 앱을 다른 서명으로 덮어쓸 수 없습니다. 기존 앱을 제거하면 그 안의 기록과 월령 선택이 함께 삭제됩니다. 앱에는 기록 내보내기가 없으므로 필요한 문장을 먼저 직접 적거나 화면을 보관하세요. 기록을 보존해야 한다면 기존 앱을 제거하지 말고 개발자에게 동일 서명의 설치 파일을 요청하세요. 자동으로 제거하거나 데이터를 지우는 설치 절차는 없습니다.

## 첫 사용

1. **소리로 살펴보기:** 녹음을 시작하고 마이크 권한을 허용합니다. 최대 10초 뒤 멈추며, 보호자가 실제 들은 `울음`, `웃음`, `옹알이`, `기타 소리`를 확인합니다. 녹음 없이 직접 고를 수도 있습니다.
2. **영상으로 살펴보기:** 카메라를 켜거나 저장된 30초·50MB 이하 영상을 고릅니다. 저장 영상의 최대 5개 장면과 첫 최대 10초 소리를 기기 안에서 살펴봅니다. 후보가 보여도 영상을 직접 듣고 소리를 확인합니다.
3. **상황 선택:** 직전에 수유·수면·놀이 등 무엇을 했는지 고릅니다. 소리나 화면만으로 아기의 뜻을 알 수 없어서 보호자의 확인이 필요합니다.
4. **문장 확인:** 가능한 표현 예시 중 하나를 고르거나 우리 아이 말에 맞게 수정한 뒤 기록에 저장합니다. 기록 화면에서 항목을 지울 수 있고, 돌봄 화면에서 전체 기록을 삭제할 수 있습니다.

앱은 원본 녹음이나 선택한 영상 파일을 기록에 저장하거나 서버로 전송하지 않습니다. 문장은 아기의 감정·욕구·건강을 판정한 결과가 아닙니다. 문제가 생기면 [0.2.1 QA 문서](Jigeum-QA-0.2.1.md)의 알려진 제한을 확인하세요. 지원 이메일은 **`[미정]`**, 공개 개인정보처리방침 URL은 **`[미정]`**입니다.
