## 문장과 분석

0.5.9는 화면·PNG·새MP4·기록에 `예상한 아기말`과 실제 근거를 표시한다. 무료는 소리 기반이다. 유료/베타에서도 실제 시각 특징이 문장에 기여한 경우만 `소리와 표정`으로 표시하며, 그렇지 않으면 소리 기반이다. 보호자 수정/과거 출처 미기록을 별도 표시한다. 기존JSON1 읽기와 DB1 이전을 유지하고 새JSON2를 내보낸다. 구버전으로 새JSON2 가져오기/DB2 다운그레이드는 지원하지 않는다.

음성이 보류되어도 요청한 영상 관찰은 제공한다. 충분한 소리 근거와 유효 단일 얼굴 표본2개가 있을 때만 입 모양에 어울리는 응답 요청 문구를 추가한다. 얼굴 주인·실제 립싱크·욕구를 판정하지 않는다. 현재 모델·음성 임계값은 유지하며 사용자 제공 두 영상의 발성 누락은 미해결이다.

YAMNet은 소리 사건을 분류한다. 영아 울음·Babbling·Baby laughter의 시간별 단서나3개 창 이상의 어린 말소리 후보가 부족하거나 무음·모델 실패인 경우 한마디를 만들지 않는다. 얼굴만 보인다는 이유로 아기말을 만들지 않는다. 일반 웅성거림(speech babble)은 Babbling과 구분한다. 웃음/울음 충돌은 양방향으로 검사하고, 혼합 소리는 중립 대사 또는 보류로 처리한다. 비명만으로 부정 감정을 정하지 않는다. 어린 말소리는 아기 신원·연령을 인증하지 않으며 TV/다른 아이 소리도 섞일 수 있다.

분석에는 DC/80Hz 저주파 잡음 필터를 적용하고 같은 필터 결과로 음량·리듬을 계산한다. 재생은 원본이다. 자동 볼륨 증폭·작은 소리 절단·TV/보호자 화자 분리는 하지 않는다.

10초 초과 구간은 여러 시간 창의 발성 근거가 충분히 이어지고 활동량 조건을 충족할 때만 긴 표현을 제공한다. 침묵·무관한 소리를 덧붙여 문장을 늘리지 않는다. 선택 시간이 길다는 이유로 문장 수나 정확도를 비례해 보장하지 않는다.

소리 유형과 연속성에서 허용되는 문장군을 고른 뒤, 입력에서 만든 임시 키로 동의미 표현을 고른다. 키는 뜻을 해석하는 모델이 아니며 저장·전송하지 않는다. 같은 입력은 같은 결과, 다른 입력에도 유한한 문장 풀이므로 반복은 가능하다. 대사를 바꾸기 위해 욕구를 임의로 바꾸지 않는다. ‘배고픔·졸림·아픔’ 판독 성능이 검증된 앱으로 소개하지 않는다.

흥미·정겨움과 상황 적합성이 제품 기준이다. 어른용 돌봄 안내는 아기 대사와 분리한다. 흥미를 위한 캐릭터화가 있다는 사실을 숨기지 않는다. 실사용 상황 적합성·자연스러움·유료 가치 평가는 아직 별도 gate다.

## 결제와 복원

기존 SKU `jigeum_album`, base plans `monthly`, `three-month-prepaid` 유지. 월4,900원·3개월12,900원은 조사 제안이며 실제 등록/거래 완료 가격이 아니다. 앱은 Google Play 응답 가격·기간·갱신 조건만 표시한다. 상품 등록·실거래 검증은 사용자 요청으로 현재 보류한다.

앱 로그인 없이 같은 Google Play 계정의 유효 구매를 복원한다. 기록 복원은 JSON 백업으로 별도 진행한다. 다른 가족 계정에 권한을 자동 공유하지 않는다.

## 만료·장애와 기존 결과

- 실제 실행 시 `BillingManager.hasCurrentEntitlement()` 사용. 구매 콜백·PENDING·화면 Boolean만으로 열지 않는다.
- 긴 촬영·가져오기·10초 초과 분석·시각 관찰은 실행 시 현재 이용권을 확인한다. 긴/시각 분석 시작 전·진행 중·결과 반환 시 권한을 확인하고, 만료되면 취소하며 늦은 결과를 버린다. 선택 클립은 그대로 두고 10초 이내 구간의 무료 소리 분석을 계속할 수 있다.
- 이미 만들어진 한마디의 수정·저장과 기존 기록·공유·백업은 무료다. 유효 권한으로 시작한 PDF는 완료할 수 있다.
- 서명 캐시는 최대24시간 또는 실제 만료 중 빠른 시각까지다. 재부팅 뒤 온라인 재확인이 필요하다. 명시적 거절/환불은 차단하며, 오프라인 중 새 환불은 확인 또는 만료까지 반영이 지연될 수 있다.
- 결제 서버 장애와 아기 소리 분석은 별개다. 촬영·재생·소리 모델·기록은 기기 안에서 실행한다.

## 개인 미디어

촬영한 원본은 앱의 비공개 `cache/captures`에서 재생·분석하는 동안만 보관한다. 이 폴더는 FileProvider 공유 경로 밖이다. 화면 닫기·다시 촬영 시 삭제하고, 비정상 종료 뒤 남은 파일은 다음 앱 실행 시 정리한다. 기존 저장 영상을 가져오면 원본을 복사·수정하지 않고 선택한 URI만 일시 읽는다. 외부 파일 공급자의 다운로드는 공급자 동작에 따른다.

결과를 보는 것만으로 앱 기록을 자동 생성하지 않는다. ‘영상·소리 함께 보관’은 보관할 내용의 선택이며 실제 저장은 ‘장면과 함께 저장하기’ 버튼을 눌렀을 때 시작한다. 문장·날짜·관찰 요약·메모는 휴대전화 내부 SQLite에, 선택 구간의 영상·실제 소리·최종 문장 MP4는 앱 비공개 파일 영역에 보관한다. ‘이 문장 저장하기’는 미디어 없이 문장 기록만 보관한다. 전체 촬영 임시 원본은 화면을 닫거나 재촬영하면 삭제하고 비정상 종료 뒤 남은 파일은 다음 실행에서 정리한다. 가져온 기존 영상의 원본은 수정·삭제하지 않는다.

결과 화면의 앨범 저장 버튼은 별도의 PNG/MP4 사본을 만들며 앱 기록을 자동 생성하지 않는다. 기록에서 앨범 저장을 누르면 보관한 내부 미디어를 읽어 앨범 사본을 만든다. 앱 기록 삭제/앱 제거는 내부 기록과 미디어를 삭제하지만 앨범·내려받기·공유 사본은 별도로 남는다. 앱 내부 DB·파일·설정은 Android 자동 백업/기기 전송에서 제외하도록 설정했고 사진 앱의 클라우드 백업은 해당 앱 설정을 따른다. JSON·CSV·PDF에는 미디어가 없으며 별도로 MP4를 보관해야 한다. 앱 로그인·외부 아기 DB·원본 자동 업로드를 추가하지 않는다. 결제·심사 확인 요청만 기존 무상태 HTTPS 서버로 보낸다.

## 비공개 테스트와 현재 검증 상태

사용자는 비공개 테스트 앱 등록·버전 업로드·검토 제출·참여 링크와 테스트 기간 전체 기능 개방을 승인했다. beta23 업데이트의 실제 제출/게시 상태는 아래 Play 상태를 따른다. Google 그룹 공개 가입과 Play 연결은 적용됐다. [현재 상태](../docs/release/20261003/PLAY-STATUS.md) / [초대 안내](../docs/release/20261002/TESTER-INVITE.md). 실제 외부 회원 Play 참여/설치·최소12명/연속14일·프로덕션 액세스 신청은 별도다. 상품 등록·실제 거래·공개 프로덕션은 보류한다.

전체 Android 계측 **281통과/0실패/3명시제외**, 호스트 게이트30통과, beta/release lint 각각 오류0/기존경고20이다. [최신 보고서](../docs/qa/sound-visual-0.5.9/README.md)에 서명 UI·업데이트·패키지 결과와 첫 실패/수정/재실행 증거를 보존한다. 공개 소리22개는 기존판정과 같고 strict 선언라벨4불일치는 남아 있다. 실제 Play split/자동 업데이트·ARM/OEM·의도 정확도/유료 가치를 이 수치로 대신하지 않는다. 이전 버전 증거는 해당 버전 기준본이다.

0.4.5의 과거 통과를 0.5 통과로 재사용하지 않는다. 새 버전의 실제 실행·패키지 근거는 새 QA 보고서를 따른다. 로컬/에뮬레이터 QA는 실기기·부모 사용성·실제 Play 거래·공개 출시 완료를 의미하지 않는다. 구체 의도 판독과 유료 가치는 단순 문구 추가만으로 검증되지 않는다.
