지원 이메일: **bsfire1237@gmail.com**. 공개 운영자명은 사용자가 확정한 **최용우**다. 과거 콘솔 표시명 추정값을 운영자명으로 사용하지 않는다.

0.4.0 목표의 전체 이용권은 위 표의 카메라·영상·PDF 기능을 한 번에 연다. 카메라권·영상권·PDF권을 따로 팔지 않는다. 향후 아직 없는 기능, 모션 앨범, 가족 클라우드, 개인화 학습, 더 높은 의도 정확도를 혜택으로 약속하지 않는다.

무료의 ‘횟수 제한 없음’은 일일 이용권·크레딧을 차감하지 않는다는 뜻이다. 저장 공간과 처리 상한은 그대로 적용한다. 로컬 기록 최대 10,000건, 입력 영상 30초·50MB, PDF 한 권 최대 300개 기록·300쪽은 기술상 한도이며 추가 결제로 해제하는 제한이 아니다.

## 2. 결제 상품과 표시 금액

| 선택 | 한국 가격 제안 | 청구 방식 | 열리는 기능 |
|---|---:|---|---|
| 월간 전체 이용권 | 4,900원 | 매월 자동 갱신. Google Play에서 해지 | 카메라·저장 영상·월별 PDF 전체 |
| 3개월 전체 이용권 | 12,900원 | 1회 선불 결제. 자동 갱신 없음 | 같은 전체 기능을 3개월 이용 |

가격은 시장·비용·지불 의사를 검증할 제안이다. 앱 버튼에는 Google Play가 반환한 실제 가격과 기간만 표시한다. 상품을 불러오지 못했을 때 제안 가격으로 결제 버튼을 대신 만들지 않는다. 월 환산값보다 결제 총액과 자동 갱신 여부를 먼저 보여 준다. 무료 체험의 자동 유료 전환·주간권·연간권·평생권·추가 소모성 상품은 현재 범위에 없다.

회원가입은 필요하지 않다. 결제와 구매 복원은 Google Play 계정을 사용한다. 같은 Play 계정의 구매 복원은 기록 복원이 아니며, 다른 가족의 Google 계정에 권한이 자동 공유된다고 안내하지 않는다. 기록 이동은 사용자가 보관한 JSON 백업으로 진행한다.

## 3. 만료·해지·오류 상태별 동작

| 상태 | 새 유료 작업 | 진행한 결과·기존 기록 | 사용자 안내 |
|---|---|---|---|
| 유효한 구매와 서명된 이용권 확인 | 허용 | 무료 편집·저장·조회·공유 계속 | 유효한 이용권과 기능 표시 |
| 유료 기간 만료 | 차단 | **이미 생성된 문장 초안·저장 기록의 편집·저장은 무료**. 진행 중 카메라/영상은 중지; 유효할 때 생성을 시작한 PDF는 완료 허용 | 갱신/복원 선택과 무료 계속 사용 경로 |
| 월간 자동 갱신만 해지, 이미 결제한 기간 유효 | 남은 유효기간 동안 허용 | 유지 | 다음 갱신 중단과 현재 만료일을 구분 |
| 환불·취소로 권한 철회 또는 명시적 검증 거절이 확인됨 | 즉시 차단하고 기존 이용권 캐시로 우회하지 않음 | 이미 생성된 문장 초안의 무료 편집·저장과 기존 기록은 유지 | 구매 상태 재확인/지원 경로 |
| 결제 대기·보류 또는 구매 완료 미확인 | 새 권한을 부여하지 않음 | 무료 기능·기존 기록 유지 | Google Play에서 완료 여부 확인 |
| 네트워크/서버 일시 장애·오프라인 | 이미 확인한 서명이 아직 유효하면 그 기간 안에서만 허용. 유효 캐시 없으면 차단 | 무료 기능·기존 기록 유지 | 일시 확인 실패와 구매 거절을 구분 |
| URL·공개 키·상품 설정 없음 | 구매와 새 유료 작업을 열지 않음 | 무료 기능·기존 기록 유지 | 실제 연결을 기다리는 상태로 안내 |

### 오프라인 허용의 한계

서명된 이용권은 발급 후 **최대 24시간 또는 구독 만료 중 빠른 시각**까지만 사용할 수 있다. 일시적인 네트워크 실패를 환불로 단정하지 않고, 명시적인 거절을 일시 장애로 취급해 유료 권한을 계속 열어 두지도 않는다.

오프라인 상태에서 새로 발생한 환불·권한 철회를 즉시 알 수는 없다. 기존 유효 캐시 기간에 반영이 지연될 수 있으며, 재확인에서 거절을 받으면 바로 신규 유료 진입을 막는다. ‘환불은 모든 기기에 즉시 반영’ 또는 ‘영구 오프라인 구매 보장’이라고 안내하지 않는다.

### 작업 시작과 결과 저장

0.4.0에서는 카메라 관찰·영상 분석·PDF의 **새 작업 시작 시** 권한을 확인한다. 카메라/영상 화면에서 권한이 만료되면 캡처·분석을 중지하고, 늦게 돌아온 분석 응답이 이용권 화면을 덮거나 새 문장을 만들지 않게 한다. 시작했다는 이유만으로 모든 분석 완료를 보장하지 않는다.

**이미 생성된 문장 초안과 저장 기록**은 무료로 고치고 저장할 수 있다. PDF는 유효한 권한을 확인하고 실제 생성을 시작했다면 도중에 만료되어도 완료를 허용한다. 만들어 보관한 PDF는 이용권 만료로 삭제하거나 읽기를 잠그지 않는다. 앱의 임시 공유 캐시 정리와 사용자가 외부 위치에 보관한 파일은 구분한다. 만료 후 새 촬영·분석·PDF 생성은 차단한다. 화면을 열어 둔 것만으로 유료 권한을 유지할 수 없어야 한다.

## 4. 결제 유도와 표현의 원칙

- 홈의 주 행동은 무료 녹음/직접 입력이다. 처음 실행부터 결제를 요구하지 않는다.
- 카메라·저장 영상·PDF를 고른 지점에 기능 범위와 전체 이용권을 설명한다. 제한을 숨긴 채 촬영·분석부터 시키지 않는다.
- 이용권 화면에는 세 유료 기능과 무료 유지 범위를 함께 보여 주고, 닫기·무료 계속 사용·구매 복원·구독 관리·약관/방침 경로를 제공한다.
- 결과 흐리기, 저장 직전 잠금, 정확도 상향 암시, 무료 기록 만료, 아기의 불안이나 부모의 죄책감을 자극하는 판매 문구를 사용하지 않는다.
- 무료와 유료 모두 보호자가 확인·수정하는 표현 예시다. 카메라와 영상은 입력 방식과 관찰 편의를 늘리며 영아 의도를 더 정확히 안다는 보증이 아니다.
- 문장 후보는 조합별 16개 표현에서 최근 9개를 피하는 유한한 구성이다. 무한 생성·영구 무반복·사용할수록 아기의 마음을 학습한다고 약속하지 않는다.

## 5. 저장·통신·운영

기록은 기기 내 SQLite에 저장하고 앱 계정·외부 아기 기록 DB·자동 가족 동기화는 사용하지 않는다. 원본 녹음·카메라 프레임·선택 영상을 운영자 서버로 보내지 않는다. 사용자가 선택한 백업·공유 대상 서비스의 처리는 별도다.

결제 확인에는 Google Play Billing과 최소 검증 API가 필요하다. HTTPS 요청에는 패키지명·상품 ID·구매 토큰·무작위 설치 식별자를 사용하며 아기 기록은 포함하지 않는다. 검증 서비스의 실제 연결·운영 검증과 Play 상품 설정은 별도 완료 사항이다. 테스트용 상태나 로컬 모의를 실제 구매 성공으로 보고하지 않는다.

### 출시 전에 확인할 항목 — 이번에 제출하지 않음

1. 최종 빌드에서 무료/유료 진입, 만료 중 카메라/영상 중지와 늦은 응답 폐기, 기존 초안 저장, PDF 진행 완료, 명시적 거절과 오프라인 유효기간을 검증한다.
2. 실제 Google Play 상품 가격·기간·갱신 여부와 구매/복원/보류/해지/환불 흐름을 확인한다.
3. 검증 API 주소·서명 키·실제 인프라 로그·보존 정책을 확정하고 비밀키를 앱에 포함하지 않는다.
4. 확정 운영자명 최용우와 지원 이메일을 반영하고 약관·개인정보처리방침의 시행일과 공개 URL을 확정한다.
5. 스토어 문구·스크린샷·상품 화면의 무료/유료 표시가 이 정책과 일치하는지 확인한다.
