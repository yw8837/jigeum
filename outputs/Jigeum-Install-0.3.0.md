# 지금 내 기분이 그래 0.3.0 설치 안내

설치 파일: **Jigeum-Android-debug-0.3.0.apk** · Android 8.0 이상 · 약 77.6 MiB.

## 설치

1. APK를 Android 휴대전화로 옮기고 파일을 엽니다.
2. 휴대전화가 요청하면 사용한 파일 앱의 ‘이 출처 허용’을 켜고 설치합니다. 설치 후에는 해당 허용을 다시 꺼도 됩니다.
3. 앱 이름 **지금 내 기분이 그래**로 실행합니다. 회원가입 없이 사용할 수 있습니다.

이전 0.2.1과 서명이 같으면 업데이트 설치할 수 있으며 기록은 SQLite로 이전됩니다. 실제 0.2.1 기록을 만든 뒤 0.3.0으로 업데이트하는 시험을 통과했습니다. 서명이 다르면 업데이트가 거절됩니다. 기존 앱을 삭제하면 기록도 삭제되므로 무작정 삭제하지 말고 먼저 기록을 보존하세요.

## 첫 사용

1. ‘소리로 번역하기’, ‘카메라로 살펴보기’, ‘저장된 영상 가져오기’ 중 하나를 선택합니다. 녹음 없이 직접 입력할 수도 있습니다.
2. 들은 소리와 수유·수면·놀이 등 실제 상황을 확인합니다.
3. 아이 시점의 표현 예시 3개 중 하나를 선택하거나 직접 고친 뒤 저장합니다.
4. ‘기록’에서 무료 문장 카드 공유, ‘돌봄’에서 JSON 백업·가져오기를 사용할 수 있습니다.

마이크·카메라 권한은 해당 기능을 켤 때만 요청합니다. 저장 영상은 30초·50MB 이하이며 첫 최대 10초의 소리와 최대 5개 프레임을 살펴봅니다. 원본 영상·음성은 서버에 보내지 않습니다.

## 이번 빌드의 범위

- 무료 문장 생성·편집·기록·PNG 공유·JSON 백업/복원은 사용 가능합니다.
- 아기말북 화면과 PDF 생성기는 구현했으며 렌더러 시험을 통과했습니다. **운영 결제 설정이 없는 이번 APK에서는 실제 구매와 유료 활성화가 불가능합니다.**
- 문장은 검수된 유한한 표현 조합입니다. 최근 반복을 줄이지만 장기간 사용하면 다시 나올 수 있습니다. 아기의 의도를 정확히 번역하거나 건강 상태를 판정하지 않습니다.
- 기록은 기기에 저장됩니다. 앱 삭제·기기 분실에 대비해 직접 JSON 백업을 보관하세요. 운영체제 자동 백업과 기기 전송은 앱 설정에서 제외했습니다.
- API 35 x86_64 에뮬레이터에서 검증했습니다. 실제 ARM 휴대전화, 실제 Play 구매·복원·환불은 아직 검증하지 않았습니다.

이 APK는 개발 서명 설치 시험용입니다. Play 제출용 파일은 아닙니다. 미서명 AAB는 빌드 검토 자료로 함께 제공하며 출시·제출은 이후 진행합니다.
