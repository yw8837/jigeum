1. 기기 안에 보관하는 정보

이 앱은 6~18개월 아기의 성인 보호자를 위한 관찰·표현·기록 서비스입니다. 회원가입이나 앱 로그인 없이 사용합니다. 보호자가 저장한 표현 문장과 메모, 기록 시각, 분석한 구간의 시간, 입력 경로와 소리 분류 요약은 기기 안에 저장합니다. 월령이나 소리·상황을 직접 선택하도록 요구하지 않으며 별도의 반복 표현 이력을 만들지 않습니다. 이전 버전의 기록이나 가져온 백업에 들어 있는 월령·선택 항목은 기록 호환을 위해 기기 안에 남을 수 있습니다. 기록 가져오기의 중복을 막기 위한 정보도 기기 안에서만 관리합니다. 외부 아기 기록 DB, 자동 업로드, 가족 클라우드 동기화는 없습니다. 아기 이름·정확한 생년월일·연락처를 요구하지 않습니다.

2. 마이크·카메라·선택한 영상

보호자가 시작할 때 무료는 최대 1분, 전체 이용권은 최대 2분 녹화·녹음합니다. 재생과 구간 선택을 위해 원본을 앱의 비공개 임시 폴더에 보관하고, 화면 종료·재촬영 시 삭제합니다. 비정상 종료로 남은 파일은 다음 앱 실행 시 정리합니다. 저장 영상은 무료 1분·100MB 이하, 전체 이용권 2분·200MB 이하까지 가져올 수 있습니다. 가져온 원본은 복사·수정하지 않고 일시적으로 읽습니다. 파형 표시와 선택한 구간의 소리 분석도 기기 안에서 처리합니다. 선택 구간은 무료 1~10초, 전체 이용권 1~20초이며, 시각 관찰은 전체 이용권으로 선택할 수 있습니다. 원본은 기록·백업·공유에 포함하지 않으며 운영자 서버로 전송하지 않습니다. 선택한 파일 제공자의 클라우드 이용에는 해당 제공자 정책이 적용됩니다.

앱이 관리하는 임시 소리 버퍼는 사용 후 초기화합니다. 운영체제나 모델 SDK의 내부 메모리까지 즉시 완전 삭제한다고 보장하지는 않습니다. MediaPipe와 Play Billing SDK의 성능 진단 경로는 현재 네트워크 상태 권한 구성에서 전송 전 실패하는 것을 확인했으나 공식 수집 해제 기능을 적용한 것은 아닙니다. SDK·권한을 바꾸면 이 경로를 다시 검토합니다. 광고·행동 추적 SDK는 없습니다.

3. 보호자가 선택하는 백업·공유

JSON 백업·CSV에는 기록과 메모가 포함됩니다. PNG 카드에는 메모를 넣지 않으며 PDF 메모 포함은 기본적으로 꺼져 있습니다. 파일은 보호자가 시스템 저장·공유 화면에서 고른 위치나 앱에 전달합니다. 다른 앱·클라우드가 파일을 처리하는 경우 해당 서비스 정책이 적용됩니다. 자동 공유는 없습니다. 아기 기록을 외부 서버에서 복구할 수 없으므로 필요한 백업은 보호자가 보관해야 합니다.

4. 결제 확인을 위한 통신

전체 이용권의 상품 조회·결제·구매 복원에는 Google Play를 사용합니다. 결제 수단과 Google 계정 정보는 Google Play가 처리하며 운영자가 카드 정보를 받지 않습니다. 구매 확인을 위해 앱 패키지명, 상품 ID, Play 구매 토큰, 앱 설치별 무작위 식별자를 HTTPS로 검증 서비스에 전송합니다. 서비스는 Google Play에서 구매 상태·기간을 확인하고 설치에 묶인 서명 이용권을 돌려줍니다. 아기 소리·영상·얼굴 정보·문장·기록·메모는 이 통신에 포함되지 않습니다.

Play 심사 접근을 선택한 경우 심사 코드와 설치 식별자를 HTTPS로 전송해 심사 이용권을 확인합니다. 심사 코드는 기기 안에서 암호화 보관하며 해제 시 삭제합니다. 심사 코드를 통한 접근은 구매나 구독 가입이 아닙니다.

운영자는 구매 토큰·설치 식별자·심사 코드를 DB·파일·요청 본문 로그에 보관하지 않습니다. 검증과 과다 요청 제한에 필요한 일시 상태는 서버 메모리에서만 처리합니다. 기기에는 설치 식별자, 서명 이용권, 최대 24시간 확인에 필요한 시각·경과시간·부팅 횟수와 구매 확인값을 보관합니다. 원본 구매 토큰을 앱에서 따로 영구 저장하지 않습니다.

5. 처리 제공자와 보관 기간

검증 서비스의 처리 제공자는 Google Cloud이며 서울 리전에서 실행합니다. Google Cloud Logging의 접속 로그에는 IP 주소, 요청 경로, 응답 상태, 처리 시간이 포함될 수 있고 보관 기간은 30일입니다. 요청 본문·구매 토큰·설치 식별자·심사 코드는 접속 로그에 쓰지 않습니다. 운영·보안에 필요한 로그만 사용하고 광고·사용자 행동 분석에 이용하지 않습니다. Google의 서비스 운영·보안 처리와 기본 글로벌 로그 저장에 따라 정보가 국외에서 처리될 수 있습니다. 제공자는 Google LLC(미국), 목적은 HTTPS 검증 서비스 제공과 장애·보안 대응, 전송 시점은 해당 기능을 사용하는 때입니다. 관련 문의는 운영자에게 접수할 수 있습니다. 국외 처리에 관한 자세한 제공자 정보는 Google Cloud 개인정보 안내를 참고하세요. Google Play의 계정·결제 정보 보관 및 삭제에는 Google의 정책이 적용됩니다.

6. 삭제와 이용자 권리

기록 화면에서 개별 기록을 삭제하고 돌봄 화면의 ‘모든 기록 삭제’로 전체 기록을 삭제할 수 있습니다. 전체 삭제에는 호환을 위해 보관한 이전 월령 값과 기록 가져오기 정보도 포함됩니다. 앱 데이터 삭제·앱 제거로 기기 내 정보와 캐시를 제거할 수 있습니다. Android 자동 백업·기기 이전에서는 앱 데이터를 제외하도록 설정했으나 모든 제조사의 별도 도구를 검증한 것은 아닙니다. 운영자가 아기 기록을 보관하지 않으므로 이메일로 기록을 보내지 않아도 됩니다.

공유 화면에 아직 전달하지 않은 작업 파일은 기록 삭제 시 정리합니다. 이미 전달한 파일은 수신 앱의 읽기를 위해 별도 캐시에 남습니다. 전달 후 24시간이 지난 파일은 다음 앱 시작·공유·삭제 시 정리 대상이며 앱을 실행하지 않으면 남을 수 있습니다. 캐시는 최대 20개·64MiB로 제한합니다. 외부에 저장하거나 공유한 파일은 해당 위치에서 직접 삭제해야 합니다. 앱 기록 삭제는 Google Play 구독 해지가 아닙니다.
