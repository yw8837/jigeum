**로컬 구현·통합 빌드·QA를 완료했다.** 실제 Google Play 거래, ARM 실기기, 운영 서버 연결은 미검증이다. 공개 출시·제출은 사용자 요청대로 보류한다. 현재 설정 없는 APK는 무료 기능을 사용할 수 있으며 유료 기능은 이용권 안내로 연결된다. 실제 구매가 가능한 출시 빌드는 아니다.

## 발견·수정·재검증

1. **접근 경계:** 표시 Boolean만 믿는 경로를 제거하고 신규 진입·화면 복원·권한 응답·URI 반환·분석 시작/완료·PDF 실행 시 실제 권한을 확인한다. 세션 세대가 다른 늦은 응답은 폐기한다.
2. **사용 중 만료·상태 보존:** 카메라/영상 작업은 종료하며 이미 만든 초안·앨범 월/표지/메모는 유지한다. 구매 후 자동 촬영하지 않고 사용자가 계속하기를 선택한다.
3. **오프라인 기한:** 기기 시계 되돌림으로 권한 캐시가 연장되는 경로를 단조시간·부팅 횟수로 막았다. 재부팅·legacy/손상 캐시는 온라인 재확인이 필요하다. 10개 시간 판정 시험을 통과했다.
4. **큰 글꼴:** 스크롤한 글자가 시스템 상태바 영역에 그려지던 문제를 viewport clipping으로 수정했다. 최종 200% 글꼴 캡처와 작은/넓은 화면을 확인했다.
5. **시험 하네스:** JVM setter와 동명 helper 충돌은 테스트 helper 이름을 변경해 빌드를 복구했다. am kill이 최근 화면 프로세스를 유지하는 경우에는 검증한 PID와 앱 UID에 한정해 종료한다. 원래 실패 로그와 재실행 결과를 보존했다.
