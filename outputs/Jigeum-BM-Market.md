# 아기말 앱 BM·시장 진입안

작성일: 2026-09-30 · 앱 이름 **지금 내 기분이 그래** (스토어·상표 확인 전)

## 1. 누구의 어떤 순간을 해결하는가

핵심 이용자는 6~18개월 아기의 엄마·아빠다. 아기가 옹알이하거나 울고, 표정·몸짓을 보일 때 보호자는 “지금 무엇을 원하지?”를 묻는다. 앱의 첫 가치는 정답 판정이 아니라 **짧은 입력 뒤 아이 시점의 자연스러운 한마디를 읽고, 실제 상황에 맞게 고치는 경험**이다. 결과가 돌봄 행동으로 이어질 수 있으므로 관찰 단서, 보호자가 제공한 상황, 문장 예시를 구분한다.

Android 0.2.1 직접 설치 후보는 10초 마이크 녹음, 후면 기본·전후면 전환 카메라, 또는 기기에서 선택한 30초·50MB 이하 영상 → 보호자 맥락 선택 → 가능한 문장 3개 → 수정·로컬 저장 흐름이다. 영상 파일은 최대 5개 프레임의 얼굴·입 단서를 살펴본 뒤 첫 최대 10초의 소리 후보를 분석하며, 보호자가 직접 듣고 확인한다. YAMNet은 일반 소리 유형 후보, MediaPipe는 얼굴·입의 보이는 움직임만 제공한다. **배고픔·졸림·건강 상태를 모델이 판독한 결과가 아니다.**

## 2. 시장과 경쟁 구도

2025년 대한민국 확정 출생아는 **254,341명**이다.[1] 6~18개월은 길이가 12개월인 구간이므로, 출생 규모가 안정적이라고 단순 가정하면 특정 시점의 국내 대상 아기 가구는 대략 **25만 가구** 규모다. 출생 시기 변동, 쌍둥이, 보호자 수, 스마트폰 이용 가능성, 국내 외 사용자는 반영하지 않은 **거친 코호트 추정**이다. 이 숫자를 곧바로 유료 고객 수나 매출로 쓰지 않는다.

| 제품 | 공개된 가치·과금 신호 | 이 기획에 주는 뜻 |
|---|---|---|
| 바뱌 | 공식 사이트에서 10초 울음 입력, 상위 3가지 이유·대처법, 하루 무료 3회를 안내한다.[2] | 울음 원인 맞히기와 정면 경쟁할 이유가 약하다. 옹알이·영상 장면과 보호자 교정을 앞세운다. |
| Huckleberry | 무료, Plus, Premium의 층위와 수면·수유 기록 및 예측 기능을 공개한다.[3] | 기록 구독 수요는 있으나, 큰 육아 기록 앱을 MVP에 복제하지 않는다. |
| 베이비타임 | 수유·수면·기저귀 기록과 가족 공유를 제공한다.[4] | 기본 기록과 가족 공유의 기대 수준을 참고한다. 우리 앱의 공유는 사용자 선택 파일 내보내기로 기획한다. |

조사 근거·제품별 상세 비교·모델 한계는 [경쟁·기술 조사](./Jigeum-Research.md)에 모았다. 경쟁사의 다운로드, 유료 전환율, 매출은 검증 가능한 공개 자료를 확보하지 못해 추정하지 않았다.

## 3. 최신 BM 결정 — 온디바이스 저장 기준

상세 상품·가격·Hook Model·지표 정의·계산 가정은 [BM·리텐션·가격 실행안](Jigeum-BM-Retention-Pricing.md)을 기준으로 한다. 기존 가족 자동 동기화·공유 서버·무료 가구별 클라우드 비용 가정은 사용자 저장 정책에 따라 철회했다.

| 범위 | 결정 | 현재 상태 |
|---|---|---|
| 핵심 경험 | 소리·영상 → 표현 예시 → 수정 → 로컬 기록 전체 무료. 일일 인위적 횟수 제한·보상 광고 없음 | 0.2.1 구현 |
| 무료 보존·공유 | 기본 주간 요약·카드 공유·JSON/CSV 내보내기와 가져오기 | 후속 개발. 자동 동기화 없음 |
| 유료 가치 | 기기 내 자동 월별 아기말북·편집·인쇄용 PDF·테마·템플릿 모션 앨범 | 시제품과 반복 지불 의사 검증 필요 |
| 월 구독 | **4,900원**, 매월 자동 갱신 | 첫 가격 검증 가설, 결제 미구현 |
| 3개월권 | **12,900원**, 1회 결제·자동 갱신 없음 | 월 환산 4,300원. 실제 Play 상품 설정 검증 필요 |
| 보류 | 연간·주간·평생권 | 6~18개월의 사용 기간과 반복 가치가 먼저 |

기록·메모는 휴대전화에만 남긴다. 외부 DB·앱 자체 계정은 만들지 않는다. 사용자가 내보낸 카드·앨범은 다른 가족이 구독하지 않아도 열 수 있게 한다. 구매 권한은 결제한 Google Play 계정 기준이며 다른 계정에 자동 공유되지 않는다. 앱 삭제·분실 시 서버 복원은 불가능하고, 현 버전에는 파일 백업도 아직 없다.

핵심 문장을 읽기 전 결제를 요구하는 하드 페이월은 쓰지 않는다. 무료 기록은 만료되지 않고 해지 후에도 유지한다. 유료 제작 기능을 직접 선택한 시점에만 가격·총액·기간·갱신 여부를 명확히 보여 준다. 현재의 고정 문장 예시만으로는 구독의 반복 가치가 충분히 입증되지 않았다. 자동 앨범을 실제 부모가 다시 열어 보는지 확인한 뒤 결제를 출시한다.

가격·세금·수수료·환불·운영 예산의 민감도 계산은 상세 실행안에 단일화했다. 시장 규모와 전환율을 곱한 옛 매출 표는 수요 예측으로 오해되지 않도록 제거했다. 실제 결제 전환·리텐션·CAC는 아직 측정하지 않았다.

## 4. 획득과 검증 실험

1. **부모 인터뷰 20명:** 최근 일주일의 실제 “무슨 말이지?” 순간, 기존 대안, 입력·공유 거부 이유를 듣는다. 앱 시연 전 문제 빈도를 묻고, 시연 후 놀라움과 신뢰를 따로 측정한다.
2. **2주 파일럿 50가구:** 온디바이스 앱으로 번역 시작→문장 노출→문장 선택/수정→재사용 흐름을 확인한다. 원본 음성·영상은 연구용으로 자동 수집하지 않는다. 피드백은 별도 자발적 설문으로 받는다.
3. **메시지 실험:** `아기말 한마디`와 `소리·표정 기록` 두 표현을 동등한 랜딩/영상으로 시험한다. `배고픔을 정확히 번역`처럼 검증되지 않은 문구는 쓰지 않는다.
4. **채널:** 산후조리·육아 커뮤니티의 허용된 제품 테스트 모집, 소아과·발달 전문가의 문구 검토, 숏폼 광고의 소액 실험. 커뮤니티 게시 규칙과 광고 표기를 지킨다.

**승인 기준(초기 제안):** 첫 실행에서 번역 문장까지 도달한 비율 70% 이상, 결과를 “상황에 맞거나 대화 시작에 유용”하다고 평가한 비율 60% 이상, 2주 내 3회 이상 재사용 30% 이상, 의도를 정확히 판독한다고 오해한 비율 10% 미만. 이 수치는 팀의 학습용 의사결정 기준이며 임상적 정확도 지표가 아니다. 표본·조건·실패 사례를 함께 보고 다음 기능을 결정한다.

## 5. 다음 구현 순서

1. 실기기에서 마이크·카메라, 권한 거부, 소음, 다른 앱 마이크 점유, 저사양 성능을 검증한다.
2. 문장 후보의 어투를 부모 20명의 평가로 정리한다. `좋아요/틀려요`보다 `우리 아기에게는 이렇게 들렸어요`라는 교정 필드를 우선한다.
3. 같은 아기의 반복 표현을 저장·찾는 기능을 만든다. 개인화 모델을 쓰려면 독립 라벨·검증셋·삭제권을 먼저 갖춘다.
4. 기기 내 자동 앨범에 실제 지불 의사가 확인되면 Play 결제를 설계한다. 무료 핵심 흐름을 잠그는 결제 장벽은 도입하지 않는다.
