# 지금 내 기분이 그래 0.3.0 통합 검증본

**설치:** [Android APK](Jigeum-Android-debug-0.3.0.apk) · [설치 안내](Jigeum-Install-0.3.0.md) · [QA 보고서](Jigeum-QA-0.3.0.md)

앱 표시 이름은 **지금 내 기분이 그래**입니다. 6~18개월 아기의 보호자가 소리와 장면을 살펴보고, 직접 확인한 상황을 바탕으로 아이 시점의 표현 예시를 기록합니다. 기술 식별자 `com.moa.babylanguage`는 기존 시험 설치와의 연속성을 위해 유지합니다.

## 사용할 수 있는 기능

1. 최대 10초 소리 녹음, 전후면 카메라, 저장 영상(30초·50MB 이하), 녹음 없는 직접 입력.
2. 보호자가 소리·상황을 확인한 뒤 표현 예시 3개를 비교하고 수정·저장.
3. 기기 내 SQLite 기록, 무료 PNG 카드 공유, JSON 백업·가져오기, 주간 돌아보기.
4. 월별 아기말북 화면과 3종 표지. PDF 생성기는 구현·계측 검증했습니다.

**이번 APK는 운영 결제 설정이 없어 실제 구매와 유료 활성화가 불가능합니다.** Play Billing·서명 이용권·검증 서버 코드는 포함하며, 가격을 임의로 표시하거나 미검증 구매를 허용하지 않습니다. 무료 기능은 계속 사용할 수 있습니다.

## 데이터와 표현

아기 기록은 이 기기에 저장합니다. 외부 사용자 DB와 앱 로그인은 없습니다. 모델은 APK에 포함되며 원본 아기 영상·음성을 서버에 보내지 않습니다. 운영 결제 설정을 추가하면 구매 토큰과 임의 설치 식별자를 HTTPS 검증 서버로 전송합니다. 이 통신을 위해 INTERNET 권한이 있습니다.

YAMNet은 일반 소리 사건 분류, Face Landmarker는 얼굴 형상 단서를 제공합니다. 앱은 아기의 뜻·감정·건강을 판정하지 않습니다. 표현은 유한한 검수 조합으로 최근 반복을 줄이며, 장기간 사용하면 다시 나올 수 있습니다.
