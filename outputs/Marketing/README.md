## 편집 소스와 정리

홍보 폴더에는 확정 영상 원본과 같은 영상의 업로드 압축본, 최종 홍보 이미지 세 장을 둡니다. 미선택 가족 시안, 중복 시안, 비교 페이지, 사용하지 않는 내레이션 초안과 옛 렌더러는 휴지통으로 이동했습니다. 문서와 소스의 옛 시안 파일명·링크도 정리했습니다.

### 업로드 압축본 — 사용자 요청, 2026-09-30

`jigeum-trailer-small.mp4`: **744,721바이트**, 540×960, 24fps, H.264 Main 3.1 / AAC-LC 80kbps, 26.5초. 원본 2,296,155바이트에서 **67.6% 감소**했습니다. 영상 전체와 소리를 유지하고 MP4 faststart를 적용했습니다. 전체 디코딩 오류 0건과 대표 자막 프레임을 확인했습니다. 실제 Threads 업로드 성공은 아직 확인하지 않았습니다.

사용자 다운로드 폴더에는 **`지금 내 기분이 그래_mini.mp4`**로 복사했고 SHA-256 일치를 확인했습니다. 이 파일은 선택된 가족 버전의 압축본이며 별도 디자인 시안이 아닙니다.

저장소 루트에서 재현:

```powershell
ffmpeg -i outputs/Marketing/jigeum-trailer-b-family.mp4 -map 0:v:0 -map 0:a:0 -vf "scale=540:960:flags=lanczos,fps=24" -c:v libx264 -preset slow -crf 29 -profile:v main -level:v 3.1 -pix_fmt yuv420p -threads 2 -c:a aac -b:a 80k -ar 48000 -movflags +faststart -map_metadata -1 outputs/Marketing/jigeum-trailer-small.mp4
```

재편집 소스와 실행 방법은 [tools/marketing README](../../tools/marketing/README.md)에 정리했습니다. 선택한 부모 이미지·효과음 원본, 제작 당시 앱 캡처와 편집 스크립트를 Git에 보존했습니다. 오디오만 재생성할 때는 저장소 루트에서 `python tools/marketing/mix_marketing_audio.py`를 실행합니다. 결과는 `work/marketing-rebuild`에 생성하며 승인된 이 폴더의 파일을 자동으로 덮어쓰지 않습니다. 기존 영상은 재압축하지 않고 오디오를 믹싱하는 방식입니다.
