## 편집 소스와 정리

홍보 폴더에는 확정 영상 하나와 최종 홍보 이미지 세 장을 둡니다. 미선택 가족 시안, 중복 영상, 비교 페이지, 사용하지 않는 내레이션 초안과 옛 렌더러는 휴지통으로 이동했습니다. 문서와 소스의 옛 시안 파일명·링크도 정리했습니다.

재편집에는 작업 폴더의 `work/render_marketing.py`, `work/mix_marketing_audio.py`, `work/marketing/assets/`, `work/marketing/audio/`를 사용합니다. 선택한 부모 이미지 원본과 효과음 원본은 보존되어 있습니다. 오디오만 수정할 때는 `python work/mix_marketing_audio.py`를 실행하면 영상 재압축 없이 반영됩니다.
