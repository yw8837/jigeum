# 결과 카드 → 갤러리 — 0.5.6/code20

사용자는 결과 카드 디자인 그대로 사진/영상으로 내려받아 휴대전화 앨범에 저장하길 요청했고, 보완된 연락처 이후 Play 비공개 테스트 진행을 승인했다.

- 결과의 카드와 이미지/영상 출력은 같은 로컬 카드 렌더러를 사용한다. 선택 장면/원음/최종 편집 문장을 담고 버튼·근거 펼침·결제 안내는 출력에 넣지 않는다.
- 결과에서 ‘카드 이미지 앨범에 저장’, ‘영상 카드 앨범에 저장’을 제공한다. 녹음도 실제 소리가 있는 카드 동영상으로 만들 수 있다. 앱 기록 보관과 갤러리 저장은 각각 명확히 표시한다.
- 기록의 보관 영상에서도 카드 이미지/영상 앨범 저장을 제공한다. 기존 파일 위치 선택/공유 경로는 유지한다. 이미 생성된 결과의 보관/내보내기는 무료다.
- Android29+는 MediaStore pending 삽입→완전 쓰기→게시, 실패/취소→생성 항목 삭제. Android26–28은 쓰기 권한을 사용자가 눌렀을 때만 요청한다. 아기 원본 자동 업로드/외부 DB는 추가하지 않는다.
- 앨범에 사용자가 저장한 사본은 앱 기록 삭제로 지워지지 않는다. 사진 앱의 클라우드 백업 설정은 그 앱에서 관리한다. 새 권한/갤러리 노출을 정책에 반영한다.
- 표정 단독 욕구 번역은 기존 조사 결과를 따른다. 이번 저장 UX 작업에서 추가하지 않는다.
- 무료60초/10초/100MB, 전체120초/20초/200MB 검토본 유지. Play에는 release만 업로드한다. 새 서명preview/code20의 자동 업데이트 전환은 후속 더 높은 versionCode가 필요하다.
