# 다음 작업 —0.4.0 전체 이용권

이 목록은 구현 승인 기준이다. 체크되지 않은 항목을 완료로 보고하지 않는다. **현재코드는0.3.0이며카메라/저장영상은아직무료다.**

## 1. 중앙 접근 정책·화면 흐름

- [ ] 카메라, 저장영상, 신규PDF를 같은권한으로묶는중앙 `AccessPolicy` 추가. 무료기능도명시해 새기능이우연히열리지않게함.
- [ ] 홈에서무료음성을주행동으로유지. 카메라/영상에는전체이용권표시,선택시왜필요한지알수있는설명.
- [ ] `MainActivity`의CAMERA/VIDEO_IMPORT분기자체를권한으로조건부구성. 홈버튼만잠그면 프로세스복원/번역뒤로가기로우회됨.
- [ ] 실제센서시작·권한응답·영상URI반환·분석시작·PDF생성직전에메인스레드 `hasCurrentEntitlement()` 확인.
- [ ] `requestedFeature`와`returnPage`를rememberSaveable로보존. 홈→카메라/영상닫기HOME,앨범→닫기ALBUM,돌봄복원→닫기GUIDE.
- [ ] 구매/복원성공후자동촬영하지않고‘카메라로계속하기/영상가져오기로계속하기/아기말북으로’행동제공.
- [ ] 만료·권한철회시카메라/영상화면dispose.현재page+권한/작업세대검사로늦은콜백이paywall을덮지못하게함.
- [ ] 이미생성된TRANSLATE초안은출처와무관하게무료편집저장. 재촬영paywall왕복에도직접고친문장유지(세션별SaveableStateProvider또는루트상태).
- [ ] 앨범의현재월/표지/메모선택은기존보존방식유지. 확인기한만료와실제구독종료문구구분.
- [ ] paywall/돌봄에서무료·전체이용권경계,가격/기간/갱신,복원,관리,정책/약관을일관되게표시.

**재사용:** 카메라의disposed/unbind/modelclose,영상의childscope취소/finally자원정리,앨범SaveableStateProvider,무료JSON/PNG경로. 현재BillingManager에실행시점검사메서드와내부계측대역이있다. Runtime우회스위치/하드코딩premium을추가하지않는다.

## 2. 반드시 실행할 통합 QA

| 사례 | 승인 신호 |
|---|---|
| 무료사용자의녹음·수동·편집·저장·PNG·JSON/CSV | 결제화면없이완료,음성횟수제한없음 |
| 비구독카메라/영상선택 | 권한요청·파일선택기·분석보다이용권안내가먼저 |
| 잠긴화면프로세스복원 | 센서/디코더가한프레임도시작되지않음 |
| 카메라중/선택기중/영상분석중만료 | 작업정리,늦은결과폐기,안전한무료복귀 |
| 편집된카메라문장중만료 | 수정·저장/공유계속가능 |
| 보류/취소/검증실패/이전세대응답 | 임의권한해제없음,복원가능한안내 |
| 서명유효한오프라인캐시 | 한도안에서만유료,기한지나면재검증요구 |
| 명시적거절/환불 | 신규유료진입즉시차단,기록/기존파일유지 |
| 각paywall진입/취소/닫기/정책왕복 | 원래화면·스크롤·편집상태유지,잠긴화면루프없음 |
| 큰글자/작은폰/넓은화면 | 주행동접근/글자잘림/겹침검토 |

기존portable UI `camera`/`video` 모드는현재무료0.3동작을가정한다.0.4에서무료사용자로이를그대로실행해잠금을버그라고판정하지말고,무료잠금시나리오와검증된유료대역시나리오를분리한다. 실제Play거래시험은그대역과별도다.

## 3. 운영 연결 — 외부 의존

- [ ] 새개인Play계정신원승인과연락처인증. 현재앱만들기비활성. 임의다른개발자계정에등록하지않음.
- [ ] 사용자Cloud프로젝트선택. 새전용프로젝트여부는질문중이며답변없음. 다른제품의운영자원에배포하지않음.
- [ ] Node검증서버HTTPS·P-256개인키·Google서비스계정·Play접근설정. 공개키만앱에넣고키/토큰은Git제외.
- [ ] 프록시뒤실제사용자별제한과원본총량설정. 기본IP30/min을프록시공유IP에그대로두면전체사용자가묶임. 처리32/연결256상한·timeout·Googlequota·모니터링검증.
- [ ] SKU `jigeum_album`,월P1M자동갱신/3개월P3M선불동일권한등록. 실가격조회와예상치않은플랜거절확인.
- [ ] 라이선스테스터실제구매/보류/취소/복원/환불/계정변경/acknowledge검증.
- [ ] 물리ARM에서마이크/전후면/파일선택/모델/발열/메모리/오프라인,가능하면16KB기기시험.
- [ ] 운영자최용우/이메일확정값으로정책·약관HTTPS게시,시행일,서명키보관·AAB서명,Play콘텐츠/데이터보안선언.

## 4. 완료 보고 조건

0.4 게이트코드+UI+QA+빌드+문서+커밋푸시가끝나면그범위완료로보고한다. 실제구매/ARM/계정상태가남으면**출시가능/전체서비스완료라고말하지않는다**. 사용자가미룬공개제출을자동실행하지않는다. 최종보고에는실행수·skips·환경·남은항목·파일/커밋을기록한다.
