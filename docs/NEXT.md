# 다음 작업 — 아가톡0.5

최신 판단은 [심층 QA](qa/deep-audit-0.5/README.md)와 [HANDOFF](HANDOFF.md). 기능 회귀 통과와 사용자에게 돈을 받을 만한 해석 품질은 다르게 평가한다.

## 1. 실제 장면 적합성 — 최우선

- 사용자 원본은 아직 없다. 동의받은 로컬 아기 클립으로 울음·웃음·옹알이·높은 발성·혼합을 비교한다. 녹음 업로드 기능을 추가하지 않는다.
- 같은 구간 반복은 같은 의미/문구, 다른 사건은 다른 근거가 나와야 한다. 성인·TV·음악·무음 음성에서도 실제 모델을 시험한다.
- 보호자 최소3명/12클립의 초기 평가를 제안한다. 장면 적합성·아기 말투·저장/공유 의향·의도 확정으로 오해하는지 확인한다. 수치는 성공 결과가 아닌 평가안이다.
- [문장 계약과 승인안](research/20261001-competitors-and-voice.md)의 울음→놀이, 비아기→한마디 모순을 출시 차단 사례로 본다. 전부 보류하는 제품도 통과하지 못한다.
- 현재 유료 시각 관찰은 얼굴/입 열림에 한정된다. 그 기능과 PDF에 지불할 이유가 있는지 확인하기 전 유료 가치 검증 완료로 보고하지 않는다.

현재 [공개 음성 두 건](research/20261001-public-audio-probes.md)에서 울음은 문장으로 이어졌고 웃음은 충돌 규칙으로 보류됐다. 이 coverage 문제를 실제 클립으로 점검한다.

## 2. 모델 개선

- 검증 가능한 가정·아기·세션 분리 자료를 먼저 설계한다. 임의 caregiver 추정을 원인 정답으로 쓰지 않는다.
- YAMNet 임베딩+소형 head, PANNs/SSAST 비교, voc2vec 교사 모델 순서. 공개 모델을 가져왔다는 이유로 정확도를 주장하지 않는다.
- 라이선스·동의·중복 검사·class별precision/recall/macro-F1·보류율·기기별 지연을 보고한다. [근거와 평가 계획](research/20261001-cry-evidence.md).

## 3. 운영/출시 — 아직 남음

- ARM 실제 폰에서 카메라/회전/음질/선택 구간/백그라운드/큰 글씨/TalkBack/분석 지연 확인.
- 새 공개 정책 소스 배포, 앱명·화면·스토어 자료·확정 트레일러 새 이름 정합성. 현재 공개 서버는0.4.5 정책.
- 현재 사용자 범위에서 상품 등록과 실제 거래는 보류. 이후 Play 설치·구매·PENDING·ACK·복원·환불·계정 변경 검증.
- Console 초안 업로드·소액 입금 확인·비공개 테스트 요건·공개 제출은 실제 상태를 확인한 뒤 진행.0.4.5 산출물을0.5로 업로드하지 않는다.
