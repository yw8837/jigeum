# 다음 작업 — 0.4.0 전체 이용권

이 목록은 구현 승인 기준이다. 체크되지 않은 항목을 완료로 보고하지 않는다. **현재 통합 코드는 0.4.4/code 11이다. 접근 정책과 PR #2 경계를 소스에 구현했고, 최신 실행 결과는 [0.4.4 QA](../outputs/Jigeum-QA-0.4.4.md)를 기준으로 한다. 기존 0.4 정책은 유지한다. 실제 운영 연결과 Play/ARM 검증은 아래 3절에 남겨 두었다.**

## 1. 중앙 접근 정책과 화면 흐름

- [x] 카메라·저장 영상·새 PDF 생성을 같은 권한으로 묶는 중앙 `AccessPolicy`를 추가한다. 무료 기능도 명시해 새 기능이 의도치 않게 열리지 않도록 한다.
- [x] 홈의 주 행동은 무료 음성 입력으로 유지한다. 카메라·영상에는 전체 이용권 표시를 붙이고 선택 시 이용권이 필요한 이유를 설명한다.
- [x] `MainActivity`의 CAMERA/VIDEO_IMPORT 분기 자체를 권한에 따라 조건부로 구성한다. 홈 버튼만 잠그면 프로세스 복원이나 번역 화면의 뒤로 가기로 우회할 수 있다.
- [x] 실제 센서 시작·권한 응답·영상 URI 반환·분석 시작·PDF 생성 직전에 메인 스레드에서 `hasCurrentEntitlement()`를 확인한다.
- [x] `requestedFeature`와 `returnPage`를 `rememberSaveable`로 보존한다. 홈에서 카메라·영상으로 진입했다가 닫으면 HOME, 앨범에서 진입했다면 ALBUM, 돌봄의 복원에서 진입했다면 GUIDE로 돌아간다.
- [x] 구매·복원 성공 후 자동 촬영하지 않는다. ‘카메라로 계속하기’, ‘영상 가져오기로 계속하기’, ‘아기말북으로’와 같은 다음 행동을 제공한다.
- [x] 만료·권한 철회 시 카메라·영상 화면을 dispose한다. 현재 page, 권한, 작업 세대를 검사해 늦은 콜백이 이용권 화면(paywall)을 덮지 못하게 한다.
- [x] 이미 생성된 TRANSLATE 초안은 입력 출처와 관계없이 무료로 편집·저장할 수 있게 한다. 재촬영을 위해 이용권 화면에 다녀와도 직접 고친 문장이 유지돼야 한다. 세션별 `SaveableStateProvider` 또는 루트 상태로 보존한다.
- [x] 앨범의 현재 월·표지·메모 선택은 기존 보존 방식을 유지한다. 구매 확인 기한의 만료와 실제 구독 종료 안내를 구분한다.
- [x] 이용권 화면과 돌봄에서 무료·전체 이용권의 범위, 가격·기간·갱신, 복원, 관리, 정책·약관을 일관되게 표시한다.

**재사용할 부분:** 카메라의 disposed/unbind/model close, 영상의 child scope 취소와 finally 자원 정리, 앨범의 `SaveableStateProvider`, 무료 JSON/PNG 경로. 현재 `BillingManager`에는 실행 시점 검사 메서드와 내부 계측용 대역이 있다. Runtime 우회 스위치나 하드코딩한 premium 상태를 추가하지 않는다.

## 2. 반드시 실행할 통합 QA

| 사례 | 승인 신호 |
|---|---|
| 무료 사용자의 녹음·수동 입력·편집·저장·PNG·JSON/CSV | 결제 화면 없이 완료되며 음성 이용 횟수 제한이 없음 |
| 비구독 사용자의 카메라·영상 선택 | 권한 요청·파일 선택기·분석보다 이용권 안내가 먼저 나옴 |
| 잠긴 화면의 프로세스 복원 | 센서·디코더가 한 프레임도 시작되지 않음 |
| 카메라 사용 중·파일 선택기 사용 중·영상 분석 중 만료 | 작업 정리, 늦은 결과 폐기, 안전한 무료 경로 복귀 |
| 카메라에서 만든 문장을 편집하던 중 만료 | 수정·저장·공유를 계속할 수 있음 |
| 구매 보류·취소·검증 실패·이전 작업 세대의 응답 | 임의로 유료 잠금을 풀지 않으며 구매 복원 경로를 안내함 |
| 서명이 유효한 오프라인 캐시 | 유효기간 안에서만 유료 기능을 허용하고 기한이 지나면 재검증을 요구함 |
| 명시적 거절·환불 | 새 유료 작업 진입을 즉시 막고 기록·기존 파일은 유지함 |
| 이용권 화면의 각 진입점·취소·닫기·정책 왕복 | 원래 화면·스크롤·편집 상태가 유지되며 잠긴 화면 사이를 반복하지 않음 |
| 큰 글자·작은 폰·넓은 화면 | 주 행동에 접근할 수 있고 글자가 잘리거나 겹치지 않는지 검토함 |

portable UI의 `access`/`paywall-layout`은 0.4 무료 상태를 검증한다. 기존 `camera`/`video`/`invalid` 모드는 유효한 실제 이용권이 있는 운영 연결 시험 설치에서만 실행한다. 무료 상태의 잠금을 미디어 엔진 실패로 판정하지 않는다. 무료 잠금 시나리오와 검증된 유료 테스트 대역의 시나리오를 나눠 실행한다. 실제 Play 거래 시험은 테스트 대역 검증과 별개다.

## 4. 완료 보고 조건

0.4의 접근 제어 코드·UI·QA·빌드·문서·커밋/푸시가 끝나면 해당 범위의 완료를 보고한다. 실제 구매·ARM·계정 상태 확인이 남아 있다면 **출시 가능 또는 전체 서비스 완료라고 말하지 않는다.** 사용자가 미룬 공개 제출을 자동 실행하지 않는다. 최종 보고에는 실행 수·skip·환경·남은 항목·파일·커밋을 기록한다.
