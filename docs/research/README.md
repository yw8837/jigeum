앞의 두 문서는 문헌·공개 소스 조사다. 경쟁 앱을 직접 설치/결제/실제 아기 소리로 비교하지 않았고 새 모델을 학습하지 않았다.0.5의 구현 범위와 실행 결과는 [HANDOFF](../HANDOFF.md)·[QA](../qa/0.5.0/README.md)에 따로 있다.

## 개발에 반영한 결정

- YAMNet의 `Babbling`과 군중 말소리 `Hubbub, speech noise, speech babble`를 정확히 구분.
- 입력 없는 결과·보호자 선택 기반 문장·후보 재뽑기 제거. 실제 구간 재생과 구간 디코딩.
- 울음에 놀이 제안을 붙이지 않음. 애매한 소리에서는 보류. 소리 유형과 짧은 캐릭터 문장 연결.
- 배고픔/졸림 욕구 분류기라고 표시하지 않음.0.35/0.30 등 점수는 미보정 구현 규칙이며 정확도 아님.
- 원음 외부 업로드와 데이터 자동 수집 없음. ICSD·CryCeleb 비상업 제한 자료 미도입.

다음 성과는 문장 수나 일반accuracy 수치가 아니라 **실제 장면과 모순되지 않는 결과, 보류율, 보호자의 다시 쓸 의향**으로 판단한다. 평가를 아직 실시하지 않은 상태에서 유료 가치 검증 완료로 표현하지 않는다.
