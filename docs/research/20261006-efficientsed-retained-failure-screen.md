# EfficientSED의 별도 보존 누락 원음 비교

2026-10-06 · 로컬 연구 · 제품 엔진/문장/판정 기준 변경 없음

## 이번에 새로 실행한 비교

[기존 AST 보존 원음 비교](20261004-retained-pcm-ast-check.md)에서 회복하지 못한
한 원본의 두 10초 구간에 20.3MB EfficientSED TF 후보를 처음 실행했다.
기존에 울음으로 수용된 다른 원본의 약 8.79초 구간도 함께 실행했다.
총 3구간·2원본이다. 누락 두 구간은 서로 겹치므로 독립 표본 두 개로 세지 않는다.
이미 조사한 자료이며 새 holdout이나 독립 청취 정답은 아니다.

다른 원본에서의 새 후보 신호를 확인하는 목적이다. 이미 완료한 약국·공개33조건·
합성 이식 검사를 반복한 것이 아니다. 원본 MP4 일부는 더 이상 해당 경로에 없어서
새 디코딩이나 현재 앱의 전체 실행을 했다고 보고하지 않는다.

## 고정 입력·실행

- 기존 `matched-corpus`의 gain1/shift0/16kHz mono float32 원음을 복사했다.
  과거 manifest·감사 결과의 PCM SHA256 및 바이트 수를 확인했고, 복사 뒤 원본 해시도 유지됐다.
  이 검증은 보존 PCM 무결성 근거이며 현재 Android 디코더/필터의 동등성을 입증하지 않는다.
- [동일 고정 모델](20261005-temporal-model-followup.md), source revision
  `e3449bfd1f4922b81d82410ed842653f462bfca8`, strict 전체 가중치 로드와
  [기존 연구 runner](../../tools/research/efficientsed_probe.py)를 그대로 사용했다.
- 공식 전처리·오른쪽 zero-padding·실제 길이 출력 crop·sigmoid를 유지했다.
  별도 denoise/gain/threshold 조정은 없다. 소스/모델/runtime pin과 shape/finite를 검사했다.
- Python 네트워크 연결 차단, Windows Job 180초/4GiB, CPU 4스레드다.
  다운로드·ADB·Gradle·사용자 자료 외부 전송은 없다.

## 관찰과 해석

기존 AST가 회복하지 못한 두 구간에서 새 후보의 옹알이 점수도 약했다.
두 구간 모두 원래 runner가 기록하는 **관찰용 0.5 이상 위치가 0개**였다.
이 값은 제품 승인 기준이나 교정된 확률이 아니다. 따라서 이를 제품의
회복률 0%나 일반 옹알이 인식률로 변환하지 않는다. 낮은 기준값을 새로 골라
통과시키지도 않았다. 점수 크기를 AST의 다른 출력과 직접 비교하지 않는다.

울음 대조 원음에서는 울음과 음악의 신호가 함께 나왔다. 후보 단독 관찰용
0.5 기준에서는 아기 울음 위치가 없었고 음악 위치는 있었다.
현재 앱의 울음 수용을 이 후보로 대체해도 보존된다고 확인한 결과가 아니다.
그러므로 기존 경로를 제거하는 일괄 모델 교체를 뒷받침하지 않는다.

이 실행에서는 성인/TV 대조를 새로 수행하지 않았다. 기존 후보 스크리닝의
비아기 점수와 이번 영아 원음만으로 오인율·욕구 정확도·새 제품 품질을 주장하지 않는다.
배고픔/졸림/놀이 문장 생성도 이번 소리 라벨 검사의 범위 밖이다.

worker는 exit0, 9.862초, cleanup 완료, 잔여 자손0으로 종료했다.
준비된 PCM의 3개 추론 구간 합계는 약 0.201초다. 두 수치는 PC 연구 실행 시간이며
실폰 지연·배터리·발열·앱 전체 분석 시간으로 일반화하지 않는다.

## 결정과 후속

이번 비교는 EfficientSED를 넣으면 미해결 옹알이와 번역 문제가 해결된다는 근거를
추가하지 못했다. **제품 채택은 보류**하며 기존 YAMNet+AST를 유지한다.
이 결과만으로 후보 전체를 폐기하거나 임계값을 낮추지는 않는다.

다음 후보 평가는 [시간축 계약](20261006-efficientsed-temporal-contract.md)의
고정 소리 종류/사건 구간 평가와 비아기 반례를 적용한다. 현재 실패 원음은 회귀 자료로
보존하고, 새 자료에서는 학습·조정용 가족/세션과 최종 평가용 가족/세션을 구분한다.
새로운 판별 이득 없이 같은 3구간 추론을 반복하지 않는다.
