# 선택 구간의 부분 관찰·넓은 음성창과 영상 연결

사용자 승인: 정확도 우선, 선택한 최대 20초 전체를 살펴 소리와 영상의 흐름을 반영한다.
기준 소스: a3b183d. 기존 code36은 Alpha 제공 중이며 이 문서는 후속 변경 계약이다.

## 확인한 결함과 범위

1. 같은 선택 구간에 충분히 반복된 아기 소리 단서와 미확정 소리가 함께 있으면
   전체가 MIXED_VOCAL로 보류된다. 확인된 부분만 시간 범위와 함께 남길 수 있어야 한다.
2. AST가 옹알이를 받아들인 영상도 broadOnly 분기에서 시각 연결을 전부 제외한다.
   S25 보관 약국10초 재구성의 기존 결과는 옹알이/AUDIO였다. 새 입력이나 아직 실패하는
   원본으로 부르지 않는다. 20초 재구성은 같은10초의 반복이며 독립 정확도 표본이 아니다.
3. TalkNet 원음/500ms shift 비교는 정렬 구분 근거가 없었다. 얼굴/입 변화로 소리 판정을
   대신하거나 발성 주체·입술 동기를 확인했다고 표시하지 않는다.

## 구현 계약

- 전체 음성·영상 관찰 및 모델/임계값 유지. 새 모델, 서버, 원본 저장, 처리 지연 추가 없음.
- 기존 성공 결과의 음성 문장은 그대로 유지한다. 음성 오류·무음·아기 단서 없는 입력은 보류한다.
- 부분 관찰은 MIXED_VOCAL에 한정한다. 유한한 점수·음량·순서가 확인된 전체 원천에서
  기존 vote를 통과한 같은 종류의 인접한 비중첩 창 2개 이상(어린 말소리 3개)을 요구한다.
  다른 충돌 창과 겹치는 창은 사용하지 않는다. 창 내 RMS .003 이상 유지.
- 부분 결과는 중립적인 아기 발성 표현만 만든다. 특정 웃음/울음/감정, 전체 지속·반복·쉼,
  욕구를 만들지 않는다. 근거에 채택한 시간 범위와 나머지 종류 미확정을 함께 남긴다.
- 넓은 옹알이/아기 발성 승인 창의 영상 연결은 해당 창 내부의 이어진 입 변화만 사용한다.
  실제 디코드 PTS와 음성 정렬을 요구하고 미관찰 공백·여러 얼굴·불완전 창을 거부한다.
  넓은 창에서의 동시 관찰이며 정밀 동기나 발성 주체를 확인한 것은 아니다.
- 단지 입을 움직이는 얼굴, 성인 더빙, 무음 영상은 새 아기 소리를 승인할 수 없다.
- 새 관찰의 출처·시간범위·보류 범위를 숨기지 않는다. 기존 기록/내보내기/권한 정책 유지.

## 검증

기존 보관 모델 출력(28+53조건, 독립 원본 수와 다름)으로 정책 전후 비교한다.
성인/음악/잡음 대조의 신규 출력0, 기존 승인 음성 문장 보존을 요구한다.
약국 보관 PTS/영상 관찰과 소리 결과를 재생해 넓은 창 연결을 확인한다.
정렬 오류, 앞/뒤 비대응, 무음, 다중얼굴, 비유한/역순/중복 시각, 겹친 소리창,
충돌 다수+고립된 강한 창을 반례로 검사한다. host 정책 재생은 Android 재추론이 아니다.
Android 제품 경로의 단위/통합·취소/실패 복구는 변경 범위에 맞춰 실행한다.
새 실제 인식 회복과 일반 정확도·욕구 정확도는 구분하며, 배포는 최종 패키지 QA 뒤 별도 기록한다.
