## 입력·진단 수정

1. 잘못된 구간과 실제 영상 길이 초과를 거절한다. FFmpeg 실제 PTS로 표본 시간을 보존한다. 늦은 오디오 시작을 구간 시작으로 당기지 않는 회귀 테스트가 있다.
2. 새로 제공된 첫 파일은 실제 **음성 트랙이 없다**. 작은 소리·무음 트랙·음성 없음은 다른 상태다. 음성 없는 파일에는 가짜 무음이나 울음 근거를 넣지 않고 명시적인 영상만 비교 경로를 사용한다.
3. 관찰만 출력하는 모드와 음성만/영상만/둘 다 비교 옵션을 추가했다. 이 모드는 제품에 표정 단독 욕구 번역을 추가한 것이 아니다.
4. 문장/관찰 응답의 시간 범위·근거 ID·형식 등을 검사한다. grammar는 형식만 제한하고 의미 정답을 보장하지 않는다. 스키마 설명 예제를 베끼는 현상이 있어 최신 관찰 프롬프트에서 예제 문장을 제거했다.
5. Native cache를 ASCII 경로로 분리해 응답을 ignored 로컬 폴더에 보관한다. 한글 경로의 초기 engine-create 오류는 재현됐으나 모든 모델·cache 경로 원인을 독립적으로 확정한 것은 아니다.
6. SDK 측정 옵션을 켜지 않고 benchmark를 읽으면 실제 응답 이후 예외가 났다. optional metrics 실패가 응답 저장을 막지 않게 수정하고 `enable_benchmark=True`를 사용한다.
7. 모델 파일·응답·사용자 영상은 Git에 포함하지 않는다. Python socket 호출은 차단했다. **이는 native SDK 전체 egress의 독립 입증이 아니며**, Android에서는 비행기 모드 실행과 통신 관찰이 별도 gate다. 외부 AI API/원본 업로드/클라우드 fallback은 사용하지 않는다.

### 전체 구간 출력 계약 수정

기존 관찰 형식은 최대3사건에 시작/종료시각을 강제하면서 모델이 앞3장을 각각 기술하는 교란이 있었다. 별도 `--whole-interval` 모드에서 음성 요약·시간순 영상 변화·한계를 출력하게 하여 원래 모드와 A/B할 수 있게 했다. 동일4K context에서 기존 event 모드는 여전히 앞0–3초 빨강만 기록했고, whole 모드는10초 전체 색상 순서를 기술했다. 따라서 앞장면만 읽던 현상을 모델의 시간 이해 능력만으로 설명할 수 없다. 다만 음성 요약에 색상 내용을 섞거나 소리 없음으로 처리한 오류는 남았다.

| 최종 대조 | 문맥 | 추론(단회) | 의미·형식 결과 |
|---|---:|---:|---|
| 기존 event10초 AV |4096|47.713초|앞0–3초 빨강만 기술. JSON 형태는 통과 |
| whole10초 AV |4096|42.613초|빨강→파랑 순서 기술. 허위 줄무늬·소리 혼입으로 의미 미통과 |
| whole10초 역순 |4096|36.486초|파랑→빨강 순서 기술. 소리 누락으로 의미 미통과 |
| whole tone 음성만 |4096|20.949초|실제 tone 외 클릭과, 입력하지 않은 시각 장면을 기술. 형식은 통과하지만 의미 실패 |
| whole20초 AV |8192|111.059초|소리/침묵을 매초 반복 기술하다450토큰 한도. 비JSON·status invalid. 문맥을 늘려도 품질 통과하지 않음 |

단순 시간순서 합성 대조의 일부 성공을 아기 영상의 맥락 이해로 일반화하지 않는다. 이 후보의 직접 AV 공동 해석을 현 제품에 탑재할 근거가 아직 없다.

추가 원천 확인에서 **입력 순서의 교란**을 발견했다. 공식 Gemma4 안내는 이미지를 텍스트보다 앞, 음성을 텍스트보다 뒤에 넣도록 권장하지만 기존 실험은 텍스트→음성→이미지 순서였다. `--media-order recommended`로 원래 순서를 보존한 비교를 실행했다. 공식 음성 지원 설명은 ASR·음성 번역·일반 말소리 이해를 중심으로 하며 아기 비언어 사건 인식의 입증 자료와 같지 않다.

| 권장 입력 순서 대조(4096 context) | 추론(단회) | 결과 |
|---|---:|---|
|10초 AV|37.510초|음성 요약에 색깔 혼입·허위 줄무늬·tone 누락. 의미 실패 |
|10초 역순 AV|40.284초|방향 일부 유지, 허위 줄무늬·실제5초 변화를4초로 기술. 의미 실패 |
|10초 tone 음성만|14.720초|없는 클릭과 입력하지 않은 시각 장면 기술. 의미 실패 |

3건 모두 schema observed였으나 의미 검증은 통과하지 못했다. 권장 순서로도 기본 대조를 통과하지 못해 추가 사용자 원본/20초 실행은 반복하지 않았다. 첫 권장순서 실행의 잘못된 로컬 bundle 경로는 모델 로드 전 실패한 하네스 준비 오류로 보존하고 별도 유효 경로 실행과 구분했다. 이 결과는 현재 후보/런타임/입력 계약의 한계이며 모든 온디바이스 모델의 불가능성을 뜻하지 않는다. [익명 수치·합성 대조 증거](../qa/ondevice-av-generation/evidence/perception-recovery-summary.json).

일부16K context 실행은 시스템 commit약98%에서 native tensor allocation에 실패했다.4K context로 실행된 사실은 동일 품질·입력 수용량을 보장하지 않는다. context 크기를 명시 옵션으로 남기고 입력을 몰래 줄이지 않는다.

### 제품 수정 범위

Android의 최대5장 근사 프레임 경로를 순차 디코딩·실제PTS·초당2회 VIDEO 추적으로 바꾸는 작업을 진행한다. 전체 구간의 얼굴/입 변화·관찰 공백을 보존하기 위한 기반 수정이다. 얼굴 주인, 발성 주체, 욕구, 아기 의도 정확도나 생성형 공동 이해를 구현했다고 소개하지 않는다. 현재 새 후보의 일괄 교체·배포는 승인하지 않는다. [동적 QA 행렬](../qa/ondevice-av-generation/PERCEPTION-QA.md).
