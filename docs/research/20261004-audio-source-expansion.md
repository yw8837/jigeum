## 평가에 사용할 때의 제한

- 여기서 label은 저자/배포 설명을 정리한 후보값이다. 파일 제목이나 태그를 청취 정답으로 간주하지 않는다. 특히 Mayra 파일은 연령과 소리 사건이 설명에서 특정되지 않아, 청취 검수 전에는 확정 label 평가 분모에서 제외한다.
- 후보 4건이 4명의 서로 다른 아기를 증명하지 않는다. PDSounds의 baby5m은 원 녹음자 `stephan`으로 묶고, Mayra/Manoj/Freesound 녹음도 공개 설명만으로 아기 신원·가족·세션이 독립임을 검증할 수 없다. 복수 창/crop은 별도 표본이 아니다.
- 대상 사용자 연령과 가까운 6–18개월 양성은 이번 조사에서 충분히 검증하지 못했다. 확인 가능한 후보 중 2개월·신생아·5개월 자료는 모두 더 어린 연령이다. 14개월 Commons 파일은 동일 PDSounds artist `stephan`의 별도 recording이지만 같은 아이인지 확인할 수 없어 새 독립 영아로 추가하지 않았다.
- CC BY-SA는 CC0/Public Domain과 사용 조건이 다르다. 특히 Mayra와 Manoj 미디어나 이를 개작한 결과물을 외부로 재배포할 경우 attribution/share-alike 조건을 별도로 준수해야 한다. 이번 로컬 연구용 다운로드는 Git에 포함하지 않는다.
- Adult negative도 Freesound 설명 기반 후보이며 사람이 실청해 성인/비아기임을 재확인하기 전 확정 ground truth로 세지 않는다. `No problem`은 1.24초로 문맥이 매우 짧다.
- 이전 조사에 이미 있는 reinsamba, Islabonita471061, keplar139046, Sage Ross 계열은 새 독립 표본으로 재사용하지 않았다. 본 문서는 소스 접근·권리·설명 확인이지 AST 성능 결과가 아니다.

## 출처 확인 방식

Agent-Reach의 Exa 웹 검색 결과를 discovery에 사용하고, 각 원본 Freesound/Commons 페이지의 HTML·Commons imageinfo 메타데이터에서 creator/description/license/file URL·크기를 대조했다. Freesound 공개 preview URL 또는 Commons 원본 파일을 15 MB 제한으로 직접 받아 HTTP 상태와 크기를 확인했다. 확인한 CC0/PD/CC BY-SA는 페이지상 표시를 옮긴 것이며 법률 의견은 아니다.
