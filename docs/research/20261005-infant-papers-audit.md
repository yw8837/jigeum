# 제공 논문·자료의 원문 감사: 6–18 개월 온디바이스 발성 관찰

확인일 **2026-10-05**. 대상은 아가톡의 옹알이·울음·웃음 사건 검출, 잡음/겹침 처리, 10–20 초의 시간 변화와 영상 관찰이다. 이 문서는 공개 원문·배포 문서의 읽기 조사다. 모델·음원·영상 다운로드, 학습/추론, Android 변환, 실기기 측정, 앱 변경은 수행하지 않았다. 사용자 아기 파일과 파생 정보는 외부로 전송하지 않았다. PDF 논문 텍스트를 임시 디렉터리에서 추출한 것은 모델/미디어 확보와 구분한다.

기존 [울음 근거](20261001-cry-evidence.md), [발성 후속 후보](20261004-additional-vocal-candidates.md), [AV 자료](20261004-labeled-av-data.md)를 먼저 읽었다. 이미 검증한 자료를 새 독립 실험으로 세지 않는다. 검색은 `agent-reach`의 Exa, 본문은 Jina Reader·`insane-search` PDF 추출, 신원 대조는 Crossref·저자 GitHub/Hugging Face 공개 API 를 사용했다. 검색 요약을 원문 평가표 대신 사용하지 않았다. 유료/인증 자료는 공개 서지·초록 수준으로 제한했다.

## 판단과 바로 할 일

**제공 자료 중 6–18 개월의 웃음·울음·옹알이를 잡음·다중화자가 있는 휴대폰 영상에서 정확하게 관찰하고, Android 에서 완전 온디바이스로 실행하는 패키지까지 입증한 논문은 확인되지 않았다.** 가정 녹음으로 사전학습한 표현 모델이 영아 발성에 도움이 된다는 직접 증거는 있다. 그 근거가 배고픔/졸림의 참값이나 작은 모바일 모델의 준비 상태를 대신하지는 않는다.

2·3 은 **다음 두 연구 후보**다. 새 모델이 이미 검증되거나 교체가 승인됐다는 뜻이 아니다. 현재 엔진 결함 수정과 별개로 다루며 기존 사적 영상에 맞춰 임계값을 반복 조정하지 않는다.

### 감사에서 중요한 네 가지 정정

1. **P2와 P11은 동일 연구다.** Academia의 P3 재게시도 새 실험으로 세지 않는다. 여러 주소를 인용해 증거 수를 부풀리지 않는다.
2. **P3의 Visualizations는 영상 인식이 아니다.** LittleBeats 장치는 audio/motion/heart-rate를 기록하지만 이 논문의 분석은 audio 표현의 그래프다. 30초 BoAW는 히스토그램이어서 창 안의 정확한 순서를 잃는다. t-SNE 군집의 시각적 구분은 classifier 정확도나 발달 진단 성능이 아니다.
3. **P4의 증강 후 큰 n은 독립 아기 n이 아니다.** 8개 burping 원음에서 384개 증강 후손을 만드는 것은 384명의 아기 또는 독립 행동 증거를 만드는 작업이 아니다. source/family를 먼저 분할해야 한다.
4. **신생아 pain 연구와 제품 연령대는 다르다.** P8의 군 평균 차이나 CryCeleb의 병원 신생아 identity 과제를 6–18개월 가정 need 분류로 바꾸지 않는다. 청취 라벨과 행동 원인은 별도 변수다.

### 추가 검색에서 대상이 달라 제외한 사례

- [InfantNet: A Deep Neural Network for Analyzing Infant Vocalizations](https://arxiv.org/abs/2005.12412),2020 원문 HTML을 읽었다. **15가족·3/6/9/18개월**,1초/8kHz CNN,2,456 train clips라는 연령 장점이 있다. 그러나 cry와 laugh를 합친 class이고 family-disjoint split/외부 시험·확정 checkpoint 권리를 확보하지 못했다. 활동이 큰5분 구간을 선택한 분포도 일상 전체 분포와 다르다. age별 결과표만으로 독립성/외부 검증이 보장되지는 않아 다음 후보2개 뒤로 둔다.
- [MAVA, Scientific Reports2024](https://www.nature.com/articles/s41598-024-69245-2) 원문을 읽었다. 제목에 infants가 있지만 실험은 **40 adults×5 vowels×4 = 800 samples**,각6 video/audio frames의 약1.5초다. optical flow+audio energy+Hebbian attention의 mouth focus 과제. offline에서는 각 subject/vowel의 절반을 train/test,online에서는 같은 stream에서 학습·평가한다. 95% mouth focus를 infant ASD/욕구 또는10–20초 가정 영상 성능으로 인용하지 않는다. 단순 동기화 설계 아이디어만 남긴다.
- Bonafos 등의 *Detection and classification of vocal productions in large scale audio recordings*는 검색에서 **Guinea baboon과 human baby 두 실험**이 함께 나타났다. 저자 공개 전문·분할/권리를 끝까지 대조하지 않아 정량 표에서 제외했다. animal쪽 정확도를 영아 수치로 옮기지 않는다. **rodent ultrasonic vocalization/동물 울음의 논문과 모델도 사람 영아 validation으로 세지 않는다.** 이번 제공 arXiv 세 주소가 rodent 논문이라는 사실은 없으므로 그렇게 오판하지 않는다.
- [Automated Analysis of Naturalistic Recordings in Early Language Development](https://pmc.ncbi.nlm.nih.gov/articles/PMC12928500/) 공개 원문은 추가 발견 지도/참고문헌 연결에 썼다. 새 review를 개별 원논문의 분모/분할 검증 대신 쓰지 않는다. babble,canonical,speech maturity,speaker type,cry reason은 서로 다른 과제다.

## 10–20초 관찰에 필요한 평가 계약

다음은 문헌을 근거로 한 **평가 설계 제안**이며 현재 앱 성능 보고가 아니다.

1. **음향 사건과 목소리 주체를 분리한다.** 울음/옹알이/웃음 종류,infant/adult/TV source,overlap,uncertain을 시간축에 별도 기록한다. 영아 소리 분류와 “화면 속 그 아기” 얼굴 연결의 평가는 따로 한다.
2. **가족·원녹음을 먼저 분할한다.** train/dev/test 가정→원음→창 순서로 만든다. 같은 아이·세션·재인코딩·겹치는 창·augmentation 후손을 여러 split에 넣지 않는다. SSL pretraining에 test 가정/아기가 포함되는지도 manifest로 확인한다.
3. **실제 negative와 짧은 사건을 포함한다.** 성인 웃음·아이 장난·TV·음악·마찰·멀리 있는 아기·숨소리·마이크 깨짐·성인/아기 겹침을 포함한다.10/20초 중1초 발성의 경우와 연속 발성을 나눠 사건 회복과 보류를 검사한다.
4. **처리 전후의 같은 입력을 대조한다.** enhancement가 평균 SNR을 높여도 짧은 비성인 발성을 지울 수 있다. raw→resample→denoise 각 단계의 onset/offset·peak/RMS/clipping·검출 결과를 기록한다. adult ASR/WER 개선은 infant babble 보존의 대용 지표가 아니다.
5. **precision/coverage·event recall·경계 오차·시간당 false positives를 함께 보고한다.** macro-F1/UAR,cry/laugh/babble별 confusion,보류율 및 보류하지 않은 오류를 보고한다. 독립 infant/family,event,clip/window의 분모를 각각 명시하고 CI는 family bootstrap 등으로 구한다. frame 수를 독립 표본 수로 세지 않는다.
6. **영상 기여는 ablation으로 검증한다.** audio-only,vision-only,aligned AV,시간 이동 AV,다른 얼굴 AV를 비교한다. 얼굴 실패·등 돌림·가림·화면 밖 성인·카메라 이동 시 보류를 허용한다. 입 형상/웃는 모양/AV 상관은 욕구의 참값이 아니다.
7. **모델 선택은 dev,최종 시험은 고정된 외부 가정.** BabyHuBERT의 best-test 모델 선택을 따르지 않는다. family-heldout이어도 반복 실험 선택이 있으면 앱의 새로운 시험을 확보한다.
8. **온디바이스는 권리와 실측까지 확인한다.** 정확한 commit·checkpoint SHA·label map·전처리·quantization parity,저가/중급 ARM에서 p50/p95 latency·peak RAM·APK 크기·연속 분석 발열/전력을 기록한다. GPU 논문·download size·PC/emulator 통과를 Android 실기기 검증으로 대신하지 않는다.

## 확인 한계와 산출물 상태

모든 사용자 제공 논문·웹주소를 표에 넣고 접근 수준을 명시했다. **인터넷 전체를 전수 조사했다거나 모든 유료 전문을 읽었다고 주장하지 않는다.** 원문 읽기·저자의 주장·제품 적용 판단을 구분했다. 가입/자료 허가 신청/저자 연락·paywall 우회·원본 미디어 외부 전송은 하지 않았다.

공개 HF 조회에서 W2V2 LittleBeats revision은 `b3250219066482f571ef3868413b0b0f1ad92502`,metadata/card license는 `openrail`이었다. 실제 가중치를 받아 해시하거나 추론하지 않았으며 이 revision을 앱 채택 판정으로 쓰지 않는다. dataset의 접근·상업 조건,모델과 코드의 license는 각각 확인해야 한다. Agent Reach1.5.0 최신 확인,업데이트 실행 없음.

독립 정확도·욕구 정답·얼굴 연결·Android 모델 교체·베타 배포를 완료한 보고가 아니다. 즉시 적용 조치는 로컬 결함 검증과 사건 관찰 보존이며,새 대형 영아 표현 모델은 권리와 실측을 갖춘 후속 연구 후보다.
