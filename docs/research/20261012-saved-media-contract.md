# 갤러리 분석 저장 / 결과 없는 영상 보관 / 연속 분석

기준 커밋: 6499256a4d2e80f72894d5ab0c37b233259ddb76. 사용자는 갤러리에서
불러온 영상을 번역한 후 영상+아가말/이미지+아가말 저장 오류를 보고했다.
분석 실패·보류 때도 영상만 저장하고, 다른 영상을 연이어 분석했을 때 비슷한
표현이 반복되는 현상을 점검·개선하도록 요청했다. 약국 옹알이 개선은 사용자 피드백이다.

후속 사용자 확인: PNG는 정상이며, 영상카드/장면과 함께 저장 두 경로에서
“이 기기에서 번역 영상을 만들지 못했어요…”가 나온다. 저장 권한/PNG 전체 실패로 보고하지 않는다.

## 완료 기준

- 실제 JigeumApp→CaptureFlow→렌더러→MediaStore/기록 저장 경로를 content URI로 검증한다.
- 저장 오류는 재현한 원인만 해결했다고 보고한다. 모르는 오류를 저장 공간 문제로 단정하지 않는다.
- 결과 유무에 관계없이 선택한 영상 구간을 자막 없이 앨범에 저장한다. 원본 전체 저장으로 표시하지 않는다.
- 실패·취소·중복 클릭 시 미완성 미디어/가짜 문장/기록을 남기지 않는다. 입력은 보존한다.
- 새 분석에 이전 문장·메모·판정이 섞이지 않아야 한다. 같은 파일의 같은 근거는 결정적이어야 한다.
- 표현 개선은 관측된 소리/시각 근거 범위 안에서 한다. 임의 표현 교체나 표정만으로 욕구 단정은 하지 않는다.
- 기존 발성 승인/보류 기준과 약국 옹알이 승인 경로를 보존한다.
- 로컬 검증과 Play 배포를 구분한다. code38의 미해결 45초 timeout gate를 해결했다고 덮어쓰지 않는다.

## 경계

온디바이스 처리, 무료 미디어 내보내기, 기존 기록/원본/키 보존. 소유 QA 에뮬레이터만 사용한다.
실제 사용자 자료는 업로드하지 않는다. 기존 삭제 정책 차단을 우회하지 않는다.
