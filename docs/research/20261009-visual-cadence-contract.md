# 짧은 입 변화 누락 — 구간 관찰 간격 비교와 수정 범위

기준 `cf691aa` / 제출된 beta35. 사용자 요청은 낮은 인식과 장면 중심 처리의 개선이다.
이 문서는 그중 **시각 관찰 누락**을 줄이는 작은 수정 계약이다. 공동 AV 모델 완성이나
음성 보류 회복, 감정/욕구 정확도를 성공 기준에 포함한 척하지 않는다.

## 확인한 구조

- 전체 선택 구간을 순차 decode하지만 시각 모델에는500ms마다20/40장(10/20초)을 전달한다.
- 실제 PTS의 입 열림/닫힘을 시간순으로 묶는다. 음성이 승인된 시간창에서만 문장을 보조한다.
- `EvidenceInterpreter`는 음성 판정 보류 시 먼저 반환한다. `broadOnly`도 시각 연결에서 제외한다.
- 따라서 시각 cadence 개선만으로 발성 미인식이 해결되지는 않는다. 이 경계를 숨기지 않는다.

## 로컬 비교

기존 허용 영상의 첫10초에서 이전에 추출해 보관한250JPEG와 source-PTS map을 재사용했다.
원본 MP4는 현재 없으며 새 원본 검증은 아니다. 각 JPEG byte SHA256/개수/시각/매핑 유일성을
기존 manifest와 대조했다. JPEG 재인코딩·30→25fps 선택 때문에 원본/Android pixel parity는 아니다.
같은 제품 `face_landmarker.task`와 MediaPipe1.0.0 PC VIDEO모드, 얼굴2개, 최대512px,
기존 입 좌표/임계값을 고정했다. 모델의 신원/월령/실제 화자 추정은 없다.

| 관찰 간격 | 표본/단일얼굴 | 입 상태 변화 | 최초 PC 실행 시간 |
|---|---:|---:|---:|
|500ms|20/20|6|1.605초|
|200ms|50/50|19|1.548초|
|100ms|100/100|23|2.146초|

100ms 추론 결과를500/200ms로 사후 선택해도 각각6/19회다. 같은 landmark track에서
관찰 시간만 줄인 비교로 누락을 분리했다. 상태 변화의 개수는 사람의 발성 정답이 아니다.
최종 helper에서 선택기를 공유한 뒤 재실행 시간은500/200/100ms 순서로2.142/2.343/2.093초였고,
개별 관찰 JSON은 세 조건 모두 첫 실행과 byte exact였다. 고정 순서·warmup·PC부하 영향이
있어200ms가500ms보다 빠르다고 결론 내리지 않는다. 속도 개선 실험이 아니다.
얼굴/소리가 없는 별도 허용 영상은 세 조건 모두 얼굴0이었다.

600/800/1000/1200/1400ms의 실제 보관 이미지를 직접 확인했다. 입이 닫힘→열림→닫힘→열림→닫힘으로
변한다. 이 부분은500ms 표본 사이에서 빠지고200ms에는 남는다. 전체19회/23회를 독립 정답으로
라벨링한 것은 아니며, 수치 확인 뒤 고른 개발 사례의 시각 확인이다.

## 수정 후보와 승인 기준

1. 선택 구간 전체에서200ms 간격으로 읽는다.10초50/20초100관찰, 실제PTS/누락/순서 검사 유지.
2. 예상 표본수는 decoder cadence 상수를 함께 사용해 완료/부분 상태의 어긋남을 막는다.
3. 표본 수 증가가 표현 근거의 지속 조건을 완화하지 않도록 웃는 모양 최소500ms,
   입 변화 run 최소1000ms를 명시한다. 전자는 이전2표본, 후자는 이전3표본의 명목 간격이다.
4. 음성 모델/필터/게이트·broad exclusion·화자/감정/욕구 의미·무료/유료 범위는 변경하지 않는다.
5. 실제 production cadence→timeline→interpreter로 짧은 반복 입 변화 누락을 재현한다.
   이전 코드2검사 실패를 보존하며 수정 후 통과·정적/성인/무음/다중얼굴/공백 반례를 확인한다.
6. Android의20초 전체 decode/실제 모델, 비영점 구간/회전/취소·재실행/PTS 회귀를 확인한다.
   PC결과를 폰 속도/발열 검증으로 쓰지 않는다. 연구 후보를 승인 없이 배포 완료로 표시하지 않는다.

## 아직 남은 본래 문제

현재 불만의 원본·실행 버전·보류 문구는 추가 확인 중이다. 옹알이를 놓친 원인이 시각 표본만인지
확정하지 않았다. 위250JPEG는 이전 실패 영상의 같은10초이며 새 독립 정확도 평가 자료가 아니다.
후속 우선순위는 음성의 좁은 구간 근거와 시각 시계열을 안전하게 연결하는 것이다.
얼굴/입 움직임만으로 아기 발성 판정을 뒤집거나 TV·성인의 소리를 아기로 간주하면 안 된다.

실행 자료는 ignored `work/visual-cadence-20261009/`, 기존250JPEG는 원위치에 보존한다.
원본/프레임/개별 특징은 커밋·외부 전송하지 않는다. 신규 대형 모델/클라우드/프로덕션 변경 없음.
