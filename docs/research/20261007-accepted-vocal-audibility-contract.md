# 인식 후 음량 보류의 재현 계약

2026-10-07 KST. 기준 Git `12e870c85eb43f762d1b316fe422a3d171a56252`,
게시 beta33. 사용자 요청은 의미 있는 인식 개선이 나올 때까지 계속 진행하는 것이다.
이 계약은 결과를 보기 전에 고정한다. 모델 교체·학습·임계값 fitting은 하지 않는다.

## 재현 질문

입력 무음 기준은 cleaned strongest-second RMS .003이지만 표현 단계는
100ms RMS .012 이상인 비율 .04를 별도로 요구한다. 넓은 infant-presence만
예외다. 작은 실제 소리에서 YAMNet이 기존 기준으로 사건을 승인했는데
표현 단계에서 QUIET로 탈락하는지 frozen Android 실행으로 확인한다.
이는 모델이 발성을 못 찾는 문제와 구분해야 한다.

## 고정 입력·실행

- 기존 권리 기록이 있는 `work/ast-public-paired-01/corpus`에서
  cry/laugh/babble/babble_seven_month/conversation/generic_laugh/piano/vacuum을 사용한다.
  각 원본과 cleaned strongest-second RMS .006/.009로 감쇠한 입력만 비교한다.
  원본보다 키우지 않으며 원본을 덮어쓰지 않는다. 원본 hash를 전후 대조한다.
- silence/dc/rumble/noise 4개는 원본 그대로 대조한다. 합계28조건.
  공개 음원의 감쇠는 SNR/시간축을 보존하는 개발 조건이며 별도 아기 수가 아니다.
  caption은 사건·신원·욕구의 독립 정답이 아니다. 사적 아기 입력은 이 실험에 없다.
- frozen caption Android app/test 한 세트를 공용 MoaQA35에 임시 설치한다.
  기존 `AstPublicAudioProbeTest`의 전체 YAMNet/AST/후처리 결과를 실행한다.
  production 패키지를 설치/초기화하지 않는다. 새 모델/새 AVD를 만들지 않는다.
- 최초 실행600초 상한. 오류·불완전/skip은 통과로 보고하지 않는다.
  고정 JSON은 run ID/PCM SHA/실행완료/조건 수를 확인한 뒤 집계한다.

## 판정과 다음 수정 경계

1. 실제 decision에 사건이 있으나 최종 QUIET인 사례가 있으면 후처리 누락으로 기록한다.
   결과가 없으면 이 가설을 제품 수정 근거로 쓰지 않는다.
2. 수정 후보는 기존 사건 승인·감정 충돌·화자/배경 guard를 유지하며,
   **승인된 소리창 자체의 측정 음량**만 사용할 수 있다. 다른 시간의 큰 성인 말이나
   음악을 빌려 아기 소리를 승인하면 실패다. 단순 전체 RMS 예외는 금지한다.
3. 같은 고정 입력의 기준/후보에서 인식된 사건·기존 출력 보존, 추가 출력 및
   control 오인 여부를 비교한다. 잡음/성인 오인이 증가하면 미채택한다.
4. 이득이 있으면 unit/native·기존53조건·저장/업데이트 계약과 코드 검토로 진행한다.
   재현·합성 검사만으로 인식률/모든 휴대폰 성능/실제 욕구 이해를 주장하지 않는다.
