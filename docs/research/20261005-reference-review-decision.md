# 아가톡 인식 개선 — 추가 조사와 적용 결정

2026-10-05. 최신 사용자 요청: 제공 자료와 추가 공개 자료를 조사하고, 타당한 개선·UltraQA·코드
리뷰를 완료한 뒤 **Play 비공개 테스트 업데이트**까지 진행한다. 공개 프로덕션·상품 등록은 대상이 아니다.
소리·영상·기록은 온디바이스이며 외부 원본 전송을 추가하지 않는다.

## 조사 결과를 읽는 순서

1. [공급 논문·데이터·웹주소 원문 감사](20261005-infant-papers-audit.md)
2. [공급 GitHub/HF·잡음 처리 후보 감사](20261005-infant-repos-audit.md)
3. [작은 멀티모달·양자화 모델 추가 조사](20261005-compact-model-update.md)

제공 주소는 항목별로 확인했다. 전문·공개 초록·서지·404·인증 제한을 구분했다. 인터넷의 모든
자료를 찾았거나 유료/차단 원문까지 읽었다는 뜻은 아니다. 발견 경로는 Exa 검색, GitHub 공식 API,
Hugging Face 모델 카드·파일 API, arXiv/PMC/출판사 원문·Crossref, Google 공식 문서다.
검색 포털 자체와 원문 논문을 별개의 연구로 세지 않았다.

## 결정

**이번 업데이트는 기존 소리 인식 경로의 확인된 누락을 줄인다. 새 LLM 탑재를 필수 조건으로 삼지 않는다.**

| 발견·근거 | 결정과 적용 범위 |
|---|---|
| 실제 Android에서 2초 같은 작은 소리가 20초 무음 패딩 후 `SILENCE`로 차단됨 | 모든 연속 1초 창을 훑어 무음 여부를 판단. 16kHz 원음 길이·시간축·모델 입력을 보존. `.003` 무음 기준과 사건 승인 점수는 유지 |
| 실패 안내도 전체 평균 RMS를 써서 짧고 또렷한 소리를 작다고 설명할 수 있음 | `.012` 안내 기준에 같은 창 단위 RMS 사용. 관찰을 실패하면 보류는 유지 |
| 앞서 검증한 AST가 알려진 약국 원본 10/20초 옹알이 누락을 회복 | 명시적 AST beta 패키지에 포함. 원음 전체를 중첩 10초 창으로 검사. 일반 정확도나 독립 영아 시험으로 확대하지 않음 |
| 성인 음성용 denoiser의 아기 발성 보존 근거가 없음 | 기존 DC/80Hz 저주파 필터 유지. GTCRN 등을 검증 없이 원음 대체 경로로 넣지 않음 |
| 큰 LLM이 소리 판별을 더 잘한다는 영아 근거 부족, Gemma 실제 합성 의미 검사 미통과 | Gemma 미탑재. 혼합2/4/8bit QAT가 이미 적용됐으며 추가 양자화가 의미 오류를 해결한다고 약속하지 않음 |
| MiniCPM-V4.6은 더 작고 Android 코드 있음 | 시각 전용 연구 후보. 음성이 없어 단독 AV 교체품으로 채택하지 않음 |

현재 영상 관찰은 선택 구간의 시간순 표본을 사용한다. 10초20개/20초40개 표본을 봤다는 사실은
20초의 모든 의미·발성 주체·욕구를 이해했다는 증거가 아니다. 웃음/울음/옹알이와 배고픔/졸림의
원인은 다른 과제다. 모순되는 소리를 억지로 하나의 욕구로 바꾸지 않는다.

## 다음 비교 후보의 우선순위

| 후보 | 해볼 이유 | 채택 전 확인할 것 |
|---|---|---|
| **EfficientAT mn04** | 실제 4.07MB 학습 모델에 옹알이·아기 울음·아기 웃음 라벨 | 전처리/라벨 수치 일치, Android 변환, 영아 누락과 성인/TV 오인의 동시 평가. 공개 모델이 현재보다 좋다는 결론은 아직 없음 |
| **GTCRN + sherpa-onnx** | 작은 ONNX와 공식 Android 잡음 제거 API | 같은 원음의 무처리/처리 쌍에서 옹알이·웃음 손실, 성인 겹침, 잔향, 변형·지연 확인. speech 품질 점수만으로 채택 금지 |
| **LittleBeats W2V2-LL4300h** | 가정 영아 자료 사전학습·실제 공개 분류 head | 권리, head/recipe/라벨 복원, 14~18개월 및 웃음 범위 부족, 크기/CPU 비용. 교사/비교 모델부터 검토 |
| **MiniCPM-V4.6** | 약1.638GB Q4+projector·Android demo | 원음 분석과 별도 시간 정렬. 얼굴만 보고 배고픔 추정 금지. 영아 얼굴 관찰·한국어·발열·기기별 fallback 검증 |

이 후보들의 새 모델 다운로드/추론/앱 탑재는 이번 문헌 조사에서 수행하지 않았다. 조사한 것과
실제로 제품에 들어간 것을 혼동하지 않는다. 성능은 test 아기/가족 단위 분할, 서로 다른 원본,
겹치는 성인·TV·무음·웃음 대조, 보류율과 승인 오인, 전체 분석 지연을 함께 보고 판단한다.
몇 개 알려진 실패 영상의 성공률을 유료 제품의 정확도로 보고하지 않는다.

## 잘못 적용하기 쉬웠던 참고자료

- `VisionInfantNet`: 확인된 내용은 `VocalBaby`와 동일 audio pipeline/모델 blob. 영상 모델이 아니다.
- `VocalMat`: 검색된 구현은 생쥐 초음파. 영아 분석 모델로 채택하지 않는다.
- arXiv2402.06888와 PMC12126097: 동일 연구. 독립 증거 두 건으로 세지 않는다.
- LittleBeats의 “Visualizations”: 오디오 표현의 시각화이지 영아 영상 인식 모델이 아니다.
- 일부 cry 프로젝트의 95/99%: 증강·oversampling 이후 분할 또는 독립 아기 시험 불명확.
  부모에게 말할 수 있는 우리 앱의 정확도 수치가 아니다.
- VocalBaby의 openSMILE, HomeBank/CryCeleb/ChildVox: 코드 공개와 상업 모델·데이터 사용권은 다르다.
  자세한 제약과 미확인은 위 감사 문서에 기록했다.
