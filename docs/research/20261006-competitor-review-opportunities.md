# 경쟁 앱 공개 리뷰로 보는 아가톡의 품질·반복 가치 실험

조사일: **2026-10-06** · 대상: 한국의 **6~18개월 아기 부모** · 범위: 경쟁·인접 앱 6개, 공개 스토어에 보인 사용자 리뷰와 공식 설명. 연구 문서만 작성했으며 앱·상품·배포는 변경하지 않았다.

## 1. 이번 조사에서 얻은 판단

**한국 Play 1위 목표의 다음 순서는 인식·문장 품질 → 장면 저장·파일 공유 → 다시 보고 싶은 기록 → 가격 검증이다.** 이는 순위 알고리즘을 알아냈다는 결론이 아니라, 아래의 실제 사용자 불만과 반복 가치 사례를 아가톡에 적용한 우선순위 가설이다. 현재 한국 Play 순위, 설치 증가 속도, 경쟁사 매출·갱신률은 확인하지 못했다. 다운로드 누적치·스토어 평점·판매자의 정확도 수치로 1위 가능성을 계산하지 않는다.

직접 읽은 리뷰에서는 ChatterBaby·Nanni의 비슷한 확률 결과가 도움이 적다는 의견, MeowTalk의 인식 실패와 광고·결제 가림에 대한 불만, BabyTalk의 뜻을 믿고 행동했는데 아기가 계속 운다는 불만이 나타났다.[C-P][N-P][M-P][T-A] **아가톡에서 대사 종류만 늘리는 것으로 인식 누락과 관찰에 맞지 않는 문장을 해결했다고 볼 수 없다.** 최신 HANDOFF는 표현 개선과 욕구 모델 미확보를 구분한다.[I1]

반대로 Nanni에는 분석을 쓰지 않아도 일상 기록 때문에 유용하다는 리뷰와, 울음 이해를 배운 뒤 더 이상 앱이 필요하지 않았다는 리뷰가 함께 있다.[N-P][N-A] FamilyAlbum에는 가족 공유·월별 정리·추억 재열람이 실제 가치로 서술되지만, 선택·정렬 오류와 조부모가 쓰기 어려운 흐름도 지적된다.[F-K][F-P][F-A] 아가톡은 온디바이스 기록과 무료 MP4/PNG 공유에서 이 반복 가치를 시험할 수 있다. 외부 가족 DB·로그인·클라우드 공동 앨범 도입이 이 조사에서 요구된 것은 아니다.

## 2. 조사 방법·표본·한계

- `research` 스킬의 원문 연구 지침과 `agent-reach`의 웹/Jina Reader 경로를 사용했다. 기존 [경쟁 기능·문장 조사](20261001-competitors-and-voice.md)와 [BM·리텐션·가격안](../../outputs/Jigeum-BM-Retention-Pricing.md)을 읽고, 이번에는 사용자 리뷰 원문을 새로 조회했다.
- **6제품 중 5제품에서 서로 다른 사용자 리뷰 31개**를 읽었다. App Store 본문은 같은 리뷰를 접힌 카드와 펼친 본문에서 두 번 출력하므로 작성자·제목·날짜로 중복 제거했다. 개발자 답변은 사용자 리뷰 수에 넣지 않았다. babba는 현재 조사 경로에서 리뷰 0개다.
- Google Play의 공개 상세 페이지에는 보통 리뷰 3개, App Store에는 4개가 보였다. 전체 리뷰를 수집하거나 최신순·별점별 무작위 추출을 하지 않았다. **스토어가 선택한 노출 표본**이므로 불만 빈도·전체 고객 만족·매출 원인을 추정할 수 없다. 일부 과거 리뷰는 현 버전의 결함을 증명하지 않는다.
- 지역은 **페이지 storefront**이다. `gl=US`, `/us/` 또는 `gl=KR`를 지정했으나 리뷰 작성자의 거주지·기기 지역을 확인한 것은 아니다. 한국 공개 리뷰는 FamilyAlbum 3개만 확보했다. 미국·다른 월령의 리뷰를 한국 6~18개월 전체 수요로 일반화하지 않는다.
- 리뷰의 정확하다/틀리다/5%만 된다 같은 표현은 사용자의 경험 진술이다. 정답 라벨·앱 버전·입력·표본이 없어 독립 성능 수치로 쓰지 않는다. 긍정 리뷰도 진위·광고/보상 관계를 확인하지 못했다. 부모가 배고프다고 생각했다는 것은 실제 욕구 정답의 검증이 아니다.
- 링크는 실제 조회한 공식 스토어·공식 홈페이지다. 리뷰 고유 URL이 공개 본문에 없어 해당 리뷰가 보인 스토어 URL과 작성자·날짜·제목으로 식별한다. Jina의 반환 HTTP200과 원본 페이지 성공은 다르므로 원문 내부의 404·본문 존재를 확인했다. Reader 캐시 여부와 생성 시각을 검증하지 않아 초 단위 현재 상태를 보장하지 않는다.
- 앱 설치·녹음 입력·결제·패킷 검사·비공개 Console 접근은 수행하지 않았다. 판매자 정확도·다운로드·의학적 연구 홍보를 현 소비자 앱의 독립 검증 결과로 채택하지 않았다.

## 5. 구체적 실험 3개

다음 표본 수·수치·기간은 **실행 전 팀 가설**이다. 업계 평균이나 확보한 실적이 아니며 이 문서에서 모집·시험을 시작하지 않았다. 참여자가 자발적으로 제공하는 익명 집계·인터뷰를 사용하고, 원격 행동 SDK·외부 아기 기록 DB·원음 자동 업로드를 만들지 않는다. 원본이 필요한 품질 시험은 명시적으로 사용 동의를 받은 로컬 자료만 사용한다. 자동 이벤트 집계가 필요하면 별도 구현·검토해야 하며 현재 전 설치 행동을 측정하고 있다고 말하지 않는다.[I2][I3]

### 실험 1 — 실제 짧은 발성을 잡고 장면과 맞는 말을 만드는가

**질문:** 안내문 개선·문장 수 증가 외에, 새 실제 입력에서도 발성을 회복하며 관찰과 충돌하지 않는 재미가 나오는가? ChatterBaby/Nanni의 반복·준비 실패와 MeowTalk/BabyTalk의 상황 충돌을 함께 다룬다.

- **자료:** 기존 개발/튜닝 자료와 다른 6~18개월 가구의 최소 **30개** 실제 입력과 **20개** 비아기 대조(성인 말, TV, 음악·장난감·무음 등). 아기·원본 출처 단위로 분리한다. 짧은 발성, 앞/뒤 창 경계, 보호자 겹침, 웃음/울음 혼합을 포함하고 Android 최소 두 기기군에서 실행한다. 개수 충족이 일반 정확도 인증은 아니다.
- **평가:** 두 명의 독립 관찰자가 원음에서 들리는 사건·구간만 표시한다. 배고픔/피로/의도 정답은 붙이지 않는다. 현재 엔진과 후보의 누락·비아기 오인·실행 실패·처리시간·최종 문장을 같은 입력에서 비교한다. 이어 **12가구**가 자기 입력 결과의 상황 적합성·자연스러움·보관 의사를 평가한다. 내부 다양성 변경은 정답 모델로 평가하지 않는다.
- **진행 기준:** 새 자료에서 실제 누락이 감소하고 비아기 오인이 증가하지 않아야 다음 채택 검토로 이동한다. 정성 관찰에는 발성을 분명히 들었는데 못 잡은 사례와 결과 충돌 사례를 전부 남긴다. 가구 평가에서 최소 9/12가 첫 결과를 상황에 맞는다고 판단하는 것을 탐색 목표로 두되 모집 편향·불확실성을 명시한다. 이 수치를 독립 욕구 정확도로 홍보하지 않는다.
- **중단·수정:** 아기 소리를 놓치는 양상이 그대로라면 공유 디자인·유료 노출 실험보다 입력/시간창·모델 문제를 먼저 해결한다. 비아기 오인이 늘면 더 많은 대사를 만드는 변경을 채택하지 않는다. 실패 입력의 안내가 원인을 오인시키는지도 동시에 확인한다.

### 실험 2 — 한마디와 실제 장면을 무료로 보관·공유할 가치가 있는가

**질문:** 분석 결과를 읽는 경험이 사용자가 다시 열어 보는 실제 추억으로 이어지는가? 원음 저장의 사용자 증거 부족을 직접 채우고 FamilyAlbum의 수신자·선택 마찰을 검증한다.

- **설계:** **20가구·14일**, 최소 첫 결과 1회 완료 뒤 참여자가 기존 `문장 저장`과 `장면과 함께 저장`을 자율 선택한다. UI 시험이 필요하면 10가구씩 현재 흐름/짧은 보관 선택 설명을 비교하되 무료 기능·표시 품질은 동일하게 유지한다. 실제 대규모 A/B 우열을 이 표본으로 주장하지 않는다. 베타는 전체 기능을 무료로 열기 때문에 유료 전환을 측정하는 시험이 아니다.
- **평가:** 문장만/MP4 선택 이유, 저장 취소·실패, 기록을 다시 연 날짜 수, 가족에게 실제 전송했는지, 받은 파일을 가족이 재생했는지 인터뷰와 참여자의 집계로 확인한다. 파일을 보냈다는 사실은 메시지 내용을 수집하지 않고 참가자가 보고한다. 공유 상대 선택과 전송은 OS 공유 화면에서 사용자가 수행한다.
- **진행 기준:** 기술 검증에서 기존 기록·원음·MP4가 업데이트/재열람 후 보존되고, 수신자 10명 중 9명 이상이 별도 설치/결제 없이 재생하는 것을 먼저 만족시킨다. 가치 가설은 20가구 중 최소 10가구가 7일 내 스스로 과거 장면을 다시 보거나 새 장면을 두 번째 날 저장한 경우 탐색을 이어간다. 저장 이유가 대사/목소리/영상 중 무엇인지 함께 기록한다.
- **중단·수정:** 저장은 많아도 다시 보지 않으면 공유 버튼 추가보다 기록 제목·날짜·재생 접근을 개선한다. 문구가 재미있지만 장면 보관 필요가 없다는 결과도 인정한다. JSON/CSV/PDF에 미디어가 포함된다고 오해하면 MP4 별도 보관 설명부터 수정한다.[I2]

### 실험 3 — 실제 재방문 뒤 추가 기능의 가격·갱신 조건을 이해하는가

**질문:** 첫 호기심을 넘은 가족에게 긴 촬영·분석, 시각 관찰, PDF가 추가 비용을 낼 이유가 되는가? Nanni의 자연 졸업과 결제 압박 사례를 반영한다.

- **설계:** 실험 2 뒤 가능한 **30~50가구를 28일** 관찰해 서로 다른 두 날의 새 저장과 이전 기록 재열람을 먼저 확인한다. 이후 실제 화면의 기능·무료/전체 경계를 보여 주는 인터뷰에서 월 **4,900원** 자동 갱신과 **3개월12,900원** 일회 결제라는 기존 *조사 가격안*의 이해·선택 이유·무료 계속 사용 선호를 묻는다. 표시 순서는 교대한다. 가상 가격 이해/의향 조사이며 상품 등록·거래·해지·환불은 실행하지 않는다.[I2][I3]
- **평가:** 전체 참여자 기준 재방문과 반복 가치가 있는 참여자 기준 지불 의향을 각각 제시한다. 실제 결제 전환·갱신·최적가격으로 환산하지 않는다. 무료 사용을 원하는 이유가 충분한 무료 가치인지, 인식 신뢰 부족인지, 기간을 짧게 보고 있는지 나눈다. 전체 이용권이 더 정확한 번역이나 마음 학습을 제공한다는 오해도 확인한다.
- **진행 기준:** 무료에서 핵심 목적을 완성했다는 답변 80% 이상, 결제 압박 10% 미만, 가격/자동 갱신·무료 지속/기존 기록 유지 조건 이해 90% 이상을 탐색 목표로 둔다. 추가 기능에 대한 구체 이유가 없으면 가격을 내리거나 무료 저장을 빼는 방향으로 해결하지 않는다.
- **다음 단계:** 상품 등록·실거래는 현재 보류다. 후속 사용자 승인과 실제 Play 설정/거래 검증이 갖춰졌을 때만 구매·첫 갱신·환불을 별도로 측정한다. 베타 풀 개방 사용률이나 인터뷰의 구매 의사를 실제 유료 수요로 보고하지 않는다. 1위 목표용 광고 확장·상위 순위 예상은 실제 유지·전환 증거 이후 검토한다.

## 6. 현재 계약을 지키는 실행 순서

1. **P0 품질:** 최신 표현 개선과 일반 인식률 개선을 구분하고, 새로운 아기/비아기 입력으로 누락·오인·상황 충돌을 해결한다. 부모의 의미 추측을 영아 의도 정답으로 쓰지 않는다.[I1][I2]
