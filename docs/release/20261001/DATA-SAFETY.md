# 최종 연결 후보의 데이터 보안 선언

2026-10-01 · 0.4.5/code12 connected · Play Console에 저장 완료. 저장 성공 메시지와 대시보드 **10/11 완료**를 확인했다. 공개 검토 전송·출시는 하지 않았다.

## Console 응답

| 항목 | 응답 | 근거 |
|---|---|---|
| 필수 데이터 유형의 외부 처리 | 예 | 구매 검증 요청과 Cloud 접속 로그 |
| 전송 중 암호화 | 예 | HTTPS 전용, cleartext 금지, 구매 리다이렉트 금지 |

| 삭제 요청 방편 | 아니요, 90일 이내 자동 삭제 | 운영자가 수집하는 요청 데이터는 서버 메모리, 접속 로그는 30일. 로컬 기록 삭제와 Google Play 거래 보존은 별도로 고지 |
| 독립 보안 인증·UPI | 신청하지 않음 | 해당 인증을 받은 사실 없음 |

|---|---|---|---|---|---|
| 구매 내역 | 예 | 아니요 | 예 | 선택 | 앱 기능, 사기 예방·보안·규정 준수 |
| 기기 또는 기타 ID | 예 | 아니요 | 아니요 | 선택 | 앱 기능, 사기 예방·보안·규정 준수 |
| 진단 | 예 | 아니요 | 아니요 | 선택 | 애널리틱스, 사기 예방·보안·규정 준수 |

구매 내역의 일시 처리는 **운영자의 검증 API가 받은 구매 토큰과 조회 상태**에 대한 응답이다. 요청 완료 후 구매 결과를 DB·파일에 저장하지 않는다. Google Play가 직접 생성·보관하는 거래 기록이 삭제되거나 일시 처리된다는 뜻이 아니다. 기기 ID에는 설치 UUID와 접속 IP가 해당하며, UUID의 서버 처리와 달리 IP 접속 로그가 30일 남으므로 유형 전체를 일시 처리로 표시하지 않았다. 진단에는 응답 상태·처리 시간 등 서비스 장애 조사용 접속 메타데이터가 포함된다.

무료 로컬 기능에는 이 API 전송이 필요 없다. 구매·복원·심사 확인과 온라인 정책 열기를 선택하는 경우 서버 접속이 발생한다. '선택'은 해당 기능 안에서 검증을 생략할 수 있다는 뜻이 아니다.

## 공유 예외와 제외한 항목

- Google Cloud는 개발자 대신 검증·호스팅·로그 처리를 제공한다. 서비스 제공업체 예외를 적용했다. Google Play 직접 결제는 별도 관계이며 운영자가 카드·은행 정보를 받지 않는다.
- JSON/CSV/PNG/PDF는 보호자가 시스템 저장·공유 화면에서 대상 앱·위치를 고른다. 사용자 주도 전송 예외를 적용했다. 수신 앱·클라우드의 개인정보 처리까지 '없다'고 보장하지 않는다.
- 아기 원음·영상·얼굴 관찰·문장·메모·월령은 앱의 외부 자동 수집 항목으로 신고하지 않았다. 기기 안에서 처리하며 서버 요청 본문에 넣지 않는다.
- 위치를 추론하거나 위치 권한을 요구하지 않으므로 위치 유형을 선택하지 않았다. 접속 IP는 ID에 포함했다.
- MediaPipe/Billing CCT 진단 경로는 현재 SDK·권한 구성에서 저장·전송 전에 실패한다. 공식 opt-out이나 SDK 전체 무통신으로 확대하지 않는다. 이번 '진단' 신고에는 실제 Cloud 요청 로그가 포함된다.
- '애널리틱스'는 Google 양식에서 장애 진단·앱 상태 모니터링을 포함하는 정의다. 광고 추적·아기 행동 분석 SDK를 추가한 것이 아니다.
