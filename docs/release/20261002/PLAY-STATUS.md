# Play 비공개 테스트 진행 상태 — 0.5.6/code20

확인일: 2026-10-02. 계정 Yeolmae, 앱 **아가톡 - 지금 내 기분이 그래**, 패키지 `com.moa.babylanguage`.

## 현재 결론

**정식 AAB 업로드와 Alpha 출시 저장은 완료했다. Google 검토 전송은 계정 정보 보완 때문에 아직 완료하지 못했다.** 비공개 테스트 참여 기간은 시작되지 않았다.

## 완료한 작업

- 한국어 기본 등록정보의 앱명·설명·아이콘·그래픽·실제 release 스크린샷 4장을 최종 저장했다.
- 비공개 Alpha의 대상 국가는 대한민국으로 지정했다. 프로덕션과 동기화하지 않았다.
- `아가톡 비공개 테스트` 이메일 목록을 만들고 운영자 계정 하나만 넣었다. 목록에 있는 1명은 참여 완료 수가 아니다. 외부 테스터 명단은 아직 없다.
- 의견 수신 주소는 기존 공개 지원 이메일로 저장했다.
- 최신 `outputs/Agattok-0.5.6-release-code20.aab`를 업로드했다. SHA256 `586a2bd08b97093da0bc65efdf1245d0de69d5aac994d4d17e465e4c6333af42`.
- Console이 **20 (0.5.6), 최소 API26, target36**으로 인식했다. 이전code18은 새 출시에서 제외했다.
- 출시명 **`0.5.6 (20) - 앨범 저장 테스트`**, 한국어 출시 노트를 저장하고 ‘변경사항이 저장되었습니다’ 모달을 확인했다. 전체 기능 sideload preview는 업로드하지 않았다.
- 게시 개요에release20 Alpha 출시·국가·테스터·스토어·기존 선언 등 **14개 변경사항**이 제출 대기 중으로 표시됐다. [업로드·저장 증거](play-release20-saved.jpg). 관리형 게시가 꺼져 있으므로 승인 후 해당 비공개 트랙에 게시되는 구성이다. Console의 ‘전체 출시 시작’은 Alpha의 표시이며 공개 프로덕션 출시를 뜻하지 않는다.
- Console 경고2개(가독화 파일 없음, native debug symbols 없음)는 남아 있다. 현재 minifyfalse이므로 첫 경고의 가독화 파일은 생성하지 않는다. 실제 제출 차단은 아래 계정 정보 항목이다.

## 제출을 막는 실제 항목

release20 저장 후 게시 개요의 빠른 검사 진행 표시가 끝나고 **‘문제1개가 모든 변경사항에 영향을 미칩니다’**로 바뀌었다. ‘문제 보기’를 펼쳐 **계정 세부정보 업데이트 — 한국 개발자 추가 정보**가 유일한 현재 항목임을 다시 확인했다. 전송 버튼은 비활성 상태다. [최신 차단 화면](play-release20-blocker.jpg). 이전code18 때의4/5·참여0명 표시를 새 버전의 최신 실측으로 재사용하지 않는다.

현재 계정은 **개인**이다. 이전에 공개 전화 항목의 국제 형식을 보완하고 문자 인증을 요청한 뒤 코드 입력→확인→변경사항 저장을 사용자에게 인계했다. **사용자의 결제 인증 통과 보고 후 2026-10-02에 실제 Console을 다시 확인했으나, 공개 ‘개발자 전화번호’ 필드는 빈칸이며 제출 버튼은 여전히 비활성이다.** 기존 비공개 연락용 전화는 ‘전화번호 확인됨’이지만 공개 전화 항목에는 확인 완료 표시가 없다. 공개 전화 입력·문자 인증·변경사항 저장이 필요하다. 이전 문자 요청이 현재도 대기 중이라고 추정하거나 비공개 연락용 전화의 확인을 공개 전화 인증 완료로 혼동하지 않는다. [재확인한 제출 차단 화면](play-release20-status-recheck.jpg).

[Google 공식 안내](https://support.google.com/googleplay/android-developer/answer/3255733?hl=ko)는 개인에게 문의 전화번호를 요구한다. 유료 앱/인앱 구매가 있는 대한민국 **업체**에는 사업자등록번호·통신판매 신고번호·신고기관도 요구한다. 첫 안내에서 빈 사업자 항목을 모두 필수라고 추정했으나 공식 문서와 개인 계정 화면을 확인해 정정했다. 공개 전화 인증/저장 후 Console을 다시 검사해야 하며, 이것만으로 모든 차단이 해소된다고 아직 단정하지 않는다.

전화 인증의 입력값·OTP·비공개 전화번호·사업자번호·원본 증명서는 이 문서/Git/증거 이미지에 넣지 않는다. 연락처 페이지와 게시 개요는 후속 작업용으로 유지했다. 인증과 저장이 실제로 끝나면 계정 차단을 다시 확인하고 사용자가 승인한 비공개 검토 전송을 이어간다.

## 참여 링크

Console이 표시한 주소: <https://play.google.com/apps/testing/com.moa.babylanguage>

**주소는 확인했으나 복사 버튼은 비활성이고 “앱을 게시하면 링크가 여기에 표시됩니다” 상태였다.** 지금 바로 설치 가능한 링크라고 안내하지 않는다. 계정 정보 보완 → 검토 제출 → Google 승인/트랙 게시 → 모집한 Google 계정을 이메일 목록에 추가 → 각 계정의 참여/설치 순서로 진행한다. 12명·14일 요건 충족이나 프로덕션 승인 완료가 아니다.

## 경고와 한계

- 출시 미리보기는 오류 없이 경고 2개: 가독화 파일 없음, 네이티브 디버그 기호 없음. 현재 `build.gradle.kts`의 release는 `isMinifyEnabled = false`다. 네이티브 기호 미제공은 관련 충돌/ANR 원인 분석의 한계로 남는다. [Console 경고 화면](play-validation-warnings.jpg).
- 현 검토본은 무료60초 촬영/10초 분석, 전체120초 촬영/20초 분석이다. **유료20초/30초는 사용자 최종 결정 전**이다. 현재 검증본으로 비공개 테스트를 준비하며 최종 상용 정책 확정으로 해석하지 않는다.
- 상품 미등록으로 Play 이용권 구매는 불가능하다. release의 실제 권한 검사를 유지한다. 전체 기능 개인 테스트는 다운로드 폴더의 sideload preview로 제공한다.
- 최신 QA는 로컬 계측246통과/0실패/1명시제외다. 서명 UI의 결과 저장 앞부분과 이후 기록 중심 통과를 함께 보존했다. [보고서](../../qa/gallery-0.5.6/README.md). 이번 업로드가 실기기·아기 의도 정확도·실제 구매 검증을 대신하지 않는다.

3. 승인된 14개 변경사항을 Google 검토에 전송하고 **검토 중** 상태를 확인한다.
4. Alpha 참여 링크 활성 여부, 게시 상태와 참여 대상을 확인한 뒤 이 문서/HANDOFF/NEXT를 갱신하고 커밋·푸시한다.
