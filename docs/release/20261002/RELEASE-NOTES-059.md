## Play 한국어 출시 노트

소리 분석이 어려울 때 이유를 더 자세히 알려드려요.
소리가 모인 구간이 있으면 짧게 다시 골라볼 수 있어요.
영상 관찰은 아기말이 나오지 않은 경우에도 확인할 수 있어요.
결과·저장 카드에 소리/소리와 표정/보호자 수정 여부를 표시해요.
소리 근거와 어울리는 입 모양이 관찰되면 답을 청하는 표현에 반영해요.
결과 카드의 화면 움직임을 줄이고 기존 기록을 유지해요.
테스트 기간에는 전체 기능을 이용할 수 있어요.

## 배포 시 제한

- 이번 변경은 보류 안내·재선택·시각 관찰·출처 보존 개선이다. 사용자 제공 영상 두 개의 발성 누락은 여전히 남아 있다.
- 동일 음성 비교에서 원본 float 모델 교체가 개선되지 않아 현재 모델과 승인 임계값을 유지했다. 아기 의도 정확도 향상이나 얼굴·목소리 주인 식별을 주장하지 않는다.
- 전체 기능 베타 120초/20초·200MB·시각·PDF 개방을 유지한다. 정식 release는 실제 이용권과 무료60초/10초·100MB를 유지한다.
- 기존 JSON v1은 가져올 수 있다. 새 JSON v2를 이전 앱으로 가져오거나 DB v2에서 이전 앱으로 다운그레이드하는 경로는 지원하지 않는다.
- 비공개 Alpha에 beta23 AAB만 제출한다. 비교용 release23은 제출하지 않는다.
