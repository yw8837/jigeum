# 장면과 함께 저장 — 0.5.5 구현 계약

사용자 요청: 텍스트만 저장되어 상황을 알 수 없다. 영상·음성·아가 번역을 함께 내려받게 한다. 표정만 해석하는 유료 기능의 가능성과 정확도 문제도 검토한다.

## 구현 범위

- 분석 결과에서 기본 선택된 ‘영상·소리 함께 보관’(녹음이면 ‘소리 함께 보관’)을 보여주고 ‘장면과 함께 저장하기’로 선택 구간을 보관한다. 사용자는 문장만 저장할 수도 있다.
- 선택 구간만 MP4로 렌더링한다. 영상은 전체 프레임을 보존하며 자막 영역을 별도로 둔다. 녹음은 문장 카드 영상에 실제 소리를 담는다. 편집한 최종 문장을 사용한다. 합성 아기 음성을 추가하지 않는다.
- 기록에서 장면 재생·번역 영상 내려받기·공유를 제공한다. 내려받기는 Android 파일 저장기를 사용하며 별도 저장소 권한이나 서버 업로드가 없다.
- 이미 생성한 결과의 보관/내려받기/공유는 무료다. 생성 시 적용된10/20초 분석 상한은 유지한다. 20/30초 상용 결정은 별도다.
- 파일은 앱 내부에 보관하고 기록 삭제/전체 삭제 시 함께 지운다. Google 백업과 FileProvider 원본 경로에서 제외한다. 공유는 제한된 수명의 복사본만 노출한다.
- 텍스트 JSON/CSV/PDF 백업은 미디어를 포함하지 않는다. 안내에 이를 명시한다. 기존 텍스트 기록에는 과거 원본을 복구할 수 없으므로 ‘장면 미보관’을 표시한다.
- 저장 실패/취소 시 기록 없는 영상·영상 없는 새 기록·완료되지 않은 내려받기 파일을 남기지 않는다. 이전 기록과 원본 가져오기 파일은 보존한다. 긴 처리 중 이탈/중복 실행을 제어한다.

외부 저장 제공자가 삭제를 거부하면 불완전 파일을 앱에서 강제로 지울 수 없다. 삭제 결과를 확인해 사용자에게 저장 위치에서 확인·삭제하도록 안내한다. 기기 내부 영상 삭제 실패는 DB와 함께 기록한 삭제 의도를 유지하고 다음 조회·실행에서 재시도하며 경고를 표시한다.

## 표정만 보기

현재 구현은 MediaPipe Face Landmarker의 얼굴 랜드마크와 입 열림 비율 관찰이며 감정/욕구 모델이 아니다. 독립 표정 번역 정확도 수치를 제시할 근거가 없다. 이번 요청에서 표정 단독의 의도 문장 생성은 추가하지 않는다. 유료 후보로는 얼굴이 잘 보이는 짧은 장면의 관찰 요약을 제안하되 아기 신원·연령·감정·배고픔 판정을 약속하지 않는다.
