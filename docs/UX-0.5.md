월령·소리/상황 수동 선택·후보 다시 뽑기는 계속 제거된 상태다. 기존 Cream/Ink/Sage와 승인된 캐릭터를 유지한다. 원본·파형·분석은 온디바이스이며 파형 표시에 별도 서버나 분석 API를 추가하지 않는다.

## 기술 경계

YAMNet은 일반 소리 분류기다. 영아 울음/옹알이/아기 웃음 후보를 보수적으로 선별하더라도 아기 신원이나 울음의 이유를 보장하지 않는다. Face Landmarker는 얼굴/입 열림 단서이며 아기 검출기·감정 분류기가 아니다. 영상 단서만으로 마음 문장을 만들지 않는다. 무료/유료 모두 같은 음성 근거가 필요하고 유료는 시각 관찰을 추가한다.

최대 60초 미디어 중 1–15초 구간을 선택한다. 재생과 실제 디코더/영상 프레임 추출이 같은 시작·끝을 사용한다. 분석 중 변경·백그라운드·뒤로 가기는 취소하고 늦은 콜백을 폐기한다. 복원 시 센서를 자동 시작하지 않는다.

## 검증

- 기존 실제 UI에서 녹음 없이 문장 저장 화면에 도달하는 회귀 재현.
- 선택 구간 앞/뒤가 다른 합성 미디어: 시간 이동이 실제 PCM·얼굴 샘플 구간에 반영.
- 무음, 무음 트랙, 일반 말소리, 임계값 미달, 모델 오류에서 문장 없음.
- 녹화/녹음·재생·다시 선택·재촬영·취소·권한 거절·백그라운드·60초 상한.
- 무료 음성 허용, PENDING·만료·지연 콜백에서 시각 분석 금지, 기존 결과/기록 보존.
- 작은 화면/200% 글자와 실제 저장·공유 회귀. 새 서명 APK는 0.4.5와 다른 이름.

이 문서는 방향과 승인 기준이다. 통과 여부는 새 QA 실행 보고서로 별도 기록한다.

최신 이름: **아가톡 - 지금 내 기분이 그래**. 앱서랍 표시명은 **아가톡**. 패키지·저장소·기존 기록은 유지한다.

## 재미와 상황 적합성 계약

결과는 **소리를 바탕으로 상상한 아기말**이다. 울음에는 도움·곁에 있기, 웃음에는 함께 웃기, 옹알이에는 이야기 참여 문구를 사용한다. 배고픔·졸림·통증·특정 사람/장난감을 알아냈다는 문구는 자동으로 만들지 않는다. 보호자 조언은 별도 영역이다.

파형에서 만든 임시 wordingKey는 같은 의미군 안의 말투만 고른다. 기분/욕구 라벨에 영향을 주지 않고 저장·전송하지 않는다. 같은 PCM은 고정 결과, 다른 파일도 우연히 같은 문장이 나올 수 있다. 문구 수가 늘었다고 분석 정확도가 오른 것은 아니다.

0.5는 일반 모델 점수 최대값과 전체 구간 에너지로 규칙을 적용한다. 프레임별 아기 발성 정답·잡음 분리·욕구 학습은 아직 없다. 현재 보류 임계값도 실제6~18개월 클립으로 보정하지 않았다. 실제 사용성/적합성 승인은 [후속 평가](NEXT.md)에서 별도로 확인한다.
