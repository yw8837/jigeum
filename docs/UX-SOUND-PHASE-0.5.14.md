# 짧은 발성 누락 보완과 실패 안내 — 0.5.14 후보

사용자: 인식 실패 안내만 길어지고 체감 개선이 없다. 기존 code27을 기준으로
실제 모델의 누락 회복을 확인하고 안내를 줄인다. 온디바이스·기존 이용 범위·원본 보존 유지.

## 구현 범위

- 현재975ms 기본 분석에서 아기 발성 미확정/배경 우세일 때만487.5ms 옮긴 두 번째 분석을 수행한다.
- 기존 identity floor에 도달한 영아 후보가 한 번이라도 있으면 재검사하지 않는다.
  이미 읽은 후보의 반복 부족에 따른 보류와 모든 영아 후보를 놓친 경우를 구분한다.
- 전체 원음을 한 번만 필터링하고 같은 표본을 사용한다. 첫 분석은 전체 구간을 유지한다.
- 두 번째 분석도975ms 간격의 독립 시간열이다. 같은 발성을 겹친 창 두 개로 세어 통과시키지 않는다.
- 두 번째 시간열 단독으로 기존 기준을 통과해야 하며, 두 시간열 전체의 반대 사건/충돌 점검도 통과해야 한다.
  결합 시간열은 거부 검사에만 사용하고 결과/길이/반복 횟수에는 사용하지 않는다.
- 기존에 승인된 결과, 웃음/울음 혼합 보류, 무음/파일/모델 오류는 이 재검사의 대상이 아니다.
- 불확실한 결과를 다시 같은 문장으로 꾸미거나 임계값을 낮추지 않는다. AST의 기존 회복은 보존한다.
- 제품 순서는 기본 YAMNet → 기존 AST 보완 → 아직 미확정인 경우에만 다른 창 위치다.
  추가 분석의 일반 실행 오류는 기본+AST 결과를 유지하고 취소는 전파한다.
  기존 `analyzeDetailed` baseline API와 조사 도구의 비교 기준은 유지한다.
- 실패 안내는 한두 문장. 실패 시 길고 기술적인 시각 관찰은 기본으로 펼치지 않고 원할 때 열어본다.
