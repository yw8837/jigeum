# 아가톡 0.5.7 · 사용자 피드백 반영

## 목표

기존의 귀엽고 차분한 가족 분위기를 유지한다. 부모가 한 손으로 촬영을 시작하고, 원하는 순간을 고르고, 현재 이용 범위와 결제 위치를 찾기 쉽게 만든다.

## 변경 계약

- 홈의 번역 시작 버튼은 하단에 고정한다. 최근 기록을 스크롤해도 가리지 않는다.
- 촬영의 시작·종료와 구간 분석의 실행 버튼은 하단에 고정한다. 촬영 자체는 사용자 동작으로만 시작한다.
- 구간의 시작·끝을 표시하고 손잡이를 두껍게 한다. 선택 영역 밖을 누르면 길이를 유지하며 해당 순간으로 이동한다. 이동 막대에는 0.5초 앞/뒤 버튼도 제공한다. 수직 스크롤이나 손잡이 드래그를 탭 이동으로 처리하지 않는다.
- 홈과 돌봄에서 이용권으로 진입한다. 돌봄에는 현재 범위·구매 복원·기기 기록 관리·분석 근거·정책·문의·돌봄 힌트를 배치한다. 새 프로필 입력이나 앱 로그인을 추가하지 않는다.
- 표지는 기존 세 가지와 ‘분홍빛 미소’를 2×2 표지 미리보기로 제공한다. 선택한 표지가 실제 PDF에도 적용된다.
- 홈과 돌봄에서 분석 근거로 진입한다. 실제 도구(YAMNet/MediaPipe)와 실행 자료(LiteRT), 연구·평가 후보(voc2vec/librosa)를 구분한다. 논문 지표를 앱의 의도 정확도로 표현하지 않는다.

## 테스트 설치본과 Play의 차이

무료 60초 촬영/10초 분석, 전체 이용권 120초/20초 정책은 유지한다. **Play 테스터 명단에 등록되는 것만으로는 구매 권한이 생기지 않는다.** 전체 기능은 sideload preview에서 열고, release는 실제 이용권 검사를 유지한다. 이용 범위를 홈·돌봄·촬영 하단에 표시한다. preview에서는 구매 상품이 없는 상태를 결제 오류처럼 안내하지 않는다.

상품 등록·실거래·공개 프로덕션은 계속 보류한다. source는0.5.7/code21이며, 기존Play Alpha release20의 게시 상태와 새 산출물의 빌드·검증·제출 상태는 별도로 기록한다.
