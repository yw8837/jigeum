## 유지할 트레일러 흐름

아기응애/옹알이 → 당황한엄마아빠와물음표 → 앱실행/사용 → 아이시점문장 → 깨달은부모표정 → 부모가반응하고아기웃음/페이드 → 서비스이름모션타이틀.

최종 영상은 합성캐릭터와 앱캡처를 사용한다. 초기 첨부 영화장면 이미지는제품자산으로사용하지않았다. 폐기한사실적시안·이름·파일을 복구할 필요없다.

## 명확히 제외한 것과 미정인 것

**제외:** 원격아기DB, 앱회원가입, 원본미디어 자동업로드, 임의생성가격, 무검증유료해제, 아기감정/건강의정답판독 주장, 출석/부모순위 압박, 비밀키커밋.

**미정:** Cloud전용프로젝트, 운영HTTPS/정책도메인, 시행일, 업로드키 보관절차, 실제Play상품등록/거래검증, 실제ARM단말, 실제사용자 가격/리텐션 검증. 등록전 상표/스토어중복 확인도남음.
