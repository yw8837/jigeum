# 결정 이력과 사용자 선호

대화에서 선택하고 수정한 순서를 보존한 요약이다. 과거 제안과 현재 결정을 구분한다.

| 주제 | 현재 결정 | 배경과 이후 영향 |
|---|---|---|
| 제품·대상 | Android, 6~18개월 아기의 부모 | 옹알이·영상에서 아이 시점의 한마디를 보고 싶다는 최초 요구 |
| 이름 | **지금 내 기분이 그래** | ‘모아’는 작업명이었으며 사용자가 이름을 변경했다. `MoaAndroid`와 패키지 ID는 기술 호환 때문에 유지한다. |
| 저장소 | **jigeum**, 비공개 | 사용자가 짧고 직관적인 이름을 요청했다. 길게 제안했던 이름은 사용하지 않는다. |
| 핵심 가치 | 가능한 표현 문장 → 부모 확인·수정 → 기록·반응 | ‘배고파요/졸려요’라는 단답의 반복보다 자연스러운 표현을 원한다. |
| 정확도 | 논문 검토와 앱의 실측 정확도를 구분 | 사용자는 80%를 맞추라고 요구한 것이 아니라 객관적인 추정을 요청했다. 이후에는 확률 논의를 접고 제작을 우선하라고 지시했다. |
| 실제 모델 | YAMNet + MediaPipe | 별도 LiteRT SDK 직접 연동, librosa, voc2vec는 검토 후보다. 모두 사용했다고 보고하지 않는다. |

## 유지할 트레일러 흐름

아기의 응애·옹알이 → 당황한 엄마·아빠와 물음표 → 앱 실행·사용 → 아이 시점의 문장 → 깨달은 부모 표정 → 부모가 반응하고 아기가 웃는 장면·페이드 → 서비스 이름 모션 타이틀.

최종 영상은 합성 캐릭터와 앱 캡처를 사용한다. 처음 첨부한 영화 장면 이미지는 제품 자산으로 사용하지 않았다. 폐기한 사실적 시안·이름·파일을 복구할 필요는 없다.

## 명확히 제외한 것과 미정인 것

**제외:** 원격 아기 DB, 앱 회원가입, 원본 미디어 자동 업로드, 임의로 생성한 가격, 검증 없는 유료 권한 해제, 아기 감정·건강의 정답을 판독한다는 주장, 출석·부모 순위 압박, 비밀키 커밋.

**미정:** 전용 Cloud 프로젝트, 운영 HTTPS·정책 도메인, 시행일, 업로드 키 보관 절차, 실제 Play 상품 등록·거래 검증, 실제 ARM 단말, 실제 사용자의 가격·리텐션 검증. 등록 전 상표·스토어 이름 중복 확인도 남아 있다.
