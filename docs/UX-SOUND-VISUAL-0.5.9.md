# 0.5.9 — 소리 인식·영상 결합·근거 표시 변경 계약

2026-10-02 사용자 승인: 이전 실사용 영상 진단의 개선점을 구현하고 비공개 테스트 업데이트한다. 공개 프로덕션·상품 등록은 범위 밖이다.

## 완료 조건

1. 실제 제공 영상과 기존 공개/음성 대조군으로 새 음성 분석 후보를 비교한다. 기존 모델을 무조건 교체하거나 세 사용자 영상에서 무조건 문장이 나오게 만드는 것을 통과 조건으로 삼지 않는다. 원본은 로컬만 사용한다.
2. 무료 음성에도 같은 분석 개선을 적용한다. 유료·베타에서는 영상의 측정 가능한 특징이 조건에 맞을 때 문장에 실제 반영된다. 얼굴만 보이거나 음성 근거가 없는 경우에는 한마디를 만들어내지 않는다.
3. 소리 분석이 보류돼도 요청한 영상 관찰을 수행하고 보류 이유와 관찰 결과를 함께 전달한다. 시각 근거는 혼합/불확실 음성을 제한 없이 구제하는 우회로가 아니다.
4. `상상한`을 `예상한`으로 바꾼다. 화면·PNG·MP4·기록에서 실제 사용한 근거를 유지한다. 영상 파일 존재/유료 권한만으로 `소리와 표정` 출처를 붙이지 않는다. 보호자 수정과 기존 출처 불명 기록도 정직하게 표시한다.
5. 무음/약한 소리/배경 소리/발성 불확실/모델 실패 안내를 구분한다. 가능한 경우 기존 구간 편집에서 소리 활동 구간을 제안하며 자동으로 분석/저장하지 않는다.
6. 무료60초/10초/100MB, 전체120초/20초/200MB, 베타 전체 개방, 정식 실제 entitlement, 무료 기존 기록/내보내기 계약을 유지한다.
7. 회귀·악조건 QA, 서명 beta APK/AAB·업데이트 경로 검사 후 code23 이상 새 버전을 같은 비공개 트랙에 업로드·검토 제출한다. Google 게시 완료와 제출 완료를 구분한다.

## 구현 분담과 공통 인터페이스

- 통합 담당: 음성 모델 비교, SoundAnalyzer/SoundTimeline/ClipEvidence, 정책·버전·문서, 모든 Gradle/ADB, 서명·Play.
- 영상 담당: VideoImport.kt 및 전용 시각 특징 테스트. 기존 VisualEvidence 생성자 뒤에 기본값을 둔 구조화된 특징을 추가한다. 의미/욕구를 직접 판정하지 않는다. 리소스 해제·취소·한 얼굴만 유효함을 검증한다.
- 표현 담당: 근거 출처 저장/복원/가져오기, 화면·PNG·MP4 공통 표시와 테스트. 통합 담당이 새 ClipInterpretation 출처 필드를 연결한다.
- 다른 작업자의 변경을 되돌리지 않는다. 빌드/ADB는 통합 담당만 사용한다.

출처의 의미는 `AUDIO`(음성), `AUDIO_VISUAL`(문장에 실제 사용한 시각 특징), `CAREGIVER`(수정한 문장), `LEGACY`(과거 출처 미기록)로 고정한다. 영상 관찰을 했지만 문장에 영향을 주지 않은 경우는 AUDIO다. DB의 과거 source 값은 미디어/입력 종류이므로 새 근거 출처를 뜻한다고 추론하지 않는다.

시각 특징은 타임스탬프·얼굴 수·입 열림·눈 감김·입꼬리 계수·관찰 유효성으로 보관할 수 있다. 영상 특징을 기본 문장과 조합하는 규칙은 독립 테스트를 둔다. 같은 구간에서 실제 확보된 관찰만 표현하고, 눈 감김을 수면/피로의 확정 판정으로 쓰지 않는다.

### 계획 검토 반영

- 아기 후보가 거의 0인 기존 실패 영상은 일반 말소리+얼굴로 구제하지 않는다. 인식 개선 주장은 기존/후보 모델의 실제 동일 구간·대조군 실행 결과에 한정한다.
- 최소 2개 얼굴을 탐색해 다중 인물이 있는 구간을 제외한다. 1개만 탐색한 결과를 단일 화자 증거로 사용하지 않는다.
- 보류 결과에도 구조화된 실패 이유·시각 관찰을 반환한다. 시각 실패가 음성 성공을 취소하지 않고, 음성 보류도 영상 관찰을 생략시키지 않는다.
- 기존 기록에는 새 근거 출처를 소급 추정하지 않는다. 모르는 출처는 LEGACY다. 입력 종류를 나타내는 과거 source 값은 유지한다.

통합 API: `ClipInterpretation.basis: String = "LEGACY"`, `ClipAnalysisResult.suggestedRange: ClipRange? = null`을 추가한다. 신규 분석은 AUDIO/AUDIO_VISUAL을 명시한다. 추천 구간은 현재 선택 구간/원본 범위 안에 있으며 현재 이용 한도를 넘지 않는다. 표현 담당은 `ExpressionBasis` 공통 표시/검증 도구와 `Observation.basis`(기본 LEGACY)를 담당한다. 통합 담당은 ClipInterpretation/ClipAnalysisResult를 담당한다.

### 모델 비교 후 확정 범위

- [동일 PCM 비교](research/20261002-model-059-comparison.md)에서 공식 float 원본도 실패 4구간을 회복하지 못했고 공개 웃음/울음 일부는 보류로 회귀했다. 기존 모델과 음성 판정 임계값을 유지한다. 이번 버전을 첨부 영상 인식 문제 해결이나 정확도 향상으로 소개하지 않는다.
- 유효 단일 얼굴 표본 최소2개와 승인된 소리가 있는 경우에만, 관찰된 입 모양과 어울리는 **답을 청하는 문장**을 더한다. 얼굴 주인·실제 프레임 PTS·립싱크를 확인하지 않으므로 입 모양을 아기 행동으로 단정하지 않는다. 눈 감김으로 수면·피로를 추론하지 않는다.
- 음성 보류에서도 시각 결과를 표시한다. 음량 기반 추천은 현재 선택 중 소리가 집중된5초이며 아기 소리 식별을 뜻하지 않는다.
- 새 DB/JSON은 v2. 기존 DB는 LEGACY로 이전하고 JSON v1/v2를 읽는다. 새 JSON v2는 구버전 앱에서 가져올 수 없으며, 기존 MP4 자막은 재작성하지 않는다.
