## 1. 결론

확정된 **완결된 무료 경험 + 카메라·저장영상·PDF를 묶은 전체 이용권**을 유지하는 것이 적절하다. 다음 과제는 기능이나 상품 수를 늘리는 것이 아니라 다음 세 가설을 검증하는 것이다.

1. 보호자가 직접 확인·수정한 한마디를 남기고 다시 보고 싶어 하는가
2. 카메라·저장영상 활용이 무료 음성·직접입력보다 실제 수고를 줄이는가
3. 월별 PDF가 다음 달에도 다시 만들고 싶은 결과물인가

월 4,900원·3개월 선불 12,900원은 **실행 가격 제안**이다. 실제 Play 등록가, 최적 가격, 지불 의사, 시장 수요가 검증됐다는 뜻은 아니다. 결제 준비 전 파일럿에서는 사용성·신뢰·재방문 이유·구체적 유료 활용 장면을 확인하고, 실제 구매와 갱신 검증은 거래 준비 후 진행한다.

## 2. 이해한 제품과 현재 상태

### 확정 방향

6~18개월 아기의 성인 보호자가 소리·장면을 관찰하고, 실제 맥락을 확인한 뒤 아이 시점의 따뜻한 표현으로 기록하는 Android 앱이다. 동물 번역 앱의 **짧은 입력 → 한마디 → 보호자 반응 → 기록·공유** 경험을 참고하되 아기의 실제 의도·감정·건강을 판독한다고 약속하지 않는다.

- 앱 로그인·외부 아기 기록 DB·원본 자동 업로드·가족 자동 동기화 없음
- SQLite에 기록 보관, 사용자가 직접 선택한 파일 공유·백업
- 무료와 유료의 문장 품질·불확실성·보호자 수정 원칙은 동일
- 유료 만료 후에도 이미 생성된 문장 초안·저장 기록·보관한 결과물 유지

## 5. 서비스 모델과 확정 무료·유료 경계

권고 설명: **“아이의 소리와 장면을 함께 살펴보고, 보호자가 그 순간을 한마디로 남기는 기록 앱.”**

핵심 사용 흐름은 관찰 → 보호자 확인 → 표현 선택·수정 → 기록 → 다시 보기 → 선택적 제작이다. 원본 음성·영상 미보관은 프라이버시 장점과 추억 보관 범위의 제한을 함께 만든다. ‘첫 옹알이 목소리를 보관한다’, ‘사진·영상 앨범을 만든다’는 기대를 만들지 않아야 한다.

| 확정 무료 | 확정 전체 이용권 |
|---|---|
| 최대10초 음성·직접입력, 일일 크레딧 제한 없음 | 실시간 카메라 관찰 |
| 동일한3후보·수정·저장·기록 조회/삭제 | 30초·50MB 이하 저장영상의 시각/오디오 분석 |
| 주간 기본 요약·PNG 공유 | 월별 PDF·세 가지 표지 적용 |
| JSON 백업/복원·CSV 내보내기 | 월간/3개월 선불 모두 동일한 전체 권한 |
| 앨범·세 표지 미리보기·기존 결과물 보존 | 별도 카메라권/영상권/PDF권 없음 |

출시 전 확인할 경계:

- 센서 권한·파일 선택·분석 전에 유료 범위 설명, 무료 계속 사용 가능
- 만료 시 신규 카메라/영상 차단·진행 작업 중지·늦은 응답 폐기
- 이미 생성한 문장 초안은 출처와 무관하게 무료 편집·저장
- 유효 권한으로 실제 시작한 PDF는 만료되어도 완료 허용, 보관한 파일 유지
- 구매 복원은 기록 복원이 아님. 기록은 JSON, CSV는 가져오기용이 아님
- 무료의 횟수 제한 없음과 기술 상한을 구분: 기록10,000건, PDF300기록/300쪽 등은 추가 결제로 해제하지 않음
- 유료는 입력·제작 편의이며 더 높은 의도 정확도가 아님

구독의 상업적 근거는 기능 세 가지를 묶었다는 사실만으로 생기지 않는다. 영상 활용·새 기록·새 월북이 반복되는지 봐야 한다. Google Play도 지속적·반복적 가치를 요구한다. 현재 묶음의 정책 위반을 단정하는 것이 아니라 실제 제공 가치와 설명을 맞추라는 의미다. [구독 정책](https://support.google.com/googleplay/android-developer/answer/9900533?hl=en), [선불 기본 요금제](https://support.google.com/googleplay/android-developer/answer/12154973?hl=en)

### 비용은 실제 로컬 구조에 맞추기

온디바이스 관찰·표현·기록·PDF에는 매번 외부 LLM 호출이나 미디어 저장 비용이 발생하는 구조가 아니다. 그러나 결제 검증 HTTPS·운영·모니터링·ARM/OS 대응·고객지원·개발·획득비는 남는다. ‘외부 아기 DB 없음’과 ‘서버비/통신 없음’을 혼동하지 않는다.

기존 월 공헌액 약3,173원은 표시가격4,900원, 부가세10%·수수료15%·환불3%·지원500원이라는 **계획 가정**의 계산이다. 실제 정산·세금 자문이나 실측 수익이 아니다. 기존64명 손익분기도 월20만원 공통예산만 넘기는 값이며 급여·광고를 포함한 사업 손익분기가 아니다. 선불12,900원은3개월에 대응하며 전액을 한 달 반복매출로 집계하지 않는다.

실제 비용 기록은 수수료·환불, 문의당 지원시간, 검증 요청·인프라 비용, 고정 유지보수·개발비, 채널별 획득비로 대체한다. 한국 자동갱신 구독15% 안내는 확인했으나 선불·일회성 거래는 계정 프로그램과 정산을 별도 확인한다. [Google 수수료](https://support.google.com/googleplay/android-developer/answer/112622?hl=en), [현재 검증 서비스](https://github.com/yw8837/jigeum/blob/f42238c341ff890449154562052be15dc7f9b2e7/outputs/PlayVerifier/README.md)

## 7. 이번 주 성인 보호자 파일럿

일반 Play 공개·실결제 준비와 테스트 릴리스는 구분한다. 인수인계상 새 개인 Play 계정은 신원 확인 중이고 앱 생성도 아직 불가능하지만, 이 사실만으로 모든 테스트 사용이 막힌다고 결론내리지 않는다. 이용 가능한 테스트 배포 경로와 해당 빌드의 기능·데이터 보존 상태를 별도 확인한다.

파일럿은 **완성된 무료 핵심 사용 + 계획 중인 유료 기능의 정직한 미리보기**를 우선한다. 0.3 카메라/영상의 무료 접근을 최종 정책으로 소개하거나, 검증 없이 유료 기능을 열어서는 안 된다. 유료 기능 실제 사용 시험은 준비된 테스트 권한과 범위를 별도 확인한다. 예시를 본 의견과 직접 사용한 증거를 구분한다.

| 질문/과제 | 관찰할 행동 | 잘못된 해석 방지 |
|---|---|---|
| “평소 있었던 순간 하나를 남겨 보세요” | 무도움 완주, 시간, 멈춘 단계, 되돌아감 | 칭찬을 사용성 통과로 대체하지 않음 |
| “앱이 방금 무엇을 해 줬다고 생각하세요?” | 의도번역/진단 오해, 표현·수정 이해 | 면책 문구를 읽었다는 사실만 보지 않음 |
| “남기고 싶은 말이 있나요? 어떻게 고치겠어요?” | 후보 선택, 수정 내용·부담 | 높은 수정률이 반드시 실패는 아님 |
| 며칠 뒤 사용 이유 확인 | 자발적 새 기록·이전 기록 재열람 | 연구자 요청/알림으로 돌아온 경우 분리 |
| “최근 어떤 저장영상에 쓰겠어요?” | 구체적 사례·줄어드는 수고 | 미리보기 의향≠실제 영상 사용률 |
| 실제 수준의 월북 예시 제시 | 다시 열기/가족에게 보여 줄 이유, 정리 편의 | 표지 선호≠월정액 수요 |
| 두 제안 가격·만료 규칙 설명 | 청구 이해, 선택/비구매 이유, 남는 자료 이해 | 구매 의향≠실결제·최적 가격 검증 |
| 테스트용 기록 백업·복원 | JSON 보관·복원 이해, 데이터 보존 | 구매 복원과 기록 복원 구분 |

자연스러운 일상 장면을 사용하고 울음을 유도하거나 돌봄을 미루게 하지 않는다. 원음·영상·아이 이름·문장 전문을 원격 조사자료로 모으는 방식으로 확장하지 않는다. 기록을 재설치/갱신 과정에서 잃지 않게 하며 원래 기록을 삭제하는 시험은 피한다.

초기 모집은6~18개월 범위 안에서 ‘사진·영상은 자주 찍지만 글 기록은 잘 못 남기는 보호자’를 우선 비교해 볼 수 있다. 이는 모집 가설이며 확정 타깃 변경이 아니다.6~8/9~12/13~18개월, 자발적/요청 사용, 무료/유료 기능 의향을 구분한다.13~18개월에서는 실제 첫 단어와 상상한 표현이 섞이지 않는지도 확인한다.

분석 SDK가 없으므로 전체 설치의 유지율을 관측했다고 보고하지 않는다. 모집 파일럿 관찰·자발적 집계·인터뷰와 Play 거래 집계를 분리한다. 거래 준비 후에는 실제 갱신일을 지난 월간 구매자의 두 번째 결제와 선불 만료 후 재구매를 별도 측정한다. 기존 활성화70%·W1 30%·W4 20% 등은 임시 가설이며 업계 표준이나 이번 주 강제 합격선이 아니다.

RevenueCat의2026 D35 중앙값10.7%/2.1%는 확인했으나 RevenueCat을 사용하고 최소 수익/설치 조건을 충족한 앱의 관측 비교다. 지금 앱의 예상 전환율이나 하드 페이월의 인과 효과로 가져오지 않는다. [보고서·방법론](https://www.revenuecat.com/state-of-subscription-apps-2026/)

## 8. 과학적·윤리적 표현과 완료 조건

YAMNet 일반 소리 사건과 Face Landmarker의 랜드마크·표정 계수는 아기의 의도·건강 정답이 아니다.2026 울음분류 체계적 검토는 가능성을 인정하면서 연구별 정확도44.5~99.82%와 다양한 데이터·현실환경 검증 필요를 보고한다. 최고 숫자를 앱 정확도로 쓰거나 반대로 관련 연구 전체가 불가능하다고 결론내리면 모두 부정확하다. [YAMNet](https://www.tensorflow.org/hub/tutorials/yamnet), [MediaPipe](https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker), [원 논문](https://doi.org/10.1177/00368504251410776)

관찰 신호·보호자 맥락·상상한 표현을 화면과 공유물에서 일관되게 구분한다. 건강 걱정을 결제·추가 분석으로 유도하지 않는다. 자연어 결과를 ‘진단 아님’이라는 작은 문구 하나로만 보완하지 않는다.

이번 주 보고 가능한 완료는 다음 범위다.

- 보호자가 실제 사용 가능한 테스트본, 정확한 버전·설치 경로·무료 범위·알려진 한계 제공
- 포함한0.4 접근 정책과 무료 완주·기록 보존·권한 만료/복원·늦은 응답을 실제 시험
- 추가9계측은 결과가 있을 때만 통과 보고. 기존0.3 APK와 새 빌드 구분
- ARM·실 Play·운영 준비 중 남은 항목은 그대로 공개
- 일반 공개·실결제 활성화는 해당 준비·승인 단계에서 별도 완료

개발·검증 순서는 [NEXT](https://github.com/yw8837/jigeum/blob/f42238c341ff890449154562052be15dc7f9b2e7/docs/NEXT.md), 확정 선택은 [DECISIONS](https://github.com/yw8837/jigeum/blob/f42238c341ff890449154562052be15dc7f9b2e7/docs/DECISIONS.md)를 따른다. 이번 리뷰를 이유로 Android 런타임이나 승인된 정책을 자동 변경하지 않는다.
