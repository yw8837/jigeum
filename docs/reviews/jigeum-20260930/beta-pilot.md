# 지금 베타 사용 테스트

작성일: 2026-09-30. 이 문서는 실행 절차이며 테스트 결과가 아니다. 대상 빌드의 커밋과 APK SHA-256을 확정한 뒤 진행한다.

## 목적과 준비

이번 테스트는 부모가 혼자 첫 기록을 만들 수 있는지, 결과를 어떻게 이해하는지, 며칠 뒤 다시 사용할 이유가 있는지 확인한다. 초기 3~5명은 진행 규모 제안이며 모집 완료 인원이 아니다. 작은 표본의 반응을 시장 수요나 유료 전환율로 일반화하지 않는다.

PM은 2026-09-30에 참여자 모집이 가능하며 12명·2주 테스터는 크몽에서 구할 계획이라고 밝혔다. 업체 선정·구매·실제 모집 완료는 아직 확인되지 않았다. 해당 테스트 참여자가 실제 타깃 보호자인지 확인하고, 그렇지 않다면 부모 사용성 테스트를 별도로 진행한다. Play 적용 요건 충족 여부는 실제 계정과 콘솔 진행 상태에서 확인한다.

- PM이 성인 보호자 참여자와 일정, 전달할 설치 파일 및 설치 방법을 확정한다. 이 문서만으로 모집 메시지를 발송하지 않는다.
- 개발 시험은 합성 자료가 있는 전용 기기에서 먼저 끝낸다. 부모의 실제 기록이 있는 기기에 초기화·삭제·강제 종료 시험을 실행하지 않는다.
- 전달 전에 무료 범위, 아직 사용할 수 없는 기능, 알려진 오류, 기록의 기기 내 보관과 백업 방법을 설명한다. 서명 불일치 때문에 기존 앱을 삭제해야 한다면 진행을 멈추고 보존 방법부터 확인한다.
- 아기 이름, 생년월일, 원음·얼굴 사진·영상, 문장 전문은 조사 자료로 요청하지 않는다. 참여자는 자기 기기에서 직접 사용한다. 피드백에는 참여자 번호와 비식별 기능 의견만 남긴다.
- 화면 녹화나 아이 자료의 외부 공유는 기본 절차에 포함하지 않는다. 사용을 위해 울음을 유도하거나 돌봄을 미루지 않는다. 보호자는 언제든 중단할 수 있다.

## 첫 사용 약 15분

진행자는 먼저 버튼 위치나 정답 경로를 가르치지 않는다. 막히면 어느 지점에서 어떤 도움을 주었는지 기록한다.

1. “평소 있었던 순간 하나를 이 앱에 남겨 보세요.” 음성 또는 직접입력을 스스로 선택하게 한다. 시작부터 저장까지 걸린 시간과 중단 위치를 기록한다.
2. “앱이 방금 무엇을 해 줬다고 생각하세요?” 처음 답변을 기록한 다음, 실제 의도 번역이나 진단으로 이해했다면 제한을 설명한다. 안전 설명을 생략해 오해를 유지시키지 않는다.
3. “남기고 싶은 말이 있나요? 원하는 표현으로 바꿔 보세요.” 후보를 고른 이유와 수정 부담을 확인한다. 수정했다는 이유만으로 실패라고 판정하지 않는다.
4. “방금 남긴 기록을 다시 찾아보세요.” 기록 조회와 수정·공유 진입의 발견성을 본다. 외부 전송은 요구하지 않고 공유 화면에서 취소해도 된다.
5. “휴대폰을 바꾸면 이 기록은 어떻게 옮길 것 같나요?” JSON 기록 복원과 구매 복원의 차이를 이해하는지 본다. 실제 개인 기록에 파괴적인 복원 시험을 하지 않는다.
6. 카메라·저장영상 이용권 안내와 실제 수준의 월별 PDF 예시를 보여 준다. “어떤 순간에 쓰겠어요?”, “이 결과물을 다시 열어 볼 이유가 있나요?”를 묻는다. 사용할 수 없는 기능은 미리보기라고 명확히 표시한다.
7. 제안 가격 월 4,900원과 3개월 선불 12,900원을 가설로 제시한다. “지금 선택한다면 어느 쪽인가요? 둘 다 선택하지 않아도 괜찮아요. 이유는 무엇인가요?”라고 묻는다. 현재 Play 등록가나 결제 성공으로 표현하지 않는다.

## 며칠 뒤 확인

참여자가 동의한 날짜에 PM이 확인한다. 자동 알림이나 연락은 이 문서로 설정되지 않는다.

- 요청받기 전에 스스로 다시 열었는가? 열었다면 새 기록, 과거 기록, 카메라·영상 등 목적은 무엇이었는가?
- 사용하지 않았다면 잊음, 필요 없음, 결과 반복, 입력 번거로움, 오류 중 실제 이유를 자유롭게 듣는다.
- 최근 문장이 반복된다고 느꼈는가? 선택할 만한 표현이 있었는가? 건강·욕구를 단정해 불편했던 지점이 있었는가?
- 다음 주에도 쓸 구체적인 순간이 있는가? PDF를 다음 달에도 만들 이유가 있는가?

요청 때문에 돌아온 사용과 자발적 재사용을 구분한다. 전체 설치자의 유지율이나 결제 전환율을 계산하지 않는다. 가격 선택 답변은 구매 의향일 뿐 실구매가 아니다.

## 판단과 중단

기록 손실, 아기 자료의 예상하지 못한 외부 전송, 결제 상태 오표시, 지속적인 앱 종료가 있으면 해당 빌드의 추가 전달을 멈추고 먼저 수정한다. 첫 기록을 혼자 만들지 못하면 새 기능보다 그 흐름을 고친다. 결과는 재미있지만 재사용 이유가 없으면 구독 확장보다 반복 가치부터 검토한다. 실제 결과를 받은 뒤 PM이 다음 테스트와 출시 범위를 결정한다.
