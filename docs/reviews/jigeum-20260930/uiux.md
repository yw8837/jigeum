## 실제로 본 범위

저장소의 `outputs/StoreListing/screenshot-01-home.png`, `screenshot-02-expression.png`, `screenshot-03-video-expression.png`를 직접 열어 확인했다. 이는 저장된 0.3 계열 캡처이며 새 0.4 실행 화면이 아니다. 홈·표현 결과·영상 표현 결과의 정적 검수다. 현재 환경에서는 Android 앱을 직접 실행하지 못했다. 결제 화면, 권한 창, TalkBack, 키보드, 작은 화면과 큰 글씨의 실제 동작은 미검증이다. 과거 QA 기록을 독립 실행 결과로 합산하지 않는다.

## 유지할 점

- 무료 소리 입력을 어두운 큰 버튼으로 강조하고 카메라·영상을 보조 행동으로 둔 위계
- 크림·세이지 배경과 큰 결과 문장, 친근한 손 그림의 일관성
- 단일 답을 확정하지 않고 대안 문장과 직접 수정 경로를 제공
- 원본 미보관과 보호자 선택을 설명하는 문구가 존재함

## 반드시 남길 실행 증거

1. 테스트 APK의 커밋·버전코드·SHA-256·서명 종류와 설치 기기/OS
2. 첫 실행 → 권한 거절 → 수동 입력 → 수정 → 저장 → 종료/재접속 → 같은 기록 확인
3. 녹음 중 배경 전환/취소, 잘못된 영상·초과 파일·선택기 취소, 중복 탭·느린 응답
4. JSON 백업/가져오기와 중복·손상 입력, PNG/CSV 공유, 삭제 직후 공유·PDF 진행 경합
5. 0.4일 경우 유료 진입·만료·명시적 거절·오프라인·늦은 콜백·프로세스 재생성·수정 초안 보존
6. 작은 화면·가로·200% 글씨·TalkBack. 스크린샷 픽셀 크기로 dp 터치영역이나 대비 적합성을 단정하지 않음

Android 공식 접근성 기준은 터치 영역 최소 48×48dp를 권고한다. 실제 Compose 의미 트리와 기기에서 측정해야 한다: https://developer.android.com/codelabs/basic-android-kotlin-compose-test-accessibility?hl=en

## 판정

정적 화면 검수는 완료했지만 전체 UI/UX 동작 검증은 대기다. 위 항목은 코드 변경 없이도 현 테스트 담당자가 재현할 수 있는 승인 체크리스트다. 0.3 무료 카메라 동작과 0.4 유료 잠금 목표를 섞어 버그 판정하지 않는다. 사용자는 성인 보호자로 모집하고 실제 아기 원본 업로드·공유를 테스트 조건으로 요구하지 않는다.
