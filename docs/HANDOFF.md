## 가장 먼저 읽을 현재 상태

**현재 소스는 0.5.1/code14 심층 QA 수정 후보이며 유료 출시 완료본이 아니다.** 최신 이름은 **아가톡 - 지금 내 기분이 그래**, 앱서랍은 **아가톡**이다. [심층 QA](qa/deep-audit-0.5/README.md)의 실행 결과를 따른다. [0.5.0/code13](qa/0.5.0/README.md)과 그 이전 수치는 과거 실행 증거이며 새 버전으로 복사하지 않는다.

사용자가 실제 앱에서 다른 녹음에도 비슷한 성인 말투, 울음 뒤 놀이 제안, 녹음 없이 선택만으로 문장이 나오는 문제를 제기했다. 스크린샷은 문구·UX 문제의 증거다. **원본 아기 음성·영상은 받지 않았으므로 해당 클립의 분류 전후 비교는 아직 없다.**

## 사용자 확정 사항

- 흥미 중심이지만 장면과 어울리는 아기 한마디가 유료 가치의 전제다. 근거 없는 욕구를 랜덤으로 붙이지 않는다. 관찰 보고문만 보여 주는 것도 제품 목표를 충족하지 못한다.
- 월령 입력, 보호자의 소리/상황 선택, 직접 번역, 후보 다시 뽑기를 제거한다.
- 최대1분 영상+소리로 통합. 소리만 녹음, 재생과 구간 선택 지원. 무료는 소리, 이용권은 시각 관찰 추가·PDF.
- 원본은 온디바이스. 앱 로그인·외부 아기 DB·무단 업로드 금지. 결제/심사 검증만 기존 HTTPS 무상태 서버 사용.
- 운영자 최용우 / 지원 bsfire1237@gmail.com. 상품 등록·실제 거래와 공개 제출은 이번 작업 범위에서 보류.
- 확정 트레일러는 `outputs/Marketing/jigeum-trailer-b-family.mp4` 하나. 폐기안을 되살리지 않는다.
- Elice 호출·설치·키 복원 금지. 다른 작업자의 변경을 되돌리지 않는다. Gradle/ADB 담당자는 한 명.

## 0.5 변경과 알려진 한계

| 영역 | 구현 | 한계 |
|---|---|---|
| 입력 | CameraX 영상+AAC / MediaRecorder 음성,60초 상한, 재생,1–15초 구간 | 가져오는 영상도1분·100MB 이하. 임시 원본은 종료/재촬영/다음 실행 시 삭제 |
| 소리 | YAMNet의 정확한 라벨 매칭, 무음 검사, 아기 울음/웃음/옹알이 후보, 충돌 보류 | 일반 AudioSet 모델이며 아기 신원/욕구를 알지 못함. 임계값은 미보정 규칙 |
| 한마디 | 관찰된 소리·에너지 패턴 안에서 짧은 캐릭터 문장, 동일 파형은 동일 문장 | 유한 풀. 파형 키는 말투 선택일 뿐 의미 특징·정확도 개선이 아님 |
| 표정 | 선택 구간 최대5장면 얼굴·입 열림 관찰 | 감정·배고픔 판독 아님. 얼굴 주인도 확인하지 않음. 유료가 더 정확한 뜻을 보장하지 않음 |
| 접근 | 무료 캡처/가져오기/소리, 실제 이용권으로 시각/PDF | PENDING·화면Boolean으로 열지 않음. 초안/기존 기록은 만료 후에도 무료 |
| 이름/아이콘 | 아가톡 / 아기 얼굴+말풍선 | 스토어/기존 트레일러의 새 이름 적용은 후속 |

중요한 재현 결함: 예전 UI에서 무입력→문장 저장 회귀 실패를 확보했다. `babbl` 부분문자열이 `Hubbub, speech noise, speech babble`도 옹알이로 매칭했으며 exact match로 수정했다. 구간 디코딩의 AAC 시작 손실과 첫 재생 전 구간 변경 시 MediaPlayer Prepared 상태에 pause를 호출하던 결함도 수정·회귀했다. 상세 통과 여부는 QA 보고서 참조.

0.5.1 심층 감사에서 수정 폼을 접은 뒤 저장하면 수정 문장이 유실되는 문제, 이전 시각 옵션이 무료 음성 분석을 취소하는 문제, 시각 모델 실패가 성공으로 표시되는 문제를 red 회귀로 재현했다. 수정 내용은 폼 접힘과 별도로 저장하며 권한 감시는 실행 중인 분석 요청에만 적용한다. 시각 관찰은 완료/부분/실패를 구분하고 실패 안내를 결과에 바로 표시한다. 계측 하네스는 test별 완료·명시 skip·실제 설치 APK 해시를 확인하며 AAB 서명을 필수 검사한다.
