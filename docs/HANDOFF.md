## 최신 사용자 요구 — 온디바이스 생성 구조 개편

사용자가 **선택한 최대20초의 소리·영상 흐름을 함께 해석하고 아기말을 새로 생성하는 구조**로 변경을 요청했다. 이어서 **무조건 온디바이스, 외부 전송 없이**를 재확정했다. 단순 문장 풀 확대만으로 이 요구를 완료 처리하지 않는다. [설계](superpowers/specs/2026-10-03-ondevice-av-generation-design.md)에 따라 Gemma4 E2B를 실제 다운로드·해시 확인하고 로컬 소리+이미지10/20초를 실행했다. **초기 관찰 품질은 미통과이며 앱 모델 교체·Android 통합·신규 배포는 미완료**다. [실측/실패와 한계](research/20261003-ondevice-av-probe.md)를 먼저 읽는다. 아래0.5.9는 계속 배포 기준본이다.

2026-10-04 최신 요청: **문장 표현보다 소리·영상을 제대로 읽는지 우선 개선**한다. 약국 영상은 또렷한 옹알이인데 현재 앱10초/20초 모두 미확정으로 보류한다고 사용자가 확인했다. 잡음이 더 크다는 가정을 하지 않는다. `응앵25초`는 이전 앱 결과 영상이며 새 원본의 인식 평가 분모에서 제외한다. 핵심 분석·수정은 사용자가 지정한 **Astra/high**, 이후 후속 조사·QA·배포는Luna/Sol로 진행한다. [실행 계획](superpowers/plans/2026-10-04-perception-recovery.md). 작업은 `codex/ondevice-av-probe` worktree에서 이어간다.

동일 원본의 현재/float YAMNet × raw/filter ×10/20초8조합에서 누락을 재현했다. AST 후보는 해당 영상의 Babbling0.419를 포착하지만 공개 옹알이·혼합 사건 한계가 남아 일괄 교체하지 않는다. 클래스 점수를 음량/정확도로 해석하지 않는다. Android에서는 순차 디코딩·실제PTS·2fps VIDEO 추적·초중후/입 변화 방향 보존을 구현했고 관련98개 계측을 통과했다. 연구 호스트26개도 통과했다. 후속 Sol 검토·보조 모델 통합·문장 생성·전체 QA·배포는 남았다. [실측](research/20261003-ondevice-av-probe.md) / [진행 중 QA](qa/ondevice-av-generation/PERCEPTION-QA.md). 새 연구 결과를 배포 앱의 인식 개선 완료로 보고하지 않는다.

### 이번 변경과 남은 인식 한계

- `상상한` 대신 `예상한 아기말`을 표시한다. 실제 근거를 AUDIO/AUDIO_VISUAL/CAREGIVER/LEGACY로 저장하고 화면·PNG·새 MP4·기록·백업에 유지한다. 영상 파일/유료 권한만으로 시각 근거를 붙이지 않는다.
- 음성이 보류돼도 요청한 시각 관찰을 실행한다. 무음·작은 소리·발성 미확정·배경 우세·모델 오류 안내를 구분하고, 조건에 맞으면 현재 선택 중 소리가 집중된5초를 제안한다. 자동 재분석/저장은 없다.
- 기존 음성 판정이 통과하고 유효 단일 얼굴 표본이2개 이상일 때 입 모양에 맞춘 답을 청하는 문구를 추가한다. 얼굴 주인·실제 프레임PTS·립싱크·감정·욕구를 확인하는 기능은 아니다. 얼굴만으로 한마디를 만들지 않는다.
- **제공된 두 영상의 아기 발성 누락은 미해결.** 공식 float 모델 비교에서도 회복하지 못하고 공개 웃음/울음 일부가 회귀해 기존 모델·음성 임계값을 유지했다. 공개22개 기존판정과 변화0이며 strict 선언라벨4불일치는 여전히 실패다. [실측 진단](research/20261002-private-video-diagnosis.md) / [모델 비교](research/20261002-model-059-comparison.md).
- 결과 카드의 초기/최종 높이를 맞춰 로딩 중 버튼 위치가 밀리는 결함을 수정했다. 이 변경을 수음 개선·아기 의도 정확도 향상으로 소개하지 않는다.

중요한 재현 결함: 예전 UI에서 무입력→문장 저장 회귀 실패를 확보했다. `babbl` 부분문자열이 `Hubbub, speech noise, speech babble`도 옹알이로 매칭했으며 exact match로 수정했다. 구간 디코딩의 AAC 시작 손실과 첫 재생 전 구간 변경 시 MediaPlayer Prepared 상태에 pause를 호출하던 결함도 수정·회귀했다. 상세 통과 여부는 QA 보고서 참조.

0.5.1 심층 감사에서 수정 폼을 접은 뒤 저장하면 수정 문장이 유실되는 문제, 이전 시각 옵션이 무료 음성 분석을 취소하는 문제, 시각 모델 실패가 성공으로 표시되는 문제를 red 회귀로 재현했다. 수정 내용은 폼 접힘과 별도로 저장하며 권한 감시는 실행 중인 분석 요청에만 적용한다. 시각 관찰은 완료/부분/실패를 구분하고 실패 안내를 결과에 바로 표시한다. 계측 하네스는 test별 완료·명시 skip·실제 설치 APK 해시를 확인하며 AAB 서명을 필수 검사한다.
