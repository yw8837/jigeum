# 선택 구간의 소리·시각 관찰 연결 — 0.5.18

사용자 요청: 영상 분석도 함께 보완한다. 기준 제품 `737c0a8`(0.5.17/code31).

## 구현 계약

- 영상은 기존 500ms cadence의 순차 디코딩·실제 PTS·MediaPipe VIDEO 관찰을 유지한다.
  10/20초 전 구간 coverage를 유지하며 더 큰 모델·원본 업로드를 추가하지 않는다.
- 기존의 구간 전체 표정 합산 대신, 승인된 YAMNet 소리 후보 시간창(975ms) 안의
  연속 시각 관찰만 요청형 표현에 기여한다. 시간창의 중첩은 정확한 발성 시점·입술 동기·화자 신원을 입증하지 않는다.
- 웃음에는 서로 인접한 두 유효 단일 얼굴 관찰의 입꼬리 계수를 사용한다. 얼굴 누락·여럿·비정상 값·750ms 초과 간격으로 연결하지 않는다.
- 옹알이/어린 말소리에는 같은 승인 중립 창 안에서 기존 기준의 열린 입 관찰 두 개와
  열림/닫힘 변화 두 회 이상이 필요하다. 중간에 승인 소리창·얼굴 관찰이 끊기면 별도 run이다.
- 여러 소리 단계에서도 각 시간창을 따로 연결한다. 울음은 웃는 모양으로 행복/웃음으로 바꾸지 않는다.
  눈 감음은 졸림이 아니다. 화면에 사람만 보인다고 발성 보류를 승인하지 않는다.
- 정확한 시점이 없는 AST broad 창은 새 시간 연결로 쓰지 않는다. 구형 PTS 없는 관찰은
  기존의 요청형 표시만 유지하고 시간 일치 근거를 만들지 않는다.
- PCM 원음은 변경하지 않는다. 실제 디코더 출력 PTS와 선택 시작·각 kept buffer의 이어짐을
  한 원본 sample의 반올림 오차 범위에서 확인한다. 지연 오디오·PTS 공백/겹침이면 새 시간 연결만
  차단하고 음성 판정과 영상 관찰은 보존한다. 내부 crop된 PCM 시간만으로 대응을 확정하지 않는다.
- 결과 근거에는 실제 관찰 구간과 관찰 종류를 남긴다. 욕구 번역·일반 정확도·립싱크 확인으로 보고하지 않는다.
