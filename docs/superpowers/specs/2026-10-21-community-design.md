# 우리 아이 자랑 — 구현 계약

## 사용자 요청과 결정

2026-10-21: 단일 ‘우리 아이 자랑’ 게시판에 아가말 영상카드·이미지·사진을 올리고 댓글·좋아요를 사용한다. 구현 후 앱에서 연결한다. 이메일 인증 제안은 최신 ‘익명, 비번설정’ 요청으로 대체한다. 분석과 개인 기록은 온디바이스 유지, 공개는 명시적 게시 동작으로만 수행한다. 예약은 만들지 않는다.

## 사용 흐름

2026-10-22 후속 확정: 공개 도메인은 **baby.yeolmaeapps.kr**. 일반 게시에는 ChatGPT 로그인을
요구하지 않는다. 기기를 바꿔도 내 글/댓글을 관리하는 기능은 선택적 Google/Kakao 로그인과
마이페이지로 구성해야 하며, 현재 익명 MVP에는 아직 구현하지 않았다. 최신 검증은
[QA](../../qa/community-20261021/README.md)를 따른다.

- 누구나 최신순 피드를 읽는다. 로그인 없이 닉네임(기본 ‘익명’), 본문, 관리 비밀번호로 글/댓글을 작성한다.
- 사진 1장 또는 영상카드 MP4 1개/게시글. 25MiB 이하, 영상 30초 이하. 초안에서 영상·소리·문장을 확인하고 공개 동의 후 게시한다. 사진은 브라우저에서 JPEG로 다시 그려 위치 등 EXIF를 제거한다.
- 앱 홈에서 게시판을 연다. 결과의 ‘우리 아이 자랑에 올리기’는 로컬에서 선택 구간 영상카드(영상이 없으면 이미지)를 만든 후 게시판 작성 화면으로 전달한다. 파일 선택·미리보기는 전송이 아니며 게시 버튼에서만 전송한다.
- 기존 카드도 게시판의 파일 선택기로 고를 수 있다. 영상 자동재생 없음. 한 영상을 재생하면 다른 영상은 멈춘다.
- 글/댓글 수정·삭제는 해당 관리 비밀번호로 가능하다. 분실 시 자동 복구 불가, 신고/운영자 문의 지원.
- 좋아요는 브라우저별 익명 토큰으로 1회/취소, DB 고유키로 동시 중복 방지. 기기·저장소 초기화 이후까지 1인1회 보장하지 않는다.
- 신고, 작성자 차단/차단 해제, 운영자 숨김/삭제·댓글 관리. 차단은 해당 익명 브라우저 작성자 기준이며 다른 기기로 작성한 동일인까지 식별하지 않는다.

## 구현 구조

- `outputs/Community`: 모바일 웹, 같은 origin의 서버 API, D1 영속 게시물·댓글·좋아요·신고·차단·요청 제한, R2 미디어. Sites를 사용해 별도 전용 저장소와 웹 호스팅을 구성한다. 기존 결제 서버와 다른 서비스 DB는 변경하지 않는다.
- 관리 비밀번호: 서버 PBKDF2-SHA256, 레코드별 난수 salt, 충분한 반복횟수, 상수 시간 비교. 비밀번호·익명 토큰·IP 원문은 공개 응답과 로그에 포함하지 않는다. 수정/삭제 실패 횟수 및 작성 빈도는 서버에서 제한한다.
- 운영자는 Sites의 검증된 사용자 ID와 서버 전용 운영자 allowlist로 판정. 익명 방문자의 헤더/닉네임으로 운영자 권한 부여하지 않는다. allowlist 미설정 시 운영 API 차단, 공개 배포 전 실제 운영자 접근 검증.
- 개인 원본 자동 업로드 없음. Android는 지정 HTTPS origin만 앱 내 WebView로 열고 JS 네이티브 브리지/파일 URL 접근을 제공하지 않는다. 준비된 카드도 파일 선택 사용자 동작 후에만 전달한다.
- 서버/앱 URL 미설정 또는 서버 검증 미완료 상태는 배포 완료가 아니다. 실제 서비스 URL과 앱 빌드 검증 후 활성화한다.

## 검증과 출시 조건

API 실제 DB 통합: 새로고침 후 지속, 타인의 잘못된 비밀번호 수정/삭제 거부, 댓글 소유 비밀번호, 중복 좋아요, 삭제 게시물의 미디어 접근 차단, 신고/차단, 용량/형식/길이 제한, XSS/잘못된 origin 거부, 실패/재시도.
브라우저: 모바일/넓은 화면, 합성 사진/영상만 사용한 게시·재생·댓글·좋아요·수정·삭제, 키보드/오류/빈 상태.
Android: 기존 분석/저장 동작 유지, HTTPS origin 및 경로 검증, 파일 전달/취소, 뒤로가기와 결과 복귀, 컴파일과 가능한 전용 QA 기기 검증.
게시판 개인정보 처리·이용 안내를 추가하고 공개 UGC에 맞는 Play 데이터 보안/정책 검토를 마쳐야 실제 beta 앱 배포 가능. 이번 변경을 인식률 개선으로 주장하지 않는다.
