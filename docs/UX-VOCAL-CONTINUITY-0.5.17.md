# 0.5.17 발성 연속성·세 단계 소리 흐름 계약

사용자는 인식·번역 개선을 실제 구현·QA·비공개 배포까지 이어가도록 재지시했다.
기준 소스는 `91947ef`다. 새 대형 모델 도입 대신 현 판정 코드에서 재현되는 누락과
관찰된 사건 순서를 표현하지 않는 결함을 먼저 수정한다.

## 제품 변경과 허용 근거

1. 모델이 연속된 인접 창을 옹알이/어린 말소리 후보로 번갈아 판정하면,
   세 개 이상 고유 관찰·각 기존 영아 라벨 기준 통과·900–1500ms 간격·1800ms 이상 span에서
   중립 발성의 연속성으로 인정한다. 각 관찰의 원래 소리 종류를 보존하며 말소리를 옹알이로 치환하지 않는다.
2. 임계값·모델·원음/필터·선택 구간을 바꾸지 않는다. 성인/일반 말소리만으로는 대사를 만들지 않는다.
   중복/역순/큰 시간 간격·충돌·배경 지배 관찰은 새 연속성의 근거에서 제외한다.
3. 다른 위치의 강한 일반 울음/웃음 단서를 중립 발성으로 가리지 않는다.
4. 중립 두 종류가 함께 인정됐으면 감정 혼합용 문장 대신 중립 소리/대화 표현을 쓴다.
   기존과 같은 입력/분석 버전은 같은 결과다. 해시가 욕구나 감정을 고르지 않는다.
5. 각 단계에 연속된 두 개 이상 고유 관찰·900ms span이 있고 원본 관찰이 누락되지 않은
   세~네 단계의 소리 흐름은 순서를 보존해 표현한다. 희박한/충돌/AST 넓은 창은 순서 이야기로 만들지 않는다.
   옹알이와 어린 말소리만 교대하는 흐름은 같은 중립 발성의 라벨 불확실성일 수 있어 안정된 단계라도
   순서 이야기 대신 원래 관찰을 보존한 중립 표현을 쓴다. 마지막 응답 문구는 실제 마지막 단계에 맞춘다.
6. 배고픔·졸림·통증의 판별이나 실제 대사 전사를 새로 주장하지 않는다.
   합성 관찰 검사 통과를 일반 영아 인식률 향상으로 계산하지 않는다.

## 완료 기준

실제 수정 전 red/수정 후 green, Android 통합·인식 반례·최종 서명 및 업데이트 보존,
독립 Standards/Spec 리뷰를 마친 후 비공개 beta만 업로드/검토 제출한다.
실폰이 연결되지 않았으면 실폰 성능/발열의 새 측정으로 보고하지 않는다.
일반 정확도·욕구 판별은 별도 평가가 남는다고 명시한다.
