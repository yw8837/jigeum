# 소리와 한마디 품질 개선 · 2026-10-02

기준: `5362ae3` (0.5.2/code15). 최신 사용자 요청과 HANDOFF가 명세다.
목표: 원문 연구를 실제 시간별 소리 판정에 반영하고 웃음→울음, 울음→놀이 같은 반대 반응을 줄인다. 유용한 응답률도 함께 기록한다. 구체적 욕구 정확도는 별도다.

## 승인 기준

- 실제 YAMNet 입력부터 대사까지 출처·권리를 확인한 공개 음성으로 전후 비교. 개발 확인용과 추가 확인용 클립 구분. 증폭/구간 변형은 독립 아기로 세지 않는다.
- 웃음과 울음 동시·교대·성인 소리·무음·잡음을 평가한다. 반대 사건 대사 0건을 목표로 하며 실패를 보류율로 숨기지 않는다. 클립 수와 사건별 출력/보류/오답을 모두 공개한다.
- 동일 입력은 동일한 의미와 문장. 얼굴 단서만으로 울음/웃음/배고픔을 생성하지 않는다.
- 실제 원인에 대한 회귀 검증, 전체 Android/호스트 QA, preview 접근·재생·범위·저장·PDF, release 제한 복구 확인.
- 새 서명 test APK, 보고서와 소스 커밋/푸시. Play 제출/운영 서버 변경 없음.
