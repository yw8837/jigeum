## 발견 사항

### P2 — 필터로 제거한 잡음이 대사와 관찰 근거를 계속 결정함

사용자 “노이즈필터 추가”, DECISIONS 40행 “DC 제거+80Hz…를 분석 PCM에만 적용”에 비해 적용이 부분적이다. `SoundAnalyzer.kt:47`은 정리한 PCM으로 분류·무음 검사를 하지만, `ClipEvidence.kt:124`는 **원본 PCM**에서 `AcousticShape`를 계산한다. 이 값은 `:70–83`의 대사 분기와 `:89–91`의 “더 커졌어요/길게 이어졌어요” 설명에 사용된다. DC·저주파가 제거됐어도 잡음의 크기 변화가 아기의 발성 강도·리듬으로 표현될 수 있다. 실제 probe도 원본 shape를 쓰며 `cry_with_dc`는 활동비율1·burst1이다. **같은 정리된 신호로 의미에 쓰는 에너지·리듬을 계산하고, 고정된 발성에 DC/증가하는40Hz를 더한 회귀에서 발성 근거가 잡음으로 바뀌지 않는지 확인해야 한다.** 원음 재생은 유지한다. 반대 사건 오분류를 실측했다는 뜻은 아니다.

### 부분 완료 — 어린 음성 경로의 비아기 대조군이 부족함

PLAN S3의 “성인·TV·음악·잡음·무음”, DECISIONS 38행의 “어린이 클래스는 아기의 신원·연령 인증이 아니다”가 기준이다. `SoundTimeline.kt:30–31`은 Child speech3창으로 문장을 허용한다. 22개 결과에는 일반 대화·일반 웃음·음악 등이 있으나 **TV/재생된 어린이 대사와 대상보다 큰 어린이 음성**의 실제 대조 결과는 없다. 새 경로를 일반 Speech와 구분하는 점수 대역 테스트만으로 이 오생성 위험이 검증되지는 않는다. 해당 대조군을 추가하고, 아기 검출이 검증됐다고 보고하지 않아야 한다.

## caf1a9a 후속 검토

`caf1a9a3fbb749d3fb9aa70d8bc09bc0efbf4f27`의 소스 수정으로 위 **P2 구현 결함은 해소됐다.** `AcousticShape.from`은 모델과 동일한 `AudioCleanup.filter` 결과에서 활동비율·커짐·쉼을 계산하고 임시 배열을 지운다. 원본은 동의미 말투의 결정적 선택 키에만 남으며, 재생 데이터는 바꾸지 않는다. `AudioCleanupTest.removedDcCannotBecomeInfantRhythmOrVolumeEvidence`는 DC 단독이 활동/리듬으로 남지 않는 것과 440Hz 발성에 DC를 더해도 의미에 쓰는 특징이 유지되는 것을 검사한다. 정적 재검토에서 새 구현 결함은 발견하지 못했다.

`outputs/QA/sound_probe.py`는 실제 설치 해시·계측 종료 판정과 소스 라벨 불일치를 별도 필드로 보고한다. `--strict`는 명시한 사건 불일치도 실패로 처리하며, 기본 측정의 계측 성공이 정확도 성공으로 표시되지 않는다. 위 출력8·보류14와 불일치4개는 **수정 전 noise-v2 자료**이며 최종 재실행 결과를 대체하지 않는다. 앞선 전체 테스트 통과 수를 새 수정 검증으로 재사용하지 않는다.

**최종 소스 판정: P2 수정 승인, 신규 코드 결함0건.** 최종 통합 실행·22개 음원 재측정은 담당자의 새 증거를 따른다. TV/재생된 어린이·대상보다 큰 어린이의 실제 대조군 부재는 여전히 평가 부분완료다. 이 잔여 범위를 명시하면 코드 통합을 막을 추가 Spec 결함은 없으며, 일반 아기 판독 성능·전체 QA 완료·유료 품질 승인으로 확대할 수는 없다.
