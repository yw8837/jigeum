# 실제 화면 검토 — 0.4.5

root가 `normal/access/album/layout/paywall-layout/review-layout/transfer-e2e`의 실제 실행 결과와 [화면 모음](visual-contact-sheet.jpg)을 검토했다. 화면은 합성 기록만 포함한다.

- 일반 폰: 무료 소리 입력이 주 행동, 결과 문장/대체 표현/저장 버튼 순서 유지. 기록·PNG 공유·아기말북 선택 접근 가능.
- 작은720×1280: 문장 영역과 하단 저장이 구분되고 서로 겹치지 않음. 긴 문장은 스크롤로 접근.
- 200% 글꼴: 문장·기록·이용권·심사 코드 설명의 줄바꿈과 스크롤, 무료 계속하기/복원/심사 확인과 뒤로가기 확인.
- 넓은1280×720: 좌측 navigation rail과 중앙 제한 폭을 유지. 앨범/홈/이용권/심사 입력 접근 가능.
- 심사 접근은 기본 접힘. 펼치면 결제 없는 심사 경로와 실제 암호화 보관 안내가 표시된다. 미설정 빌드에서 확인 동작이 시작되지 않으며 무료 홈으로 복귀한다.
- 저장 선택기에서 앱 프로세스 종료 후 백업 완료, 중복/손상/미래시각 JSON 처리와 후속 저장을 실제 화면/DB로 검증.

화면 밖으로 스크롤되는 요소는 고정 잘림으로 보고하지 않았다. 실제 TalkBack, 한국어 IME의 모든 제조사, 색각 사용자/부모 파일럿, ARM 센서는 이번 x86_64 화면 시험으로 대체하지 않는다.
