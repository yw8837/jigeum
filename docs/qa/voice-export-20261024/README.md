# 직접 음성 녹음 내보내기 조사 — 2026-10-24

사용자가 앱의 `카메라 없이 소리만 녹음` 결과에서 음성+번역 내보내기가 안 되는 것 같다고 제보했다.
오류 문구/실폰 로그는 아직 없다. 사용자 폰은 ADB 미연결이며 폰/기록을 변경하지 않았다.

## 현재 조사

- 소스는 음성 입력을 아가말 PNG 카드 + 원음 AAC의 MP4로 합성하도록 되어 있다.
- 영상에서 추출한 AAC를 사용하는 기존 `TranslatedMediaTests#voiceOnlyRendersCardWithOriginalSound`는
  현재 소유 MoaQA35 host GPU에서1/1 통과했다. 이것만으로 앱 직접 녹음 오류 해결을 주장하지 않는다.
- 실제 앱 마이크 녹음→결과→앨범 MP4→앱 기록의 별도 재현 검사를 추가했다.
  이 검사는 분석기만 대역이며 MediaRecorder/Media3/갤러리/SQLite는 실제다. 음성 인식률 검사가 아니다.
- 수정 전 직접 녹음 경로도 **1/1 통과**했다. `recorded-voice-before.txt`.
- 따라서 사용자 실폰 저장 실패의 원인을 재현했다고 주장하지 않는다. 누른 버튼/오류 문구를 추가 확인 요청한 상태다.

## 확인한 UI 문제와 좁은 수정

소리 전용 결과도 저장 버튼이 `영상 카드 앨범에 저장` / `장면과 함께 저장하기`로 표시되어
원음과 아가말을 함께 저장할 수 있다는 점이 불명확했다. 입력이 음성 전용일 때만 다음과 같이 바꿨다.

- `소리+아가말 카드 앨범에 저장` + 원음/카드 MP4가 사진 앱 아가톡 앨범에 저장된다는 설명.
- `소리와 함께 기록하기`, `저장한 소리와 카드 보기`, 소리 전용 저장 완료 안내.
- 영상 입력의 기존 문구/동작, 저장 권한과 과금 정책, 미디어 합성 엔진은 변경하지 않았다.

## 수정 후 검증

- debug 앱·계측 APK 빌드 성공 (`build.txt`).
- `SavedMediaFlowTest#recordedVoiceResultExportsSoundAndCaptionWithoutSubscription`:
  실제 앱 마이크 녹음→대역 분석 결과→실제 앨범 MP4→실제 앱 기록의 음성/영상 트랙 확인.
  무료 상태에서 통과. 분석기만 대역이며 인식률·실제 아기 소리 정확도 시험이 아니다.
- 기존 영상 PNG/MP4/장면 기록 시험을 함께 실행해 **2/2 통과, 실패0/skip0** (`clarified-ui-after.txt`).
- 실폰 실패 재현/원인/해결은 미확인. 소리 전용 UI 안내 개선을 실제 오류 해결로 부르지 않는다.
- 최종 서명/Play 배포 전 단계이며 이 변경은 아직 사용자 설치본에 반영되지 않았다.
- 소유 MoaQA35의 이번 앱/계측앱을 제거하고 에뮬레이터 종료. 사용자 폰·기록은 미접근.
- 새 로그/근거는 보존하고 이전 정책 차단 빌드 폴더를 삭제하지 않았다.

## 내보내기 정책

기존 PNG/MP4·원음과 번역 보관/공유는 무료 정책이다. 사용자에게 기본 무료 유지를 권고했으며,
유무료 차등 잠금은 적용하지 않았다. 구독·보상형 광고 정식판 준비는 별도 계속된다.
