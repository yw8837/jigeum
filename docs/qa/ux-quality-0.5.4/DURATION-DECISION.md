# 유료 20초 / 30초 비교

2026-10-02. 무료 **60초 촬영 / 10초 분석**은 사용자 확정이다. 유료 촬영은120초이며 분석20초/30초는 사용자가 비교 중이다. 현재 소스·QA 검토본은20초이며 사용자 확정으로 기록하지 않는다.

## 확인한 사실

- 디코더·필터·실제 YAMNet 경로는30초까지 처리한다. 두 분짜리 합성 영상의100–120초 및90–120초를 디코딩하고, 각각15초/25초 이후의 모델 결과가 존재하는지 검증했다.
- 첫 통합 검사에서 소리 필터만15초 상한이 남아 두 검사가 실패했다. 상한을30초로 수정한 뒤 두 검사 모두 통과했다.
- 고정된 모델 관찰로 같은 발성이20초/30초 이어지는 경우를 비교하면 현재 문장 생성기는 같은 표현군을 사용한다. **30초 처리 가능은30초만큼 풍부한 의미의 생성이나 정확도 향상의 근거가 아니다.**
-10초 아기 발성 뒤 무음을 붙였다는 이유로 긴 표현으로 바뀌는 결함과 보호자→침묵→아기 순서의 침묵을 아기의 쉼으로 표현하는 결함을 재현·수정했다. 실제 PCM과 고정 모델 관찰로 분리 검증했다.
- 수정 후 관련18개 계측 검사가 모두 통과했다. 이는 실제 아기 의도/상황 적합성의 정확도 평가가 아니다.

## 현재 추천

첫 버전은 **무료10초 / 유료20초**를 추천한다. 유료는120초 촬영, 더 긴 구간, 같은 구간의 시각 관찰, PDF를 함께 제공한다. 무료 표현을 일부러 단답으로 줄이지 않는다.

30초는 기술적으로 가능한 대안이다. 다만 같은 패턴에서 문장량이 같을 수 있으므로 '3배 더 풍부한 대화'나 시간별 문장 수를 약속해서는 안 된다. 향후 시점별 소리 변화의 표현과 실제 부모 평가를 통해 추가10초의 가치를 확인한 뒤 확대할 수 있다.
