2. **침묵으로 긴 문장 생성:** 같은10초 발성에2초 무음을 추가했을 뿐인데 긴 표현군으로 전환됐다. 허용된 아기 관찰 시작 시각들의 범위가10초를 실제로 넘도록 검사했다(`1401fa6`).
3. **보호자 쉼을 아기 쉼으로 표현:** 보호자 소리→0.5초 침묵→지속된 아기 소리에서 “잠깐 쉬었다가”가 출력됐다. 실제 무음 구간의 시각을 보존하고 바로 앞뒤 모델 관찰이 모두 허용된 아기 후보일 때만 쉼 표현을 사용한다(`0e2f1db`). 화자 신원 확인 모델을 추가한 것은 아니다.
4. 앞선 구현 검토에서 이용권 만료로 분석 취소 후 부모 구간 상태와 화면 구간이 불일치하던 문제를 수정했다. 만료·취소·무료10초 재시도·기존 결과 보존은 전체 계측에 포함된다.
