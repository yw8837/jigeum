## 목표와 경계

사용자가 개선판의 기존 Alpha 업데이트를 요청했다. 현재 ADB 기기는0대이며 사용자는
지금 S25 연결이 어렵다고 답했다. 새 휴대폰 속도·발열 검증은 수행할 수 없다.
대신 기존 합성10/20초 AV 검사에 실제 얼굴이 있는 로컬 파생 영상의 모델 부하 검사를
추가한다. 이는 실폰 성능을 입증하지 않는다. 결과와 위험을 검토한 후 비공개 베타 제출을 판단한다.
폰 측정은 후속으로 남기며, 성능 개선·일반 인식률·아기 화자/감정/욕구 정확도를 주장하지 않는다.
새 모델/권한/요금제/원본 외부전송/프로덕션 변경은 없다. QA는 메인만 Gradle/ADB를 사용한다.
최대5cycle·동일실패3회 중단. 실패를 통과로 바꾸지 않고 원천 및 정리를 보존한다.
