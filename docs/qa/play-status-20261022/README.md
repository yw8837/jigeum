## 작성 근거와 범위

[실제 제출 답변](application-answers.json)은 유료 업체 Zardu 모집과 기존 테스터 참여,
업체의 설치·초기 실행 중심 범위, 별도 실사용 피드백 및 실기기 QA를 구분했다.
갤러리 영상 저장·결과 표시·저장 날짜·뒤로가기 수정과 S25 세로36+가로2 검사,
서명 업데이트 후 미디어 보존·정식 접근 제한 복원 근거를 사용했다.
설치 예측은 근거가 없어 `모름`, 모집 난이도는 신청서에 이미 선택된 `어려웠음`을 유지했다.
미배포 문구 확장·게시판·Google/Kakao 로그인은 제공 완료 기능으로 기재하지 않았다.
