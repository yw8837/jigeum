# 최종 APK 화면 검토 (0.4.3)

normal-result.png: 제목/관찰 설명/주 문장/대안 후보/수정/저장 순서가 구분됨. 고정 저장 버튼과 scroll 내용의 영역이 분리되고 상태바/시스템 gesture영역 침범 없음. 긴 대안 문장은 줄바꿈해 보임. 현재사진은 합성·수동선택, 실제영아의 의미추론을 검증한 자료가 아님.

free-share.png: 시스템 공유판에서 실제PNG preview가 보임. 카드의 문장/날짜/소리·상황/보호자 표현 안내가 겹치지 않음. Android chooser 진입 자체는 실제UI normal scenario에서 확인. 별도UID읽기는 계측 explicitreceiver로 별도검증.

paywall-small.png: 작은 화면 제목/설명/혜택이 줄바꿈하며 scroll 영역에서 이어지고 겹침 없음. paywall-large-font-actions.png: 200% 글꼴에서 무료 계속하기가 여러 줄로 확장되고 복원/관리 행동에 접근 가능. scroll 중 viewport 경계에서 일부 앞 문장이 잘리는 것은 정상이며 시스템바 영역 침범은 보이지 않음. paywall-wide-actions.png: 중앙 좁은 본문 폭을 유지하고 무료/복원/약관/개인정보 행동이 모두 보임. 3화면 모드에서 실제 복원 탭/뒤로가기는 portable UI 검증 pass.

final-home.png: 시험 기록·월령·권한·화면을 정리한 후 cold launch한 홈을 직접 확인했다. 제목, 무료 소리 입력, 전체 이용권 카메라·영상 진입과 하단 내비게이션에 겹침이나 시스템바 침범이 보이지 않았다. 시험 합성 기록이 화면에 남지 않았다.
