## 구현과 이번 개선

- 단일 2열 모바일 그리드, 사진·이미지/영상카드 필터, 최신순 페이지 이동.
- 필터를 DB 페이지 계산 전에 적용한다. 앞쪽 사진이 많아 뒤쪽 영상이 가려지던 문제를 막았다.
- 파일 선택 → 공개 전 미리보기 → 공개 동의 → 게시. 개인 분석·전체 기록 자동 업로드 없음.
- 닉네임/관리 비밀번호로 글·댓글 작성·수정·삭제, 좋아요, 신고, 작성자 차단/해제.
- 댓글 수정·신고 창을 열어도 상세 화면과 작성 중인 새 댓글을 보존한다.
- 브라우저 뒤로가기는 가장 위 창부터 닫으며, 작성 중인 내용을 버릴 때 확인한다.
- 요청 순서를 검사해 오래된 응답이 새 필터/댓글 목록을 덮지 않게 했다.
- 연결 실패/90초 응답 지연은 한국어로 안내하고 파일·작성 내용을 유지한다.
- 파일 준비와 업로드 진행 표시를 구분하고 중복 요청은 같은 요청 ID로 처리한다.
- Android는 지정 HTTPS origin만 내부에서 열고, 준비된 카드는 사용자가 첨부를 선택해야 전달한다.
- Android 밝은 배경에서 상태 표시줄 아이콘이 흐려 보이던 대비를 보완했다.

## 검증

### 자동 검사

- Node **24개 통과**: 실제 인메모리 SQLite + R2 대역. 비밀번호, 다른 작성자,
  삭제/숨김 미디어 접근, 요청 중복, 관리 권한, 용량·형식, 필터와 창 뒤로가기 포함.
- 필터 회귀: 최신 사진45개 뒤 영상23개를 영상 필터로 **20+3개**, 중복 없이 조회.
- TypeScript 검사와 배포용 production build 통과.
- Android `assembleDebug assembleDebugAndroidTest` 통과.
- API35 `CommunityContractTest`3개 + `CommunityFlowTest`1개, **4/4 통과**.
  [실행 로그](android-instrumentation.txt), [준비된 합성 카드 화면](android-prepared-card.png).
- 초기 Flow 검사에서는 JavaScript 클릭이 파일 선택의 실제 사용자 제스처를 만들지 못했고,
  WebView 접근성 노드 클릭도 선택기를 열지 못했다. 실제 좌표 터치를 사용하는 시험 동작으로
  수정한 뒤 파일 선택·미리보기·복귀 취소/확인·초안 정리까지 통과했다.

### 브라우저

- 390px: 문서390px, 2열 약173px. 360px: 문서360px, 2열 약158px. 가로 넘침 없음.
- 합성 MP4 재생 준비 `readyState=4` 확인.
- 댓글 초안 → 신고 창 → 브라우저 Back 뒤 초안 유지. 초안 삭제 거절 뒤에도 유지.
- 기존 댓글을 비밀번호로 수정한 뒤 상세 화면과 작성 중인 별도 댓글 유지.
- 오프라인 게시 실패 시 파일·본문·비밀번호·동의 유지. 온라인 복구 후 동일 초안 재시도로
  정확히1개 게시. 소유 합성 테스트 글3개는 검사 후 삭제.
- 실제 baby 도메인에 최신 빈 필터 문구와 로그인 없는 작성 버튼 확인.
- 브라우저 오프라인·화면 크기 에뮬레이션은 검사 후 원상 복구.

## 보안·운영 범위와 남은 출시 조건

- 관리 비밀번호는 PBKDF2-SHA256 100,000회, 레코드별 난수 salt. 원문 비밀번호 미저장.
- 익명 HttpOnly 쿠키, 동일 origin 변경 요청, 요청 빈도 제한, 삭제 tombstone 후 미디어 제거.
- 운영자는 서버 ADMIN_EMAIL과 플랫폼 검증 ID로 제한한다. 일반 방문자에게 ChatGPT 로그인을 요구하지 않는다.
- 실제 운영자 계정으로 신고 처리·복구하는 전체 UI 인수 검사는 별도로 남는다.
- 영상 제한은 MP4 컨테이너/mvhd 길이 및 용량 검사다. 모든 codec/track 재생을 보장하지 않는다.
- Google/Kakao 개발자 앱/리디렉션 등록·서버 비밀값 설정, 선택적 계정 연결 및 마이페이지는 남았다.
- 앱 배포 전 외부 개인정보처리방침, Play 데이터 보안·UGC·콘텐츠 등급을 실제 새 기능에 맞춰 갱신해야 한다.
- 새 versionCode, 서명 beta, 기존39에서 업데이트/기록 보존과 실제 UI 확인, Play 제출·제공 확인은 미완료다.
- 현재 연구는 일반 인식률·감정/욕구 정확도나 실폰 성능을 새로 입증하지 않는다.

## 정리

실서비스 합성 글2개와 로컬 합성 글3개는 삭제했다. 사용자 원본·S25 기록은 건드리지 않았다.
이전 정책 차단 폴더 삭제는 우회하지 않는다. 빌드·게시 아카이브·실행 상태는 Git 제외 대상이며,
소스·배포 SHA·작은 증거를 보존한다. 에뮬레이터/미리보기 종료 결과는 summary.json을 따른다.
