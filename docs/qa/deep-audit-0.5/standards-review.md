1. **P2 — 시각 모델 실패를 시각 관찰 성공으로 표시한다.** `VideoImport.kt:73–76`은 모델 실패도 문자열로 반환한다. `ClipEvidence.kt:122–124`가 이 문자열을 전달하면 `:97`의 `visualEvidence != null`이 참이 된다. 결과는 `CaptureFlow.kt:325`의 ‘소리 + 표정 관찰’, `MainActivity.kt:273`의 `VIDEO_FILE`로 분류된다. 실패 설명은 접힌 근거에만 남는다. AGENTS의 ‘모델 출력은 관찰 단서’ 및 이용 정책의 실제 시각 관찰 제공과 일치하지 않는 성공 표기다. 재현: `modelAvailable=false, analyzedFrames=0`인 `VideoFrameSummary`의 `visualEvidence()`와 유효 울음 점수를 `interpret`에 입력하면 `interpretation.visual == true`. 모델 전부 실패와 정상적인 얼굴 미검출을 구분해야 한다.

2. **P2 — 늦은 결과 폐기 회귀는 실제 늦은 결과를 발생시키지 않는다.** `AccessNavigationTests.kt:96–107,127–133`의 취소/만료 테스트가 사용하는 `ControlledAnalyzer`는 `:188`의 취소 가능한 `gate.await()`에서 종료된다. `complete()` 뒤 반환문은 실행되지 않으므로 테스트명과 달리 늦은 결과 수락 경로를 검증하지 못한다. 정책의 ‘늦은 결과를 버린다’는 구현 자체가 틀렸다는 증거는 아니지만 해당 QA 증거는 불충분하다. 취소를 무시하고 반환하는 대역과 반환 완료 카운터를 사용해 재검증해야 한다.
