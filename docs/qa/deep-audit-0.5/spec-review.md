# Spec 독립 검토 — 0.5 심층 QA

2026-10-01 · 대상: `git diff 063c183...4d98944`. 이 문서는 최초 읽기 전용 검토 결과다. 아래 행 번호는 검토 대상 커밋 기준이며, 수정·동적 재현·최종 판정은 통합 감사 보고서에서 구분한다.

## 발견 사항

### P2 — 수정 폼을 접으면 수정 문장이 저장되지 않음

이용 정책 12행의 “보호자 수정·메모·저장”과 어긋난다. `CaptureFlow.kt:332`의 “기록 수정 접기”는 `edit=false`로 변경하지만, `:352`의 저장은 `edit`가 거짓이면 원문을 사용한다. **문장 수정 → 수정 접기 → 저장**으로 재현할 수 있는 코드 경로다. 메모는 저장되므로 문장만 조용히 유실된다. 기존 `AccessNavigationTests.kt:109`는 수정 직후 저장만 검사한다.

### P2 — 남아 있는 시각 옵션이 무료 음성 분석을 취소할 수 있음

이용 정책 15행은 “촬영·재생·소리 분석은 이용권 만료와 무관하다”고 정한다. `CaptureFlow.kt:108`의 `reset()`은 `visual`을 초기화하지 않는다. 유료 영상에서 옵션을 켠 뒤 **다시 촬영 → 소리만 녹음 → 이용권 만료 → 무료 분석**하면 실제 요청은 `useVisual=false`인데 `:192`의 감시 루프가 남은 `visual=true`를 보고 취소한다. 음성 화면에는 옵션 스위치도 없어 직접 해제할 수 없다. 정적 분석 결과이며 통합 담당자의 동적 재현이 필요하다.

### 검증 누락 — 실제 영상 구간과 일부 생명주기 승인 기준

UX 명세 26행은 “시간 이동이 실제 PCM·얼굴 샘플 구간에 반영”을 요구한다. 검토 대상 androidTest에는 `inspectVideo` 실행·결과 검증이 없다. `AccessNavigationTests.kt:135`는 재생 시작 문자열과 가짜 분석기에 전달된 범위만 확인하며 재생 종료 경계는 확인하지 않는다. 새 캡처 테스트는 권한을 미리 허용한다. 권한 거절·준비 직전 취소 회귀는 없고, 60초 자동 종료는 오디오만 실측했다.

## 부합 사항과 판정 한계

소리 근거 없는 문장 제거, 수동 선택·월령·재뽑기 제거, 동일 PCM의 안정적 문구 선택, 기존 결과 보존은 명세와 부합한다. 반복 감소와 실제 상황 적합성 향상은 별개다. 현 QA가 후자를 입증하지 않았다는 기존 문서의 제한도 타당하다.

**Spec: 결함 2건, 검증 누락 묶음 1건. 가장 큰 문제는 수정 내용의 조용한 유실이다.**

## 추가 확인 후보

`VideoImport.kt:74`는 시각 모델 실패를 설명 문자열로 반환한다. `ClipEvidence.kt:122`와 `:97`은 문자열의 존재만으로 `visual=true`를 기록해, `CaptureFlow.kt:325` 상단에 “소리 + 표정 관찰”을 표시한다. 실패 설명은 접힌 근거에서만 드러난다. 실제 관찰 성공 여부를 별도 상태로 전달하는 것이 적절하다. 이 항목은 위의 두 P2와 별도로 통합 감사에서 재현·분류한다.

## 수정 후 재검토 — 2026-10-01

작업 트리의 `CaptureFlow.kt`, `ClipEvidence.kt`, `VideoImport.kt`, `AccessNavigationTests.kt`, `VisualEvidenceAuditTest.kt`를 읽기 전용으로 재검토했다. 통합 담당자가 실행한 `work/deep-audit/red-regressions.txt`에서 세 제품 실패를, `work/deep-audit/green-targeted.txt`에서 수정 후 **24개 테스트 정상 종료**를 확인했다. 이 검토자는 별도 Gradle·ADB 실행을 하지 않았다.

**판정: 검토한 세 제품 수정은 승인한다. 추가 제품 결함이나 새 권한 우회는 발견하지 못했다. 전체 제품의 출시·실기기·의미 정확도 승인은 아니다.**

- **수정 문장 보존:** 폼의 열림 상태 `edit`와 내용 변경 여부 `draftEdited`가 분리됐다. 변경 여부와 문장은 모두 복원되고, 저장 및 빈 문장 차단은 폼이 접혀 있는지와 무관하게 적용된다. 폼을 다시 열어도 사용자가 비워 둔 문장을 원문으로 덮어쓰지 않는다. 새 회귀는 접기·상태 복원·실제 DB 저장과 빈 문장 저장 차단을 확인한다.
- **무료 소리 분석 보존:** 재촬영에서 `visual`을 초기화하고, 진행 중 권한 감시는 실제 요청의 `analyzingVisual`을 사용한다. 시작 직전·진행 중·반환 직후의 시각 권한 검사와 늦은 결과 폐기 구조는 유지됐다. 무료 음성 분석에는 이용권 감시가 적용되지 않는다.
- **시각 실패·부분 성공 표시:** 완료·부분 완료·실패가 구조화됐다. 실패 시 이미 얻은 음성 문구는 유지하지만 시각 성공으로 표시하지 않는다. 부분 실패는 실제 분석한 장면 수와 별도 안내를 전달한다. 안내는 접힌 근거 밖에 표시되고 Saver가 보존하며, 과거 저장 상태에 새 필드가 없으면 null로 복원된다. 취소는 실패 안내로 바뀌지 않고 전파된다.
- **늦은 결과 회귀의 개선:** 테스트 분석기는 `NonCancellable` 대기를 사용하고 `returns` 증가까지 기다린다. 이전처럼 단순한 `await()` 취소만으로 통과하는 검사가 아니며, 대기 해제 이후에도 UI에 결과가 나타나지 않는지 검사한다.

### 여전히 구분해야 하는 검증 범위

실제 묶음 얼굴 모델의 선택 구간 실행 검사가 추가돼 “실제 영상 모델 실행 0건”이라는 최초 누락은 해소됐다. 그러나 새 입력은 얼굴이 없는 합성 영상이며 장면별 차이를 단언하지 않는다. 잘못된 앞쪽 3초를 추출해도 장면 수·무얼굴 결과는 같을 수 있으므로 **영상의 시작 시각·장면 변경 경계가 정확한지까지 증명한 검사는 아니다.** 재생 검사는 8초 시작·9초 진행·정지를 확인하도록 개선됐지만, 정확한 종료 시각이나 출력 오디오의 끝 경계를 직접 측정하지는 않는다. 권한 거절·준비 직전 취소·영상 60초 종료의 추가 실행 여부는 통합 보고서의 별도 증거를 따른다.
