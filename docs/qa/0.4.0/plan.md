# 0.4 전체 이용권 통합 QA

협업 체크포인트 f42238c 푸시 및 로컬/원격 SHA 일치 확인 완료. 사용자는 푸시 이후 원래 구현 작업 계속 진행을 요청했다. 기존 0.3 산출물과 49계측 체크포인트 결과를 보존한다.

## 범위와 경계

무료 음성/수동/기록/PNG/JSON/CSV 유지. 카메라/저장영상/PDF를 하나의 전체 이용권으로 묶는다. 앱 로그인·아기 외부 DB 없음. 실제 Play와 ARM은 외부 의존으로 별도. 공개 출시·제출 보류. 테스트 대역은 androidTest에만 둔다. 빌드/ADB 담당은 root 한 명.

각 외부 명령에 timeout. 최대 5 QA cycle, 같은 실패 3회면 원인을 보고하고 멈춤. 설치 환경 실패와 제품 실패를 구분한다. 다른 작업자의 변경, 사용자 기기·데이터, 다른 Cloud 프로젝트를 건드리지 않는다.
