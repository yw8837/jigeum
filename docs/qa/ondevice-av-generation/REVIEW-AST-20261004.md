# AST 통합 변경 검토

기준: `81b2019b2f24d842ddbb34438b85119f48d12275` 이후의 staged 변경, 2026-10-04.
`code-review`의 두 축을 별도 Sol/high 에이전트로 읽기 전용 검토했다.

## Standards

확인된 규칙 위반 0건, 수정이 필요한 구조상 지적 0건.
검토 범위는 모델 해시·원자적 복사, 텐서/세션 수명, 취소 감시, 온디바이스 경계, 넓은 음성 창의 과도한 시각 귀속 방지, 시간순 영상·색상 처리, 평가 자료의 로컬 경로 제한이다.
이는 코드 검토 결과이며 실기기 품질이나 배포 승인이 아니다.

## Spec

1. **P2 — 감정 충돌의 하위 클래스 누락: 수정·검증 완료.** 독립 sigmoid인 AST에서 상위 `Laughter`가 낮아도 `Giggle`이 높을 수 있다. 정책의 “울음/웃음 계열”과 5개 클래스 구현이 불일치했다. 세부 클래스 6개가 높은 합성 입력 6건 모두 잘못 승인되는 RED를 확보하고 v2에서 모두 보류되는 GREEN을 확인했다. 기본116개·연구27개 Android 묶음에 포함된 정책9개도 모두 통과했다.
2. **P2 — 비활성 실험 모델의 기본 패키지 포함: 수정·검증 완료.** Git에서 제외된 91MB 모델과 ORT를 정식/beta 빌드도 필수로 요구했다. 명시적인 연구용 debug 빌드로 분리했고 기본 APK/AAB에서 모델·고지·ORT가 없는 것을 확인했다. 누락/손상 모델과 금지 변형을 포함한 Gradle6게이트도 통과했다.

요구된 원음·영상의 공동 생성, 일반화된 옹알이 회복, ARM 검증, 새 Play 업데이트는 공개된 미완료 요구다. 이미 기록된 미완료를 새 결함 수에 더하지 않았다.

[SDK·템플릿·품질 원인 검토](../../research/20261004-generation-failure-review.md).
배열/문자열 메시지 두 형식은 동일한 템플릿과 응답을 생성했다. 간단한 한국어 대조는 성공했지만 중립 옹알이 표현에는 없는 감정과 사물을 추가했다. 호출 형식 수정만으로 해소됐다고 볼 수 없다. 외부 AI 전송 없이 실행했으며 현재 생성 후보는 채택하지 않았다.
