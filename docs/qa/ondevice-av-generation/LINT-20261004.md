# 경고 검토와 수정 — 2026-10-04

사용자의 경고 해소 요청에 따른 후속 작업이다. 수정 전 AST beta의 Lint 경고는 20개,
일반 release는 19개였다. 수정 전 서명 UI·약국 사례 검증은 `work/ast-beta-package-01/`에
보존한다. 경고 수정 회귀는 `work/ast-beta-package-02/`, 마지막 미디어 보존 수정과
최종 서명 후보는 `work/ast-beta-package-03/`에서 검증한다.

## 코드 수정

- AST native watchdog을 fixed rate에서 fixed delay로 바꿨다. 캐시 상태에서 복귀할 때 누적된
  타이머 호출을 몰아서 실행하지 않는다. 최초 즉시 실행·20ms 간격·원래 절대 deadline·동기화·핸들 정리는 유지한다.
- 절대 deadline이 지난 경우, caller job을 취소하지 않고 native 실행을 종료하고 새 RunOptions로
  실행을 재개하는 회귀 검사를 추가했다. 기존 취소/재분석 검사도 실행한다.
- 설정 화면의 package URI를 KTX `toUri`로 옮겼다.
- 심사 접근 해제는 KTX `edit(commit=true)`로 바꿨다. 키 삭제 전에 동기적으로 저장하는 동작을 유지한다.
- Kotlin의 구형 `kotlinOptions.jvmTarget`을 `compilerOptions`로 이전했다. JVM target은 17 그대로다.
- Media3의 deprecated sequence 생성자를 바꿨다. 검토 중 explicit AV factory가
  오디오 없는 영상에 무음 트랙을 만들 수 있음을 발견하여, 영상은 단일 EditedMediaItem을
  직접 내보내도록 보완했다. 음성에 문장 카드를 붙일 때만 영상/음성 composition을 명시한다.
  원본 영상·원음과 소리 없는 영상의 트랙 보존을 실제 코덱으로 검사한다.

## 의도적으로 유지하는 권고

아래 항목은 lint suppression이나 baseline에 숨기지 않고 원래 검사를 유지한다.

| 경고 | 개수 | 유지 이유 |
|---|---:|---|
| UseKtx | 7 | `SharedPreferences.commit()`의 성공 Boolean을 확인한다. KTX edit는 Unit이므로 단순 대체하면 실패 확인이 사라진다. 앨범 저장/삭제 journal 2, 이전 기록 정리 1, 구매 설치 ID/승인 2, 심사 설치 ID/승인 2 |
| UsableSpace | 2 | 촬영40MiB·렌더80MiB 기준은 당장 쓸 수 있는 공간이다. 회수 가능한 cache까지 더한 allocatable을 실제 여유 공간으로 취급하지 않는다. readiness 검사에서 OS cache 회수나 공간 선점을 추가하지 않음 |
| GradleDependency | 1 | 최신 Lifecycle2.11 Compose군으로 옮기려면 현재 검증 범위를 벗어나는 AGP9.2 전환이 필요함 |

`commit()` 성공 검사를 없애거나 `usableSpace`를 동일 의미의 다른 API로 바꾸기만 해서 경고를 피하지 않는다.
남은 경고는 오류 또는 크래시 실측 건수와 다르다. 새 실패나 보안 원천이 나오면 판단을 갱신한다.

## 최종 검증

경고 수정 후 beta/release Lint는 각각 **오류 0 / 경고 10**이다. 위 권고 10개만 남았고
추가 suppression/baseline은 없다. 타이머/ApplySharedPref/URI 권고와 호환 가능한 버전 경고는 해소됐다.

`ast-beta-package-02/regression-01/result.json`은 121개 통과 / 실패·제외 0이다:
native 취소·기한·재사용 3, 저장·구매·심사 접근 21, UI·접근·구간 37, 미디어 45,
protobuf 2, 영상 시간순 관찰 13. 별도 candidate 앱을 지웠고 기존 테스트 제품 설치 정보는 동일했다.

마지막 single-item export 수정 뒤 `ast-beta-package-03/media-final/result.json`의
미디어 46개가 모두 통과했다. 앞선 45개를 재검증하고 video-only 트랙 보존 1개를 더했다.
따라서 중복을 뺀 관련 검사는 122개이며, 167개의 서로 다른 검사를 했다고 세지 않는다.
AST·권한·UI의 76개는 마지막 미디어 수정 전 검사임을 구분한다. 미디어 수정 후 빌드는 exit0 / 33.62초다.

독립 Spec 검토는 미해결 P1/P2를 찾지 못했다. 실행 검사와 부모의 Standards 검토를 대신하는 주장은 아니다.
최종 서명 설치본의 업데이트/전체 UI와 파일 해시는 [패키지 QA](AST-BETA-PACKAGE-QA.md)에 확정한다.
최종03 서명본의 23→25 업데이트와 UI 7개 시나리오, 알려진 옹알이 사례가 모두 통과했다.
검사 전용 AVD와 격리 QA state도 제거했다. 이 결과는 소리·영상의 의미 생성 정확도 검증을 포함하지 않는다.
`android.overridePathCheck=true`는 한글 작업 경로를 위한 기존 빌드 설정이고,
구형 SDK command-line tool의 XML 형식 안내는 개발 환경 경고다. 이를 앱 Lint 수치와 합산하지 않는다.
