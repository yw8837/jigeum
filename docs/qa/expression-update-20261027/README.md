## 사용자가 확정한 자동 흐름

사용자는 ‘판별없어?? 자동으로 나와야지’라고 답했다. 처음 검토한 수동 자막 선택기는 제거했다.
`DeviceClipAnalyzer`가 기존 소리 해석을 얻은 뒤 `AutomaticBabySpeech`를 호출한다.
기존 인식 모델, 소리 승인 임계값, 소리 종류/순서/시간, 돌봄 안내는 유지한다.

| 이미 승인된 관찰 | 추가 가능한 자동 창작 표현 |
|---|---|
| 시간창이 있는 단일 울음 | ‘흥!’, ‘싫어잉’, ‘귀찮아잉’ 같은 투정 말투 |
| 시간창이 있는 단일 아기 웃음 후보 | 신나는 놀이 말투 |
| 시간창이 있는 단일 옹알이/어린 말소리 후보 | 장난·애교 말투 |
| 위 옹알이/어린 말소리와 아래 영상 조건 | ‘졸려’, ‘하암’ 소재의 말투 |
| 실패/보류/일부만 승인/넓은 AST 창/소리 종류 미확정/여러 종류 혼합 | 기존 결과 유지, 이 창작 층을 추가하지 않음 |

같은 PCM 파생 키에는 같은 문장을 선택한다. 이전 영상의 결과를 저장해 재사용하지 않는다.
키는 허용된 말투 안에서 문장을 고를 뿐, 졸림의 선택 조건이나 감정 점수가 아니다.
기존 관찰 문장을 보존하며 합계160자를 넘는 후보는 제외하고 문장을 자르지 않는다.
실제 마음과 구분하도록 화면·기록·JSON·카드의 출처를 `AUDIO_PLAYFUL` 또는 `AUDIO_VISUAL_PLAYFUL`,
‘소리를 참고해 상상한 아가말’ 또는 ‘소리와 장면을 참고해 상상한 아가말’로 표시한다.
보호자가 수정하면 기존 계약대로 `CAREGIVER`로 바뀐다. DB/JSONv2 스키마는 변경하지 않았다.

### 졸림 소재를 허용하는 영상 모양 규칙과 한계

3~20초 전체 선택 구간, COMPLETE 상태, 실제 증가하는 디코딩 시각, 최대 표본 간격750ms,
11개 이상 표본, 모든 표본의 유효한 단일 얼굴 및 유한한 눈/입 계수를 요구한다.
눈 감김>=0.65·입 벌림>=0.32가 연속4표본 이상이면서1,200ms 이상 이어지고,
전후 각각2표본이 눈 감김<=0.35·입 벌림<=0.12로 돌아와야 한다. 각 전후 쌍은 경계750ms 이내다.
기존 영상 표본 간격은200ms이고 이를 변경하지 않았다.
한 번 깜빡임, 정지한 열린 입, 시각 누락/역순/중복/긴 간격, 여러 얼굴, 계수 누락/NaN은 제외한다.

**이것은 합성 계수로 검사한 영상 모양 규칙이며 검증된 하품·졸림 판별기가 아니다.**
화면 인물과 발성 주인이 같은지도 확인하지 않는다. 눈·입 계수는 졸림 확률이 아니다.
‘귀찮아’ 역시 울음에 연결한 작가의 재미 표현이며 귀찮음과 다른 울음 원인을 구별한 결과가 아니다.
실제 아기 자료의 정답/오탐률, 졸림·귀찮음·욕구 정확도, 새 실폰 속도/발열은 이번에 측정하지 않았다.

## 앱 시작 업데이트 안내

공식 `com.google.android.play:app-update:2.1.0`의 `AppUpdateManager.appUpdateInfo`를 사용한다.
Play가 해당 사용자/국가/트랙에 UPDATE_AVAILABLE을 반환하고 설치 버전보다 높을 때만 표시한다.
검토 중 버전이나 웹에 적힌 최신 버전을 별도 비교하지 않는다.
홈 로딩 완료 및 분석/내보내기/미디어 보기 중이 아닐 때 표시한다. ‘업데이트’는 정확한 Play 상세 페이지,
‘나중에’와 뒤로 닫기는 같은 버전을24시간 보류한다. 더 높은 버전은 별도로 안내할 수 있다.
오프라인/조회 실패/Play 외 설치는 앱 사용을 막지 않는다. 자동 설치나 강제 업데이트는 아니다.
기존41/42에는 이 기능이 없어43을 먼저 설치해야 이후 업데이트부터 안내받을 수 있다.
