## 요구사항 부합

- **구매·심사 코드 없이 실행:** PLAN 7행. `AccessPolicy.kt:48`이 명시적 테스트 배포에서 시각 분석과 PDF를 허용하고, `MainActivity.kt:269,343`이 실제 실행 경로에도 같은 정책을 전달한다. PDF 버튼만 열고 실행을 막는 구조는 아니다. `MainActivity.kt:136`의 진입값은 빌드 상수이며 UI·구매 콜백으로 만들어 낸 권한이 아니다.
- **출시 제한 복구:** PLAN 7·22행. `app/build.gradle.kts:31`의 기본값은 false, `:68`의 preview만 true다. 테스트 권한을 DB·환경설정에 저장하는 변경은 없다. 출시 버전에서는 기존 시각 시작·진행·반환 검사와 PDF 실행 시 권한 검사가 유지된다. 이는 정식 업데이트 시 복구이며 기존 preview 설치본의 원격 자동 잠금은 아니다.
- **같은 설치·기록 유지:** PLAN 7행. `app/build.gradle.kts:26`은 패키지를 유지하고 버전 코드를 15로 올린다. preview는 release 설정을 상속하며, `build-test-apk.ps1:11,25–26`은 기존 업로드 키·별칭을 사용한다. DB 삭제·새 저장소·앱 로그인·외부 업로드 변경은 없다.
