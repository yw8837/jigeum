# 두 축 독립 검토 — 0.5.6

기준점 `31042d7cbf6a0333d43abf43222822c2fa6a3937`와 작업 트리 비교. Standards/Spec은 서로 독립된 읽기 전용 검토이며 Gradle·ADB는 root 한 명이 실행했다.

## Standards

- **완료:** 이미지 제작 후 dispatcher 반환 중 취소되면 bitmap 소유권이 유실될 수 있었다. IO 블록에서 소유 변수에 먼저 채택하고 미공개 bitmap만 정리한다. 화면에 공개한 bitmap은 Compose 참조와 함께 GC 수명으로 관리한다.
- **완료:** 저장 완료 저널 이후 취소·게시 실패·삭제 실패가 겹치면 재시작에서 취소한 결과를 게시할 수 있었다. catch는 삭제 전에 `written=false`를 영속 기록하고, 성공 저널 제거 직후 취소 경계에서도 삭제 의도를 복원한다.
- **완료:** Android26–28에서 insert와 URI 기록 사이 종료 시 파일만 삭제하고 MediaStore 행은 남길 수 있었다. UUID와 검증된 정확한 DATA 경로로 행을 검색·삭제하며 파일 삭제 실패 시 저널을 유지한다.
- **완료:** 새 취소 회귀가 작업 취소 직후 일반 IllegalStateException을 던져 부모 테스트를 실패시켰다. androidTest 제공자는 해당 경로에서 CancellationException을 던지며 실제 오류·취소 경로를 구별한다.

최종 정적 검토 당시 처음 세 코드 결함은 보완 확인. 취소 테스트 지적은 이후 수정·focused3 20/20에 포함됐다. journal 제거 이후 dispatcher 취소 경계 자체는 정적 검토 범위다.

## Spec

- **완료:** 최초 카드 문장27px는 작은 화면에서 약12dp가 되고 fontScale을 반영하지 않았다. 본문56px×fontScale(1..2), 긴 문장은 높이 확장, 영상의 선택 장면 영역은640px를 유지한다.
- **완료:** 기록 창의 갤러리 완료 안내가 아래에 가려졌다. 창 안의 완료 문구를 BringIntoView로 보여 준다.
- **완료:** 갤러리 사본·Android8/9 쓰기 권한·기록 삭제 후 사본 보존·사진 앱 클라우드 백업 안내를 앱과 공개 정책에 반영했다.
- **완료:** MediaProvider 정리 오류가 정상 SQLite 기록 로드까지 막았다. 정리는 재시도 상태를 유지하며 Boolean으로 알리고 기록 로드를 완료한다.
- **경계:** MediaStore의 `external_primary`/실제 외부 볼륨 URI도 구조·소유권 검사를 거쳐 허용하도록 보완했다. 외부 볼륨/OEM별 실행은 별도다.
- **미검증 범위:** API35에서 legacy DATA 복구 알고리즘을 검증하되 Android26–28 권한·제공자 실동작을 검증한 것으로 보고하지 않는다.

두 축에서 지적한 제품 결함은 수정했고 정적 재검토에서 추가 확정 결함은 없었다. 실행 완료 범위와 잔여 항목은 [QA 보고서](README.md)를 따른다.
