# Play 비공개 테스트 전체 기능 — 0.5.8/code22

## 사용자 요청

2026-10-02: 테스트 기간에는 Play에서 등록·설치한 테스터도 **유료판 전체 기능을 구매 없이 사용**하고 정식 출시 후 유료화한다. 앞선 release21은 무료 범위로 남아 있어 이 요청을 충족하지 못한다.

## 변경 계약

- 전용 `beta` 빌드는 같은 패키지·기존 업로드키의 Play 비공개 테스트용 AAB/APK다. 기존 sideload `preview`는 Play에 제출하지 않는다.
- beta에서 전체 120초 촬영/녹음·20초 분석·200MB 영상 가져오기·시각 관찰·PDF를 구매 없이 개방한다. 실제 구매·PENDING·심사 코드를 위조하거나 권한을 저장하지 않는다. 표시된 MB의 구현 단위는 MiB(1,048,576바이트)다.
- 홈/촬영/돌봄에 전체 기능 테스트와 120초/20초 범위를 표시한다. 테스트 안내에서 구매·복원·구독 관리 버튼을 숨기고 정식 업데이트 후 무료/이용권 범위를 설명한다.
- 정식 `release`는 테스트 접근 false 및 실행 시 `hasCurrentEntitlement()` 검사를 유지한다. beta 사용 후 정식 버전으로 바꾸면 새 유료 작업을 제한하며 기존 결과·기록·무료 내보내기는 보존한다.
- 전체 기능 개방은 배포본의 설정이다. Google 그룹 가입으로 영구 구매 권한을 만들지 않으며 자동 만료·강제 업데이트를 약속하지 않는다. 향후 정식 Play 버전은 code23 이상과 실제 Play 서명/업데이트 경로 검증이 필요하다.
- 모델·분석 임계값·기록 DB·외부 서버·제품 가격·상품 등록·실제 거래·프로덕션 출시는 이 변경에 포함하지 않는다.

## 검증과 제출

컴파일된 beta/release 배포 표시·서명·16KiB 정렬·모델 동일성을 검사한다. 최종 서명 beta에서 실제 120초 자동 촬영·20초 선택·200MB 범위·영상 분석 접근·PDF를 검증한다. 정식 release 수동 교체로 무료 60/10 복구·기존 기록 유지를 확인하되 이를 Play 자동 업데이트로 보고하지 않는다. 전체 계측을 실행하고 완료 수·skip·설치 해시를 확인한다. 이후 beta AAB만 Alpha에 업로드·검토 제출하며 실제 게시·참여 가능을 별도 증거로 보고한다.
