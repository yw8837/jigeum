# 아가톡0.5 폰 테스트

**테스트 후보**: `outputs/Agattok-0.5.0-code13.apk`. 앱서랍에서 **아가톡**을 찾는다. 새 파일의 해시·검증 결과는 [QA](qa/0.5.0/README.md)에 있다.0.4.5는 이전 기준본으로 보존한다.

## 무료로 바로 확인

1. 기존 업로드 서명 앱에는 업데이트 설치한다. 다른 서명이면 삭제 전 **돌봄 → 전체 기록 백업하기**로 기존 자료를 먼저 보관한다.
2. **아기말 번역하기 → 카메라 준비하기 → 녹화 시작**. 최대1분 담는다. 카메라 없이 소리만 녹음도 가능하다.
3. 촬영을 마치고 먼저 재생한다. 양 끝 손잡이로 아기 소리가 있는1–15초를 고른다.
4. **이 구간 소리로 번역하기**. 한마디·근거가 장면에 맞는지 본다. 같은 구간은 같은 결과여야 한다.
5. 근거가 없으면 한마디가 안 나올 수 있다. 특히 무음·성인 말·TV가 아기 대사로 나오면 실패 사례로 남긴다.
6. 결과 수정·저장 → 기록 → PNG 공유·백업/복원을 확인한다. 원음·영상은 임시 자료라 기록에 남지 않는다. 결과에서 나가기 전에 필요한 구간을 들어본다.

개월수/소리/상황을 고르는 화면과 후보 재뽑기는 제거했다.0.5 문구는 소리를 바탕으로 상상한 말이며 배고픔·졸림의 검증된 번역이 아니다.

## 전체 기능 접근

- 같은 클립의 **표정도 함께 보기** 또는 돌봄의 **구매 복원 · 이용권 관리**에서 기존 심사 접근 경로를 사용한다.
- **Play 심사 접근 → 심사 접근 코드 → 심사 접근 확인**으로 서버가 서명한 권한을 받는다. 구매/구독이 발생하지 않는다.
- 실제 코드는 저장소 밖 개인 안내 `%USERPROFILE%/.jigeum/verifier-20261001/owner-test-guide.txt`에만 있다. 이슈·Git·공유 APK에 넣지 않는다.
- 얼굴·입 열림 관찰과 PDF를 확인하고 **심사 접근 해제**한다. 새 시각 분석/PDF만 잠기고 촬영/재생/소리/기존 기록은 무료로 남아야 한다.

인터넷은 코드/구매 검증에 사용하며 원본 아기 미디어를 보내지 않는다. 현재 상품 등록·실제 거래는 보류 상태다. 안내 작성이 사용자 폰에서의 활성화/해제 완료를 뜻하지 않는다.

## 남길 피드백

기기명·Android 버전·선택 구간·실제 장면 설명·출력 문구·어울리는 정도(1~5)를 남긴다. 특히 울음→즐거운 말, 웃음→불편한 말, 아기 소리 없음→대사는 우선 결함이다. 단순히 다른 문장이 나오는 것만으로 분석이 좋아졌다고 평가하지 않는다. 사적인 원본이나 심사 코드를 공개 이슈에 첨부할 필요는 없다.
