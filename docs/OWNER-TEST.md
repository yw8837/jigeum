# 아가톡 0.5.8 베타 전체 기능 테스트

**설치할 파일:** 다운로드 `아가톡 테스트/아가톡-전체기능테스트.apk` 하나. 원본은 `outputs/Agattok-0.5.8-beta-code22.apk`다. 앱서랍은 **아가톡**, 버전은 **0.5.8-beta**, 홈에는 **전체 기능 테스트 · 2분 촬영 · 20초 분석**이 표시된다. 구매·심사 코드·앱 로그인 없이 긴 촬영·시각 관찰·PDF까지 사용한다. [QA](qa/closed-test-0.5.8/README.md).

Play 전용 beta22 AAB도 같은 전체 범위를 개방하며 현재 **Alpha 업로드·검토 전송 완료·Google 검토 중**이다. Google 그룹 → 같은 계정 Play 테스터 참여 → Play 설치는 [초대 안내](release/20261002/TESTER-INVITE.md)를 따른다. **직접 설치 APK는 Google Play의12명·연속14일 참여를 대신하지 않는다.**

정식 무료60초/10초/100MB, 전체120초/20초/200MB 정책은 유지한다. 유료20초/30초 상용 최종 결정·상품·실거래는 별도다.

## 바로 확인

1. 기존 업로드 서명 앱에는 업데이트 설치한다. 다른 서명이면 삭제 전 **돌봄 → 전체 기록 백업하기**로 문장을 보관하고, 영상이 있는 기록은 **장면 보기 · 내려받기**에서 MP4도 따로 보관한다. JSON 백업에는 영상·소리가 없다.
2. 짧은 아기 일러스트·앱명 타이틀 뒤 홈으로 자동 진입한다. 타이틀은 탭으로 건너뛸 수 있다. **아기말 번역하기 → 녹화 시작**. 최초 한 번만 카메라·마이크 권한을 허용한다. 이미 허용했다면 바로 미리보기가 준비된다. 자동 녹화는 하지 않는다. 이 전체 기능 테스트본은 최대2분, 소리만 녹음도 가능하다.
3. 촬영을 마치고 먼저 재생한다. 양끝 손잡이로 아기 소리가 있는1–20초를 고른다. 가운데를 끌면 길이를 유지한 채 구간 전체가 이동한다. 선택 구간 밖을 누르거나 앞/뒤0.5초 버튼으로 통째로 이동할 수도 있다. 파형·영상 미리보기·확대·0.5초 조절로 원하는 부분을 맞추고 **선택 구간 다시 듣기**로 확인한다. 원음부터 작으면 수음 문제이고 원음은 들리는데 문장이 없으면 분석 보류일 수 있다.
4. 영상은 **표정도 함께 보기**가 기본으로 켜져 있다. **영상 + 소리로 번역하기**를 누른다. 옵션 행을 누르면 소리만 분석할 수도 있다. 한마디·근거가 장면에 맞는지 본다. 같은 구간은 같은 결과여야 한다.
5. 근거가 없으면 한마디가 안 나올 수 있다. 특히 무음·성인 말·TV가 아기 대사로 나오면 실패 사례로 남긴다.10초보다 긴 구간도 실제 아기 발성이 충분히 이어질 때만 긴 표현을 만든다. 무음을 덧붙여 길어진 구간에서 문장이 늘어나거나, 보호자가 쉰 순간을 아기가 쉬었다고 표현하면 오류로 남긴다.
6. 결과의 **‘카드 이미지 앨범에 저장’**을 누르면 카드 디자인 그대로 PNG가 사진 앱의 ‘아가톡’ 앨범에 저장된다. **‘영상 카드 앨범에 저장’**은 선택 구간 영상·원래 소리·최종 편집 문장 MP4다. 녹음만 있으면 실제 녹음과 문장 카드 동영상이 담긴다. 저장 완료 안내와 사진 앱에서 실제 재생을 확인한다. Android8/9는 저장할 때만 쓰기 권한을 요청한다.
7. 앱 안에도 보관하려면 ‘영상·소리 함께 보관’을 켜고 **‘장면과 함께 저장하기’**를 누른다. 기록 → **‘장면 보기 · 내려받기’**에서 재생·앨범 저장·파일 저장·공유를 확인한다. 체크를 끄면 앱에는 문장만 남는다. JSON·CSV·PDF에는 미디어가 없으므로 MP4도 따로 보관한다. 예전 텍스트 기록의 원본은 복구할 수 없다. **아기말북 → 네 가지2×2표지 선택 → 이 달의 아기말북 PDF 만들기**와 백업/복원도 확인한다. 앱 기록을 지워도 사용자가 앨범에 저장한 사본은 남으며 사진 앱의 클라우드 백업은 그 앱 설정을 따른다.

개월수/소리/상황을 고르는 화면과 후보 재뽑기는 제거했다.0.5 문구는 소리를 바탕으로 상상한 말이며 배고픔·졸림의 검증된 번역이 아니다.

## 테스트 종료 후

- 베타 접근은 구매 이용권이 아니며 저장되지 않는다. 베타 자체에 자동 만료/강제 업데이트는 없다.
- **정식 버전 업데이트** 후 긴 촬영·10초 초과 분석·새 시각 관찰·PDF에 실제 이용권이 필요하다. 기존 기록·저장 영상·완성 PDF·무료 내보내기는 유지한다.
- beta22 이후 정식 Play 전환은 **code23 이상**과 실제 Play 서명/설치 경로 확인이 필요하다. 같은code22 release 수동 교체는 로컬 재잠금 검증이며 자동 업데이트 완료가 아니다.
- Google Play 앱의 서명은 업로드키로 만든 직접 설치 APK와 다를 수 있다. 설치 충돌 시 삭제부터 하지 말고 문장 JSON과 MP4를 각각 보관한 뒤 경로를 확인한다.
- 테스트에는 `beta` 파일을 사용한다. 정식 정책 비교용 `release`와 sideload 전용 `preview`를 Play 테스트 파일로 혼동하지 않는다. 상품 미등록으로 현재 실제 이용권 구매는 제공하지 않는다.

표정 관찰은 얼굴·입 열림 단서이며 욕구/감정을 맞히는 검증이 아니다. 사용자 실제 폰·Play split 설치·거래·아기 의도 정확도는 로컬 QA와 구분한다.

## 남길 피드백

기기명·Android 버전·앱 버전·선택 구간·실제 장면 설명·출력 문구·어울리는 정도(1~5)를 남긴다. 특히 울음→즐거운 말, 웃음→불편한 말, 아기 소리 없음→대사는 우선 결함이다. 구간 조절 난이도,10초와20초 결과의 차이도 기록한다. 단순히 다른 문장이 나오는 것만으로 분석이 좋아졌다고 평가하지 않는다. 사적인 원본이나 심사 코드를 공개 이슈에 첨부할 필요는 없다.
