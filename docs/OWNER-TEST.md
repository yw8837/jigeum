## 전체 기능을 열고 닫기

1. 현재 APK를 Android 폰에 설치한다. 서명이 다른 이전 테스트 앱을 지워야 한다면 먼저 무료 JSON 백업을 보관한다.
2. 카메라 버튼 또는 돌봄의 **구매 복원 · 이용권 관리**에서 이용권 화면을 연다.
3. **Play 심사 접근 → 심사 접근 코드 → 심사 접근 확인**으로 실제 서버 서명 이용권을 받는다. 구매·구독 가입은 발생하지 않는다.
4. 카메라·선택 영상·PDF를 확인한다. 코드 확인·재확인은 인터넷이 필요하며 원본 아기 기록을 서버로 보내지 않는다.
5. 끝나면 **심사 접근 해제**를 누른다. 기기의 암호화 코드·심사 캐시가 삭제되고 유효한 구매가 없는 기기는 다시 잠긴다.
6. 무료 문장 초안·저장 기록·PNG/백업과 이미 내보낸 PDF가 남는지 확인한다.

실제 코드는 저장소 밖 개인 안내 파일 `%USERPROFILE%/.jigeum/verifier-20261001/owner-test-guide.txt`에만 있다. 사용자/SYSTEM ACL을 확인했다. Git·QA ZIP·APK에 넣거나 공개 공유하지 않는다. 이 경로는 운영자의 현재 개인 테스트용이고 일반 테스터 일괄 배포용으로 준비한 코드가 아니다.

앱 전체를 무조건 유료로 표시하는 Boolean이나 코드가 내장된 테스트 APK를 만들지 않았다. 테스트 접근은 기존 서명 검증 경로를 사용한다. 최대 24시간 캐시와 재부팅 후 온라인 재확인을 따른다. 각 테스트 기기에서 접근을 해제해야 하며 이번 안내를 만들었다는 사실이 사용자 휴대폰의 활성화·해제 완료나 모든 기기의 원격 회수를 뜻하지 않는다.

## 폰에서 확인할 순서

- 무료: 녹음·직접 입력 → 후보 3개 → 수정·저장 → 기록 → PNG → JSON 백업/복원.
- 전체 접근: 전후면 카메라 → 중지/뒤로 → 소리가 있는 짧은 저장 영상 → 문장 저장 → 월별 PDF 생성·열기·공유.
- 예외: 마이크/카메라 거부, 손상 영상, 30초/50MB 제한 초과, 화면 끄기·앱 전환, 큰 글씨.
- 재잠금: 심사 접근 해제 → 카메라·영상·새 PDF 잠금 → 기존 기록·무료 내보내기 보존.
- 표현: 문장이 그때의 상황에 어울리는지, 어색하거나 반복되는 말, 수정 동선을 기록한다. 현재 문구는 관찰 안내가 많이 섞인 유한한 후보 조합이다.

기기명·Android 버전·앱 버전·실패 단계만 피드백으로 남긴다. 아기 원본이나 코드를 이슈에 붙일 필요는 없다. 물리 단말/보호자 사용성 결과를 아직 수집한 것은 아니다.
