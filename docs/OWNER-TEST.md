# 아가톡 0.5.2 전체 기능 테스트

**설치할 파일**: `outputs/Agattok-0.5.2-test-code15.apk`. 앱서랍에서 **아가톡**을 찾는다. 상단에 **테스트 버전 · 전체 기능 열림**이 표시돼야 한다. 구매·심사 코드·로그인 없이 표정 관찰과 PDF까지 사용한다. [이번 QA](qa/test-access-0.5.2/README.md). 기존0.5.1 APK에는 테스트 접근 요청이 반영되지 않아 잠금이 있었다.

## 바로 확인

1. 기존 업로드 서명 앱에는 업데이트 설치한다. 다른 서명이면 삭제 전 **돌봄 → 전체 기록 백업하기**로 기존 자료를 먼저 보관한다.
2. **아기말 번역하기 → 녹화 시작**. 최초 한 번만 카메라·마이크 권한을 허용한다. 이미 허용했다면 바로 미리보기가 준비된다. 자동 녹화는 하지 않는다. 최대1분, 소리만 녹음도 가능하다.
3. 촬영을 마치고 먼저 재생한다. 양 끝 손잡이로 아기 소리가 있는1–15초를 고른다.
4. 영상은 **표정도 함께 보기**가 기본으로 켜져 있다. **영상 + 소리로 번역하기**를 누른다. 옵션 행을 누르면 소리만 분석할 수도 있다. 한마디·근거가 장면에 맞는지 본다. 같은 구간은 같은 결과여야 한다.
5. 근거가 없으면 한마디가 안 나올 수 있다. 특히 무음·성인 말·TV가 아기 대사로 나오면 실패 사례로 남긴다.
6. 결과 수정·저장 → 기록 → PNG 공유·백업/복원, **아기말북 → 이 달의 아기말북 PDF 만들기**를 확인한다. 원음·영상은 임시 자료라 기록에 남지 않는다. 결과에서 나가기 전에 필요한 구간을 들어본다.

개월수/소리/상황을 고르는 화면과 후보 재뽑기는 제거했다.0.5 문구는 소리를 바탕으로 상상한 말이며 배고픔·졸림의 검증된 번역이 아니다.

## 테스트 종료 후

- 테스트본의 전체 접근은 구매 이용권이 아니며 저장되지 않는다. 코드 입력·결제 검증 서버 연결이 필요 없다.
- 테스트 APK 자체에는 자동 만료가 없다. 테스트 종료 시 **정식 버전 업데이트 설치**로 새 표정 관찰·PDF의 이용권 제한을 복구한다. 기존 기록·완성 PDF는 남는다.
- 다음 실제 Play 배포는 테스트본보다 높은 **versionCode 16 이상**으로 만든다. 함께 보관한 code15 release는 수동 업데이트·재잠금 검증용이며 Play 자동 업데이트 완료를 뜻하지 않는다.
- 같은 서명·패키지이므로 앱 아이콘을 하나 더 만들지 않는다. 기존 Google Play 앱이 별도 Play 서명으로 설치됐다면 업로드키로 서명된 로컬 APK와 서명이 다를 수 있다. 이 경우 삭제부터 하지 말고 기록을 백업하고 설치 경로를 확인한다.
- `release` 이름의 APK/AAB는 출시 정책 검증용으로 별도 보관한다. 지금 기능을 시험할 때는 위 **test** 파일을 사용한다. 공개 Play 제출은 하지 않았다.

표정 관찰은 얼굴·입 열림 관찰이다. 아기 욕구나 감정을 맞히는 기능으로 검증된 것은 아니다. 현재 상품 등록·실제 거래와 ARM 폰 검증은 별도이며, 사용자 폰에서 새 설치본 검증이 끝났다고 보고하지 않는다.

## 남길 피드백

기기명·Android 버전·선택 구간·실제 장면 설명·출력 문구·어울리는 정도(1~5)를 남긴다. 특히 울음→즐거운 말, 웃음→불편한 말, 아기 소리 없음→대사는 우선 결함이다. 단순히 다른 문장이 나오는 것만으로 분석이 좋아졌다고 평가하지 않는다. 사적인 원본이나 심사 코드를 공개 이슈에 첨부할 필요는 없다.
