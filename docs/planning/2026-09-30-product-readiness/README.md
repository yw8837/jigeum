## 외부 준비와 결정이 필요한 부분

실제 Play 검증에는 앱·상품 설정과 운영 검증 서비스가 필요하다. Cloud 프로젝트 선택, 키·계정 권한, 업로드 서명 및 실제 결제는 별도 허가와 사용자가 수행할 단계가 있을 수 있다. 정책·약관 URL과 시행일, 스토어 자료, ARM 설치 검증까지 각각 완료 증거를 남긴다.

연구 자료를 새로 수집하거나 아기 원음·영상·임베딩을 외부로 보내는 일은 승인하지 않았다. 보고서의 대규모 모델 연구 계획은 이후 선택지이며, 이번 주 부모 확인형 테스트본에 일괄 선행조건으로 붙이지 않는다.

각 변경의 담당자·커밋·검증 결과를 PR에 남기고 이미 작업 중인 파일은 서로 덮어쓰지 않는다. PM은 가격이나 범위 변경 등 제품 결정을 맡고, 구현·검증 결과에 따라 출시 범위를 확정한다.
