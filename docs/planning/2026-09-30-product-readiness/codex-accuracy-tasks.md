# 지금 내 기분이 그래 관찰 정확도 개발 작업안

기준: [f83887c](https://github.com/yw8837/jigeum/tree/f83887c), 2026년 9월 30일  
관련 자료: [정확도 개선 계획](accuracy.md), [합성 좌표 검산](geometry-regression.py)

이 문서는 후속 개발에 넘길 작업 지시안이다. 앱 수정·모델 학습은 아직 실행하지 않았다. P0는 관찰 신뢰도를 위한 개발 순서이며 입증된 안전 비상사태를 뜻하지 않는다. 현재 보호자 확인형 테스트 베타와 이후 모델 검증 프로그램을 구분한다.

## 작업 1 입 벌림 계산 수정

목표: 가로·세로 프레임 때문에 같은 입 모양의 비율이 바뀌는 문제를 고친다.

- CameraScan과 VideoImport에 동일한 순수 Kotlin 함수를 사용한다
- d(i,j) = hypot((x_i−x_j)×W, (y_i−y_j)×H), ratio = d(13,14)/d(61,291)
- W·H는 해당 추론에 사용한 실제 upright/scaled MPImage 비트맵 크기다. 원영상 metadata·PreviewView 크기·내부 tensor 크기로 대체하지 않는다
- 가림·NaN·0분모 등 판단 불가 상태를 처리한다. 단위가 달라지므로 기존 normalized 폭 0.001을 그대로 복사하지 않는다
- 앱이 별도 crop/letterbox/회전을 하면 좌표계와 변환을 명시한다. 균일 축소·이동은 비율을 보존하고, 비균일 resize는 피하거나 역변환한다
- 0.12는 임의 상향하지 않는다. 보정 후의 적합성은 라벨 평가로 확인할 후속 항목이다

시험: 제공 Python 검산을 재실행한 다음 그 사례를 실제 Kotlin 함수에 이식한다. 0.10/0.20·경계값, 0/90/180/270도, 가로·세로, 균일 축소·letterbox·crop·mirror, invalid 좌표를 포함한다. 기존 build/test와 두 입력 경로를 확인한다.

완료 보고: 실제 Kotlin 회귀 결과와 Android/실기기 실행 여부를 구분한다. Python 8사례 통과만으로 앱 수정 완료나 영아 정확도 향상을 주장하지 않는다.

## 작업 2 소리의 원클래스와 시간 보존

목표: 전체 최대점수만 남기면서 사라지는 사건 시점과 근거를 보존한다.

- timestamp·분석 구간, raw class ID/이름/점수, 모델·전처리 버전을 유지한다
- 분석 중 RAM에서 전체 score vector를 보존하고 최종 표시용 집계를 분리한다
- 명시적 클래스 매핑을 사용하며 generic Laughter/Giggle과 Baby laughter를 구별한다. Speech 계열의 화자 미확인 상태를 유지한다
- 부모가 확인한 아이 소리와 모델 후보를 서로 다른 필드로 둔다
- 부모 확인형 흐름을 유지한다. 임계값·최대값 집계 대체는 라벨 자료에 대한 후속 비교 없이 임의 적용하지 않는다

시험: 여러 timestamp와 클래스가 병합되어도 원근거 복원 가능, generic 웃음이 baby-specific 근거로 바뀌지 않음, 빈 결과·NaN·실패·취소 처리. 기존 기록·JSON 호환성을 유지하며 원격 전송이나 원본/벡터의 기본 영구 저장을 추가하지 않는다.

## 작업 3 영상과 소리의 관찰 구간 맞추기

목표: 첫 10초 소리와 다른 시점의 얼굴을 같은 사건처럼 사용하지 않는다.

- 기존 10초 오디오 범위에 대응하는 영상 구간과 실제 timestamp를 명시한다
- 키프레임 5장 요약은 정적 장면 관찰로 유지한다. 연속 입 움직임을 주장하려면 실제 연속 프레임·시점 보존이 필요하다
- GOP·중복 프레임·회전 metadata·가변 프레임률·누락을 시험한다
- 아이가 화면 밖에 있다는 이유로 들린 울음 사건까지 폐기하지 않는다
- 30초 전체 분석·새 구간 선택 기능은 별도 결정 없이 추가하지 않는다

완료 보고: 분석 범위 일치와 실제 시점 확인 결과를 제시한다. 지금 PhraseEngine은 소리·상황·세션 ID를 입력받으므로 얼굴 단서가 이미 문장 결정에 쓰인다고 설명하지 않는다.

## 작업 4 평가 도구 준비

목표: 실제 개선을 같은 시험으로 비교할 준비를 한다.

- 가족/아이/세션/원본 출처 hash를 가진 분할 manifest와 누출 검사
- 모델·전처리·threshold 버전, 사건별 precision/recall/F1, 오탐/분, 보류/실패/coverage, 가족 단위 신뢰구간
- 오디오만·영상만·둘의 결합·보호자 맥락을 분리한 실험표
- synthetic 라벨로 집계·분할 검사를 먼저 시험한다
- 아기 자료 수집·다운로드·학습·외부 업로드는 별도 승인 전 시작하지 않는다

후속 판단: 한국어 가정환경에서 라벨 자료·권리가 마련되면 현재 기준선 E0와 집계 개선 E2를 비교하고, 그다음 YAMNet 작은 head·연구 임베딩 후보를 검토한다. 90가족 안과 90%/80% 기준 예시는 이후 연구·자동 추천 정책의 논의안이며 이번 주 베타의 새 출시 필수조건이 아니다.

## 공통 범위

- 앱 이름, 무료·유료 정책, 원본 자동 업로드 없음, 보호자 확인 흐름은 유지한다
- 즐겁게 아이 시점의 표현을 고르는 경험은 유지하되 모델 관찰·부모가 고른 상황·표현 후보를 구분한다
- 새 모델·라이선스 수락·데이터 다운로드·외부 서비스 추가·의료 진단 기능은 포함하지 않는다
- 얼굴 단서를 PhraseEngine에 넣는 기능은 관찰 검증 후 별도 작업으로 결정한다
- 코드 변경 승인 후 현재 checkout·지침·실제 기준 커밋을 다시 확인하고 작은 변경별 시험 결과를 보고한다
