# 표현 개선 0.5.15 구현·검증 계약

사용자는 소리를 놓치는 문제와, 인식 후 `으앙 / 내 목소리 들려요 / 나 좀 봐줘요`에
몰리는 문제를 함께 개선하도록 요청했다. 배고픔·졸림·놀이 욕구의 실제 판별 근거도 추가 조사한다.

## 이번 제품 변경

- 기존 소리 승인·보류 기준, YAMNet/AST 모델, 온디바이스·이용권 정책을 유지한다.
- 울음의 의성어 시작을 강제하지 않는다. 달래기·다정한 반응·곁에 있기 등 표현을 넓힌다.
- 웃음은 함께 웃기·즐거운 놀이 초대, 옹알이는 소리 탐색·흉내내기·말 주고받기로 표현한다.
  초대형 표현은 캐릭터 표현이며 실제 놀이 욕구를 판별했다는 뜻이 아니다.
- 한 구간에서 서로 다른 사건이 안정된 순서로 관찰되면 그 순서를 표현한다.
  두 구간 각각에 연속된 고유 관찰이 있어야 하며, 동시 충돌·되풀이 전환·넓은 AST창만으로
  감정의 변화나 발성 순서를 만들어 내지 않는다. 같은 시간의 중복 관찰은 근거를 늘리지 않는다.
- 긴 표현은 기존의 실제 지속 발성·쉼 근거 검사를 그대로 통과해야 한다.
- 같은 입력/분석 버전의 출력은 동일하다. 표현의 무작위 재뽑기나 최근 이력 의존을 추가하지 않는다.
- 배고픔·졸림·통증의 원인 판별은 이번 표현 수정에서 추가하지 않는다.
  조사된 성능·월령·독립 아기 검증·사용권·온디바이스 가능성을 별도 문서로 남긴다.

| E1 | 같은 울음/옹알이 사건의 서로 다른 입력 키 | 실제 interpreter 계측 | 관심요청·의성어 편중 감소, 같은 입력 결정성 | QA 보고서 |
